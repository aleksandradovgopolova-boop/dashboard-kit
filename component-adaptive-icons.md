# Адаптивные иконки

Подбирает размер значка по контексту и способу управления.

## Когда использовать

- Иконки действий должны соответствовать размеру соседних контролов.
- Один экран используется мышью и на сенсорном устройстве.

## Когда выбрать другое

- Логотип, иллюстрация или график — это не адаптивная иконка.
- Фиксированная иконка данных может использовать dk-i--sm или dk-i--lg.

## Контент: так

- Одна иконка одного смысла во всех размерах.
- Используйте существующие названия Tabler из dkIconNames.

## Контент: не так

- Маленькое окно автоматически считается телефоном.
- Увеличить иконку, сохранив слишком маленькую область нажатия.

## Доступность

- Декоративная иконка: aria-hidden="true"; имя кнопки задаётся текстом или aria-label.
- CSS автоматически реагирует на смену режима указателя.
- Tabler — один масштабируемый рисунок. Это адаптация размера, а не переключение двух отдельных рисунков VKUI.

## Пример

Значок подстраивается под соседний контрол и способ управления. Маленькая иконка не уменьшает область нажатия.

## Структура

- **Иконка** — Один вектор Tabler, без дублирования SVG.
- **Контекст** — В S-кнопках иконка меньше; сама сенсорная цель остаётся минимум 44 px.

## Варианты

- `dk-i--adaptive` — Автоматический размер. Обычный SVG или вызов dkIcon.el.
- `dk-btn--sm / dk-iconbtn--sm` — 16 / 20 px внутри S. Компактные контролы.

## Размеры

Внутри контролов действует общая шкала 18–20 px независимо от ширины окна. Сами сенсорные цели растут до 44 px. За пределами контролов адаптивный SVG сохраняет собственный вариант размера.

## Код

```html
<button class="dk-btn dk-btn--sm"><svg class="dk-i dk-i--adaptive" aria-hidden="true"><use href="#ti-search"/></svg>Найти</button>
```

## Параметры

- `dk-i--adaptive` (класс): Добавьте к dk-i или передайте в dkIcon.el.
