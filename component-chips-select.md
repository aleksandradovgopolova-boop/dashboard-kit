# Выбор нескольких значений · ChipsSelect

Выбрать несколько значений из готового списка. Выбранные значения показаны отдельными метками и доступны для удаления без повторного открытия списка.

## Когда использовать

- Пользователь выбирает несколько объектов из известного справочника.
- Выбранный набор важен для задачи и должен оставаться видимым.

## Когда выбрать другое

- Нужно создавать новые значения — Ввод нескольких значений.
- В компактной строке фильтров достаточно подписи и счётчика — Фильтр.
- Несколько вариантов должны быть видны одновременно — Флажки.

## Контент: так

- Подпись называет набор: «Метки», «Службы».
- Названия значений сохраняют смысл без соседних элементов.
- Кнопка удаления называет конкретное значение.

## Контент: не так

- Placeholder вместо постоянной подписи.
- Все выбранные значения скрыты за счётчиком.
- Обязательные условия ввода описаны только после ошибки.

## Доступность

- В текстовом поле Enter добавляет значение. Backspace в пустом поле переводит фокус на удаление последней метки; Enter или пробел выполняет удаление.
- Выбор из списка использует нативный select. Уже выбранные и отключённые варианты недоступны для повторного выбора.
- Поле имеет постоянную видимую подпись. Кнопки удаления получают доступное название с именем значения.
- Добавление и удаление должны быть доступны с клавиатуры; фокус остаётся в рабочем контексте поля.
- Отключённое состояние запрещает изменение, сохраняя выбранные значения для чтения.
- Проверьте работу с длинными названиями, увеличенным текстом и на телефоне. Полная проверка со скринридером требует отдельного прохода.

## Размеры

Отдельных размеров нет. Поле и кнопки используют размеры существующих компонентов; выбранные значения переносятся на следующую строку.

## Код

```html
<div id="services"></div>
<script>
var services = dkChipsSelect(document.getElementById('services'), {
  label: 'Службы',
  options: [
    { value: 'requests', label: 'Приём заявок' },
    { value: 'telemetry', label: 'Телеметрия сетей' }
  ],
  value: ['requests'],
  placeholder: 'Выберите службу',
  onChange: function (value) { /* применить выбранные идентификаторы */ }
});
services.value(['telemetry']);
// services.destroy();
</script>
```

## Параметры

- `label` (строка): Постоянная подпись поля.
- `value` (массив строк): Начальные значения.
- `placeholder` (строка): Подсказка в поле добавления.
- `disabled` (boolean): Запрет изменения набора.
- `onChange(value)` (функция): Получает новый массив значений после изменения пользователем.
- `instance.value(nextArray)` (метод): Без аргумента возвращает набор; с массивом заменяет значения.
- `instance.disabled(bool)` (метод): Без аргумента возвращает состояние; с boolean переключает доступность.
- `instance.destroy()` (метод): Удаление компонента и его обработчиков.
- `options` (массив {value, label, disabled?}): Справочник: value — идентификатор, label — видимое название; disabled запрещает выбор пункта.
