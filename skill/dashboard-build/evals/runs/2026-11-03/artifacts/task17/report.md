## Бриф и решения

Аудитория → владелец программы. Решение → выбрать регион для разбора отклонения. Вопросы → сколько выполнено, каково отклонение, какие регионы его создают, что происходило по месяцам. Устройства → 390 mobile и 1280 desktop, Dark/Light.

Два равноправных показателя: выполнение плана выдач в кредитах; использование бюджета в млн ₽. Для каждого видны факт, план, процент и отклонение. Шкалы независимы и выражают долю своего плана; точный процент сохраняется, декоративный прогресс ограничен 100%. Лимит бюджета и остаток — контекст бюджетной карточки. Один региональный список отсортирован по отклонению выдач (наиболее отрицательное первым); отдельный рейтинг, карта и дополнительный график не добавлены. Помесячный ряд уже доступен в деталях и не требует третьего обзорного блока.

Месяц действует одновременно на сводки, регионы и детали. Два региона и два месяца не оправдывают поиск и пагинацию. Месяцы доступны непосредственно как сегмент, без скрытого меню. Возврат закрывает dialog и возвращает фокус к региону, месяц сохраняется.

Методика и источник открываются по одной текстовой кнопке в отдельном dialog; формулы и описание источника не занимают рабочий обзор. В методике явно указано отсутствие версии/даты утверждения плана. В обычном состоянии нет поясняющих абзацев. Краткое обозначение учебности, обновления, единицы, подписи и статусы оставлены по §7 assembly-rules. Состояния partial/zero-plan/no-data имеют короткий видимый текст.

## Данные и проверяемые ответы

Формулы взяты из plan-fact recipe, numeric-checks и стандарта деталей: процент = сумма факта / сумма плана × 100%; отклонение = факт − план. Месячные бюджетные лимиты этого учебного набора суммируются согласно numeric-checks. Цвет не задаёт произвольную оценку эффективности бюджета.

До разметки по четырём исходным строкам зафиксированы числовые ответы:

| Срез | Выдачи факт / план | Выполнение | Отклонение выдач | Бюджет факт / план | Выполнение бюджета |
|---|---:|---:|---:|---:|---:|
| Апрель–май | 100 / 200 | 50% | −100 | 50 / 80 | 62,5% |
| Май | 30 / 80 | 37,5% | −50 | 15 / 30 | 50% |
| Санкт-Петербург, весь период | 40 / 50 | 80% | −10 | 20 / 30 | 66,7% |
| Республика Алтай, май | 0 / 50 | 0% | −50 | 0 / 10 | 0% |

Бюджетный лимит всего периода 120 млн ₽, остаток 70 млн ₽. В апреле выдачи 70/120 = 58,3%, бюджет 35/50 = 70%.

Модель не усредняет проценты регионов. Null блокирует соответствующий агрегат и зависимые процент/отклонение, сохраняет другие независимые показатели и обозначает неполноту. Нулевой план сохраняет факт, процент неизвестен. Отсутствие обязательного поля — ошибка контракта. Переданные единицы и агрегирование сверяются с метаданными. Пустой срез не считается нулём. Обобщённую полноту охвата вне четырёх строк fixture не заявляю.

## API и селекторы для основного агента

Запуск: открыть `app/index.html` из файла или на уже разрешённом проверяющем HTTP server. Все ресурсы локальные. Я сервер не запускал.

- Месяцы: `#months [data-month="all"]`, `#months [data-month="2025-04"]`, `#months [data-month="2025-05"]`; выбранный aria-pressed=true.
- Темы: `[data-theme-set="dark"]`, `[data-theme-set="light"]`.
- Сводка: `#summary [data-metric="issued"]` / `[data-metric="budget"]`, дочерние `[data-value="percent|actual|plan|delta|status"]`.
- Регионы: `#regions tr[data-region="altai-rep"]`, `#regions [data-open="spb"]`.
- Детали: `#detail[open]`, `#detail-title`, `#detail-period`, `#detail-summary`, `#monthly tr[data-month="2025-05"]`, `[data-field="issued|issuedDelta|budget|budgetDelta"]`; кнопка `#detail [data-modal-close]`, footer «Вернуться к регионам».
- Сведения: `#method` → `#method-dialog[open]`; закрывающие X имеют dkTooltip: hover/focus/tap/Escape.
- `window.planFact.getView()` — копия модели; `setMonth('2025-05')`, `openRegion('altai-rep')`, `closeDetails()`, `replaceSource(clonedSource)`, `resetSource()`.
- Для null: клонировать `window.PLAN_SOURCE`, установить `rows[3].values.issued=null`, вызвать replaceSource и выбрать май. В issued сводке «Нет данных» и «Неполные данные», в budget остаётся 15/30. Затем resetSource возвращает исходные числа без устаревшего статуса.
