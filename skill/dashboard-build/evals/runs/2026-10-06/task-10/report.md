## Chrome: действия и доказательства

verify.mjs использует tools/browser-harness.mjs, настоящий headless Chrome и CDP; результат verification.json. Мышь нажимает видимые кнопки и опции, Tab/Escape посылаются как keyboard input. Runtime применён для проверки DOM, публичных lifecycle API и установки искусственного отказа нативного requestFullscreen.

- Начальный график отрисован canvas, таблица имеет 12 строк.
- Выбор Тверской области через меню оставляет 6 строк. Таблица и экспорт совпадают с текущим срезом.
- Кнопка CSV действительно скачала файл; содержимое проверено: только Тверская область, 6 строк, заголовки, UTF-8 BOM, CRLF, включая ноль 4 октября. После no-data CSV содержит только заголовок (файл downloads/requests-filtered.csv последним перезаписан пустым срезом; полный текст предыдущего выгруженного среза сохранён в verification.json).
- PNG действительно скачан, сигнатура 89504e470d0a1a0a, 91458 байт. downloads/requests-chart.png просмотрен: только серия отфильтрованного региона, ноль сохранён.
- Полный экран нативно открывается, кнопка выхода внутри видима; нажатие выхода закрывает fullscreen и возвращает фокус кнопке открытия.
- При искусственном отказе requestFullscreen используется modal dialog; выход виден, фокус внутри, после 10 Tab фокус остаётся внутри; Escape закрывает dialog и возвращает фокус кнопке открытия.
- Костромская область даёт 0 строк, текст «Нет наблюдений» в графике и отдельное объяснение таблицы. PNG отключён с видимой причиной. Сброс возвращает 12 строк.
- Плотность compact включена через change нативного select; root получает data-density=compact, desktop row height 28 px. Первоначальный тест update({value:'compact'}) также дал 28 px. Попытка End/Enter через CDP оставила comfortable; её нельзя считать успешным keyboard test для нативного select.
- При 390 px и pointer:coarse компактная плотность не уменьшает видимые кнопки/select: все высотой 44 px; ширина документа 390 px. Тематическая кнопка меняет тему на dark.
- destroy() вызван у fullscreen, density, select, table, chart. Сохранённый ECharts instance сообщает isDisposed=true, canvas удалён, dialogs=0, Runtime exceptions отсутствуют.

## Границы проверки

Нативный Escape через CDP Input.dispatchKeyEvent не закрыл document.fullscreenElement в headless Chrome; после этого состояние сброшено публичным exit(). Поэтому нативный выход Escape не подтверждён автоматизацией, хотя кнопка выхода и Escape fallback подтверждены. Это наблюдение не доказывает работу или поломку физической клавиши в обычном браузере.

Нативный select плотности: change и API подтверждены, реальная клавиатура не подтверждена. Shift+Tab, все варианты повторного init/destroy и автоматический cleanup при удалении узла не проверены. Нет живого spoken screenreader, пользовательского исследования, реального телефона, Safari/Firefox или WebView; эмулятор не выдаётся за устройство. Работа скачиваний в ОС/просмотрщике не проверялась, файл проверен на диске Chrome automation. Страница — учебный срез, не production pipeline.
