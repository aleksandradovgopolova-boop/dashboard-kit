Все три потребности присутствуют в каталоге: `dkBullet`, `dkPeriodComparison`, `dkTimelineAnnotations`; компоненты обозначены экспериментальными. Числа 72, 80, 23, 19 взяты из задания. Процентная единица, показатель «доля устранённых аварий», диапазоны 0–60 / 60–80 / 80–100, даты равных по длительности смен и события — явно названные учебные допущения. У факта написаны обе границы каждого диапазона, поскольку сам SDK перечисляет только верхнюю границу. Объяснены положение точки и длительность полосы; события не выданы за доказательство причины.

Второй визуальный проход убрал повтор заголовка сравнения и повтор времени в названиях событий; исправил лишний знак «+» в фразе про отставание от цели и лишнюю точку после единицы.

## Обнаруженные ограничения

1. Первый эксперимент `annotations.update({events:[]})` без start/end завершился `RangeError: timeline: invalid interval`. Документация говорит `update(opts)` без обещания partial merge; финальный тест передаёт полный набор options. Рекомендуется явно документировать, что update заменяет options и требует границы шкалы. Это не сбой конечной страницы.
2. `events:[]` оставляет только заголовок шкалы, без текста «Нет событий/нет данных», причины и следующего действия. Различие «нет событий» и «данные не загружены» должен объяснить host; готового поведения по этому контракту не наблюдается.
3. Bullet с null фактом использует штриховку и прочерк, но не добавляет видимое слово «Нет данных». Host должен дать пояснение и объявление status для динамического отсутствия наблюдений. У конечного примера статичные непустые данные; полноценный поток загрузки/ошибки не реализован и не заявляется проверенным.
4. Диапазоны bullet чередуют нейтральные поверхности, повторяя заливку первой и третьей зоны. Их смысл передаётся текстом. Отсутствие семантических цветов не выдаётся за пороговый риск.
5. Правильность чисел и доступные альтернативы доказаны для этого примера; причинная связь событий с авариями, реальный источник данных и производственные пороги отсутствуют.

Физические iPhone/Android и настоящий WebView не проверены. VoiceOver/NVDA не прослушивались. Safari/Firefox, системные Dynamic Type/font scale, исследования с участниками, отказ сети и длительные утечки памяти не проверены. Проверки DOM и эмуляция не заменяют эти доказательства.
