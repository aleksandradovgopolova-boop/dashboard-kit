# Своя страница или блоки в чужой

README кита: «Границы кита: .dk-root и .dk-page», «Каркас страницы»,
«Иконки приложения, фавикон и логотип».

## Блоки внутри чужой страницы

```html
<div class="dk-root" data-theme="dark">
  <div class="dk-widget">…</div>
</div>
```

- `dk-root` и `data-theme` / `data-accent` — на одном элементе.
- `dk-page` не ставят: кит не красит фон хозяина.
- Подключение — `kit.py head <части> --embed`: без `dk-theme.js`, тему держит
  обёртка. Графики и карта берут тему и цвета с неё же.
- Каркас (`chrome`) не подключают.

## Своя страница

```html
<html class="dk-root" lang="ru" data-theme="dark" data-accent="blue">
  <body class="dk-page"> … </body>
</html>
```

- Каркас — `kit.py head … chrome`: боковое меню, липкая шапка, «К содержимому»,
  нижняя панель на телефоне. Разметка — `kit.py show chrome` и README «Каркас
  страницы»; собранный образец — `dashboard.html` кита.
- Иконки и фавикон — `kit.py show app-icons`: собрать скриптом из знака
  продукта, теги из его вывода — в `<head>`.
- Акцент — один на продукт: `data-accent` = `blue | violet | indigo`. Красного,
  жёлтого и зелёного акцента нет намеренно.

| ✗ | ✓ |
|---|---|
| `dk-page` на странице хозяина | только `dk-root` на обёртке |
| блоки зависят от меню и шапки | блоки работают и без `chrome.css` |
| иконки нарисованы руками в шести размерах | `node <кит>/tools/build-app-icons.mjs` |
