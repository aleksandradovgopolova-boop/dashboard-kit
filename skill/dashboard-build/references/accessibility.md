# Доступность и задачи

Проверяй реальные потоки: найти проблемный объект, понять показатель, изменить фильтр, раскрыть детали. Используй полные названия, именованные поля/кнопки, заголовки, таблицы с scope и альтернативы графикам. Срез/пустое состояние должны объявляться через status; сброс должен быть достижим. Проверяй Tab, Shift+Tab, Enter, Escape, видимый фокус, удержание и возврат фокуса диалога. На телефоне цели не менее 44 px.

Различай автоматические проверки, экспертный walkthrough, accessibility tree, фактический вывод скринридера и исследование с участниками. Не объявляй успешную проверку screenreader без наблюдаемого вывода. Не выдавай экспертную оценку за пользовательское исследование. Подробности и нерешённые ограничения — DESIGN-UX-ACCESSIBILITY.md в корне кита.
