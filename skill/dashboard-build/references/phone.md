# Телефон и приложение

README кита: «Телефон и приложения», «Внутри приложения (WebView)»,
«Нижняя панель на телефоне», «Живой телефон: ручная проверка».

## Страница в браузере телефона

- Размер под палец решает указатель (`pointer: coarse`), а не ширина — кит
  делает это сам; своих размеров кнопок не задавай.
- Страница никогда не шире экрана: широкое — в своей прокрутке
  (`dk-tablewrap`, строка фильтров, лента).
- Своя страница с каркасом — нижняя панель `dk-tabbar`: 3–5 главных разделов,
  текущий — `aria-current="page"`. Полный список остаётся в меню.
- Поле ввода — кегль 16 (у `dk-search` уже так), иначе iOS прыгает при фокусе.

## Внутри приложения (WebView)

- **Каркас и нижнюю панель не подключают**: навигация и «назад» — у приложения.
- Тему задаёт приложение: `?theme=dark|light`. Свой переключатель темы не ставят.
- «Назад» — сначала `dkBack()`: закрывает верхний слой и отвечает `true`;
  `false` — можно уходить.
- Файлы кита — через свою схему приложения, не `file://`: иначе `fetch` данных
  карты запрещён.
- Выгрузка и внешние ссылки — через приложение.

| ✗ | ✓ |
|---|---|
| фильтры стопкой на всю ширину | строка пилюль, листается вбок |
| меню каркаса внутри WebView | без каркаса, навигация у приложения |
| переключатель темы на странице в приложении | `?theme=` от приложения |
| проверено в эмуляторе — «работает на iPhone» | «эмулятор да, живой телефон не проверен» |
