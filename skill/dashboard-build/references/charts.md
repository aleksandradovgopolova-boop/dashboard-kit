# Графики

Источник — `python3 <кит>/tools/kit.py charts` и README: «Какой график
выбрать», «Каждый вид: когда не брать и что услышит скринридер», «Три правила,
из которых эта таблица следует», «Чего обёртка не позволит».

## Сначала — нужен ли график вообще

| данные | показать |
|---|---|
| одно значение и тренд | KPI-плитка со спарклайном |
| несколько главных чисел | ряд плиток |
| одно число, ради которого экран | `dk-hero` |
| больше семи значимых категорий | таблица или таблица плюс график |

## Выбор вида — по работе читателя

`charts` → «Что должен сделать читатель → чем показать». Строка «НЕТ В КИТЕ» —
**пробел**: скажи человеку и возьми замену из той же строки.

## Обязательное

- `label` — заголовок своими словами. Подпись из данных для скринридера
  обёртка допишет сама. Где точные числа важны — **таблица рядом**
  (колонка «скринридеру» в `charts`).
- `target: { value, label }` — если есть норма: без неё столбец сравнивают с
  соседом, а не с нормой.
- `forecast: n` у серии — незакрытые данные тонкой линией, ромбами и подписью «Прогноз».
- `highlight: 'имя'` — если история про одну серию.
- До шести серий; седьмую свернуть в «Прочее» или развести по графикам.
- Цвет серии ≠ цвет состояния: в одном графике либо принадлежность, либо риск.

| ✗ | ✓ |
|---|---|
| две оси Y | два графика или общая база |
| сглаженная линия | как есть: обёртка не сглаживает |
| пончик на восемь долей | `bar-h` или «Прочее» |
| график с осями в плитке S | `type: 'spark'` |
| цвета серий «по смыслу» (вода синяя) | палитра серий кита — проверена на дальтонизм |
