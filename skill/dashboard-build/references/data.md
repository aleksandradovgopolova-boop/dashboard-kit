# Числа, таблицы, списки, карта

Части описи: `hero`, `car`, `tile`, `rank`, `list`, `table`, `map`, `badge`,
`uptime`, `empty`. Смотри `kit.py show <часть>` — «Брать, когда» и «Не брать →
чем заменить» у каждой.

## Какой блок

| что показать | часть |
|---|---|
| одно число экрана из целого | `hero` |
| 3–7 историй «было → стало» | `car` |
| одно число с трендом | `tile` |
| кто хуже всех, топ-5/10 | `rank` |
| события, полосы доли, раскрытие | `list` |
| много объектов × много показателей | `table` |
| где и у кого хуже по регионам | `map` (карта и плитки с увеличением) |
| работала ли служба по времени | `uptime` |
| загрузка, пусто, ошибка | `empty` — у каждого блока |

## Правила чисел

- Все числа — `dkFmt`: `num`, `compact`, `delta`, `pct`, `pp`, `money`, `date`,
  `range`. Не `toFixed` и не склейка строк.
- Число с мерой: «25 из 89», «за сутки», единица в заголовке колонки.
- Цвет смысла — только у значения, сравнённого с порогом, и всегда со словом
  или значком: статус — `dk-status` со значком, не одним цветом.
- «Нет данных» — не ноль. Пусто — `empty` с тремя строками: что, почему, что
  делать.

## Таблица

- Только прямо в `dk-tablewrap` (проверяется статически).
- Числовая колонка — `dk-td-num`; ширины колонок в сумме ≤ 94%, колонка выбора
  48 px.
- Больше страницы — `pager`; сортировка — `data-sortable`.
- Больше трёх колонок и телефон — `dk-table--cards` и `dkTable(...)`: строки
  станут карточками, шапка — пилюлями сортировки.

## Карта

- Внутри `dk-widget` с `dk-widget__head` — переключатель «карта / плитки» встанет
  в шапку сам.
- Данные карты (`data/*.json`) грузятся `fetch` — страница открывается по http.
- Фильтр по округу — `scope` или `setScope(ids)`: регионы вне среза
  приглушаются, шкала общая. Не красить их «нет данных» и не прятать.

| ✗ | ✓ |
|---|---|
| `value.toFixed(1) + '%'` | `dkFmt.pct(value, 1)` |
| `innerHTML = '<td>' + name` | `dkEsc(name)` или узлами |
| таблица из одной строки | плитки |
| рейтинг на двадцать строк | таблица с пагинацией |

В динамической разметке — `dkMeaning(name, 'text'/'fill')`, canvas —
`dkMeaning.color(name, role, el)`. Не конструируй semantic tokens в JS.
Нет наблюдений: `dk-nodata` плюс «Нет данных»; ноль остаётся нулём.
Разрыв временного ряда — null. Штриховка не заменяет числовую альтернативу.

Для трёх уровней риска: высокий → `crit`, средний → `high`, низкий →
`calm`. Имя `high` в API — предупреждение (жёлтый), а не русский уровень
«Высокий риск». Для событий — `event`, отсутствия наблюдений — `nodata`.
