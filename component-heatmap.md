# Тепловая карта

Помогает найти высокие и низкие значения на пересечении объектов и интервалов.

## Когда использовать

- Нужно найти сочетания объект × время, требующие внимания.

## Когда выбрать другое

- Есть только один ряд: используйте bar-h или uptime для доступности.

## Контент: так

- Название показателя, единица, интервалы и значение каждой ячейки.

## Контент: не так

- Одинаковый цвет для нуля и отсутствующего наблюдения.

## Доступность

- Настоящая таблица с заголовками scope и числовыми значениями. Четыре уровня отмечены I–IV, а отсутствие — текстом и нейтральной заливкой. На телефоне таблица прокручивается внутри; цвета смысловые, не accent.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Сопоставьте цвет, уровень и число. Ноль и отсутствие данных обозначаются по-разному.

## Структура

- **Контекст** — Сравнение интенсивности по объектам и интервалам с доступными числами.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Ноль — измерение. null/нечисловые значения — Нет данных. Пороговая оценка объясняется легендой; большая матрица требует предварительной агрегации, виртуализации нет.

## Варианты

- `dkHeatmap(el, opts)` — Основной контракт API/markup. При задаче, описанной выше.

## Размеры

Размер зависит от числа строк и колонок. На узком экране таблица прокручивается внутри контейнера.

## Код

```html
<div id="advanced-heatmap"></div>
<script>
document.addEventListener("DOMContentLoaded", function(){
dkHeatmap(document.getElementById('advanced-heatmap'), {label:'Риск по службам', columns:['Пн','Вт','Ср'], thresholds:[25,50,75], rows:[{label:'Тепло',values:[12,58,null]},{label:'Вода',values:[0,77,35]}]});
});
</script>
```

## Параметры

- `dkHeatmap(el, opts)` (API): columns: string[], rows: {label,values}[], thresholds: три возрастающих числа. update(opts), destroy().
