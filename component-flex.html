↔️Строка и колонка

Располагает элементы в строку или колонку с едиными интервалами и переносом.

Статус: стабильный ПримерКак выбратьС чем сочетатьКод и API

В работе

Элементы выстраиваются в строку или колонку с едиными интервалами. При изменении ширины группа переносится, сохраняя порядок.

Код примера ↗

Когда использовать

Когда использовать
  • Кнопки и подписи внутри одной группы.
  • Колонка элементов с одинаковым интервалом.
Когда выбрать другое
  • Равноправные карточки — Сетка карточек.
  • Виджеты разной ширины — сетка дашборда dk-grid.
  • Визуальный порядок не должен расходиться с порядком чтения и клавиатуры.

Из чего состоит

1 Контейнер
2 Содержимое и управление
  1. Контейнер — Задаёт раскладку или поведение.
  2. Содержимое — Названия, данные и доступные действия задаёт приложение.

Варианты и размеры

Ширина определяется контейнером. Интервалы задаёт --flex-gap; перенос включён по умолчанию. Выравнивание выбирается по задаче группы.

Класс или параметрЧто делаетКогда
dk-flexСтрока с переносом.По умолчанию.
dk-flex--columnКолонка.Вертикальная группа.
dk-flex--between / --centerРаспределение по главной оси.Шапка / центрирование.
dk-flex--start / --stretchВыравнивание по поперечной оси.Разная высота / одинаковая высота.
dk-flex--nowrapБез переноса.Только если содержимое помещается.

Состояния

Строка переносится при нехватке ширины. Для вертикальной группы используйте column; nowrap допустим только при гарантированно коротком содержимом.

Текст и подписи

Понятно
  • Полные названия объектов и конкретные действия.
Вызывает вопросы
  • Непонятные подписи «Далее» для перехода к объектам без контекста.

Доступность

  • Порядок чтения и Tab соответствует DOM; не используйте reverse для смысловой перестановки.
  • На телефоне кнопки имеют область нажатия минимум 44 px.
