# Баннер и уведомление

Баннер отвечает за состояние всей страницы и не закрывается, пока не ушла причина. Уведомление подтверждает действие человека и уходит само. Две разные вещи, которые часто путают.

## Когда использовать

- Баннер: состояние, которое касается всей страницы, — сбой служб, устаревшие данные, готовый отчёт.
- Уведомление: подтвердить, что действие человека выполнено: «Срез сброшен», «Работа добавлена».
- Уведомление с «Отменить»: действие обратимо, и отмена дешевле подтверждения заранее.

## Когда выбрать другое

- Новость о данных («Авария в Новосибирске») — не уведомление: уехавшее через пять секунд сообщение о новой аварии — это авария, которую никто не увидел. Это баннер или строка в ленте.
- Проблема одного виджета — ошибка внутри виджета, не баннер страницы.
- Подтверждение опасного действия — Модальное окно.

## Контент: так

- Заголовок баннера с числом и глаголом: «Не удалось обновить данные».
- Уведомление в прошедшем времени: «Работа добавлена в календарь».
- Тревожное уведомление говорит, что делать: «попробуйте ещё раз».

## Контент: не так

- Баннер «Внимание!» без того, на что.
- Уведомление «Успешно» — что именно?
- Крестик на баннере о сбое — сбой, спрятанный руками человека, который через час о нём забудет.

## Доступность

- Уведомления объявляются скринридеру: полка — живой регион.
- Крестик с aria-label; кнопка действия — обычная кнопка, Tab до неё возможен, поэтому таймера с действием нет.
- Не только цветом. Значок и текст у обоих; цвет — дополнение.
- Контраст. Заголовок и подстрока на заливке баннера — проверка КОНТРАСТ в обеих темах.

## Размеры

Размер один: баннер на всю ширину под шапкой страницы, уведомление до 520 px в правом нижнем углу, не больше трёх одновременно — старые уходят снизу.

## Код

```html
<div class="dk-banner dk-banner--crit">
  <svg class="dk-i"><use href="#ti-alert-triangle"/></svg>
  <div class="dk-banner__text">
    <div class="dk-banner__title">Не удалось обновить данные</div>
    <div class="dk-banner__sub">Проверьте подключение и повторите загрузку</div>
  </div>
</div>

<script>
dkToast('Работа добавлена в календарь');
dkToast('Срез сброшен', { action: { name: 'Отменить', onClick: restore } });
var t = dkToast('Не удалось сохранить', { kind: 'crit' });
t.close();
</script>
```

## Параметры

- `dk-banner--priority / dk-banner__number` (классы): Опциональный главный баннер обзора: крупное число, тонированная поверхность и действие. Использовать с crit/high/calm; обычные сообщения сохраняют прежний вид.
- `dkToast(text, opts)` (функция): Показать уведомление; возвращает {close, el}.
- `opts.kind` ('calm' | 'high' | 'crit'): Вид; по умолчанию calm.
- `opts.action` ({name, onClick}): Кнопка; отключает таймер.
- `opts.life` (число мс): Явное время жизни.
- `dk-banner--crit | --high | --calm | --event` (класс): Вид баннера; закрывается только event.
