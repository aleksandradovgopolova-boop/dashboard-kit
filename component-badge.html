Бейдж, статус, прогресс

Мелкие детали, из которых собраны таблицы и карточки. Бейдж отвечает «сколько» или «что за штука», статус — «как дела» и обязан иметь значок и подпись, прогресс — «сколько сделано».

стабильный версия кита: не ведётся — открыто в DECISIONS.md, п. 5 Figma: нет код: css/components.css

Живой пример

Атомы сами по себе и внутри строки таблицы — ради этого они и нужны.

АварияВ работеУстраненоНет данных
72%
34%
—
АКБМ+4следят за регионом

Когда использовать

Да
  • Бейдж: число или короткая метка рядом с названием — «23» у вкладки, «БПЛА» у региона.
  • Статус: состояние объекта в строке таблицы или карточке.
  • Прогресс: доля выполненного, когда есть известный конец: устранение, готовность.
Нет → куда
  • Категория, которую можно снять, — чип-фильтр, не бейдж.
  • Главное число экрана — KPI-плитка, бейдж для этого мелок.
  • Доступность во времени — Полоса доступности, не прогресс.

Анатомия

Номера на схеме — те же, что в списке.

1232БПЛА
34В работе
5664%
  1. Бейдж с числом — цвет смысла — только если число сравнивают с порогом (балл риска); иначе нейтральный.
  2. Бейдж-метка — dk-badge--pill: короткое слово-категория, всегда нейтральный.
  3. Значок статуса — обязателен: цвет видят не все, в чёрно-белой печати его нет вовсе.
  4. Подпись статуса — обязательна по той же причине; статус без слова — не статус.
  5. Дорожка прогресса — поверхность третьего уровня; заливка — --accent со значением по умолчанию.
  6. Число — рядом с полосой всегда: полоса показывает «примерно», число — «сколько».

Варианты и размеры

Размер один — под строку таблицы и текст карточки. Крупнее нужен не бейдж, а число KPI.

Класс или параметрЧто делаетКогда
dk-badgeНейтральный бейдж с числом или словом.По умолчанию.
dk-badge--crit / --high / --calmЦвет смысла.Число сравнивают с порогом.
dk-badge--brandАкцентный: «новое».Единственный бейдж с акцентом; открыто в REVIEW.md.
dk-badge--pillМетка-категория.Слово, не число.
dk-status / --crit / --high / --calmСтатус со значком и подписью.Состояние объекта; без модификатора — «нет данных».
dk-progress / --indeterminateПолоса; неопределённая бежит.Известен конец / не известен.
dk-avatar / --sm / --moreИнициалы человека; «+4».Кто отвечает, кто следит.

Состояния

АварияВ работеУстраненоНет данных
0%
100%
—
«Нет данных» — отдельное состояние, а не ноль. Статус без модификатора и прогресс с прочерком говорят «не знаем», а не «ничего». Ноль процентов — это ответ.

Контент

Так
  • Статус — одно-два слова о состоянии: «В работе», «Устранено».
  • Метка — существительное-категория: «БПЛА», «Плановое».
  • Прогресс с числом рядом и понятным концом: 64% устранения.
Не так
  • Статус одним цветом или одним значком.
  • Бейдж «новое» на всём подряд — акцент перестаёт значить «новое».
  • Прогресс без числа и без известного конца — там неопределённая полоса.

Доступность

  • Не только цветом. Статус — значок + подпись; бейдж цвета смысла всегда с числом.
  • Прогресс — число рядом читается скринридером; сама полоса декоративна.
  • Аватары — инициалы с aria-label полного имени.
  • Контраст. Подписи статусов и бейджей на своих заливках проверяются проверкой КОНТРАСТ в обеих темах.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

Код

Только разметка; скрипта нет. Цвет заливки прогресса задаётся входным параметром --accent.

<span class="dk-badge dk-badge--crit">23</span>
<span class="dk-badge dk-badge--pill">БПЛА</span>

<span class="dk-status dk-status--high">
  <svg class="dk-i"><use href="#ti-clock"/></svg>В работе
</span>

<div class="dk-progress">
  <span class="dk-progress__track"><span class="dk-progress__fill" style="width:64%;--accent:var(--high)"></span></span>
  <span class="dk-progress__value">64%</span>
</div>
ПараметрТипЧто делает
