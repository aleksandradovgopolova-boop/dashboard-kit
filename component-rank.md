# Рейтинг и сводка

Располагает объекты по одному показателю, чтобы быстро увидеть лидеров и отстающих.

## Когда использовать

- Вопрос «у кого хуже» по одному показателю: регионы по баллу, команды по просрочке.
- Нужен верх списка, а не весь список — топ-5 или топ-10.
- Строка ведёт к объекту: клик открывает регион.

## Когда выбрать другое

- Несколько показателей на объект — Таблица.
- Доля от самого крупного полосой — Полосы (dk-bars).
- Все 89 регионов — Плитки регионов.

## Контент: так

- Заголовок называет показатель и порядок: «Регионы с наибольшим отставанием».
- У числа есть единица и период; база сравнения указана, если нужна.
- Полные названия объектов совпадают с источником.

## Контент: не так

- Длина полосы и число показывают разные показатели.
- Порядок строк не объяснён.
- Одинаковый цвет обозначает разные уровни риска.

## Доступность

- Строки — кнопки: Tab и Enter открывают объект; кольцо фокуса при навигации с клавиатуры.
- Порядок читается числом номера, не только положением.
- Значение цветом и числом; цвет — дополнение.
- Контраст. Значения на поверхности панели — проверка КОНТРАСТ.

## Пример

Порядок строк помогает найти крайние значения, полосы — оценить разницу. Подпись уточняет показатель и направление сортировки.

## Структура

- **Тренд сводки** — dk-trend внутри dk-summary: куда идёт и в скольких объектах.
- **Главное число** — dk-score: значение и «из скольких» мельче.
- **Шапка рейтинга** — надпись и стрелка направления сортировки.
- **Номер** — dk-rank__i: место в списке, две цифры.
- **Название** — переносится и остаётся видимым целиком.
- **Значение** — dk-rank__v табличными цифрами; цвет смысла через --accent.

## Состояния

Загрузка Загружаем рейтинг Ничья и нет данных 04 Новосибирская область 73 04 Ростовская область 73 — Чукотский АО — Равные значения делят место. Два региона с баллом 73 — оба четвёртые, следующий шестой. Регион без данных в рейтинг не входит и стоит внизу с прочерком.

## Варианты

- `dk-summary` — Главное число с трендом. Верх правой колонки.
- `dk-rank` — Ранжированный список кнопок. Топ-N.
- `dk-rank__meter` — Необязательная сравнительная полоса; дочерний span получает --value в процентах и --fill из роли заливки. aria-hidden, точное число рядом. Общая нулевая шкала для всех строк среза; не выдавать относительную длину за процент выполнения.
- `dk-chip` — Число с подписью. Разбивка по категориям под сводкой.
- `--accent на dk-rank__v / dk-chip__n` — Цвет смысла значения. Порог: crit-ink, high-ink, calm-ink.

## Размеры

Ширина определяется сеткой виджетов. Показывайте короткий список лидеров; полный набор вынесите в таблицу с сортировкой и пагинацией.

## Код

```html
<div class="dk-summary" style="--accent:var(--crit-ink)">
  <div><div class="dk-trend"><svg class="dk-i"><use href="#ti-arrow-up-right"/></svg> негатив растёт в 28</div></div>
  <div class="dk-score"><span class="dk-score__v">23</span><span class="dk-score__of">/89</span></div>
</div>

<div class="dk-rank">
  <div class="dk-rank__head"><span class="dk-overline">Регионы</span></div>
  <button class="dk-rank__row" data-id="RU-CR">
    <span class="dk-rank__i">01</span>
    <span class="dk-rank__name">Крым</span>
    <span class="dk-rank__v" style="--accent:var(--crit-ink)">82</span>
  </button>
</div>
```

## Параметры

- `--accent` (переменная в style): Цвет значения или числа чипа.
- `dk-rank__row` (кнопка): Строка; страница вешает клик.
- `dk-score__of` (элемент): «из скольких» — не пропускать.
