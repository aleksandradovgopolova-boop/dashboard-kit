# Выбор в иерархии

Выбирает объекты из иерархии групп и дочерних элементов.

## Когда использовать

- Нужно выбирать объекты, объединённые в реальные группы: территории, подразделения, службы.

## Когда выбрать другое

- Плоский справочник — Фильтр или Выбор нескольких значений.

## Контент: так

- Полные названия групп и объектов; частичный выбор виден у родителя.

## Контент: не так

- Одинаковые подписи дочерних объектов без контекста группы.

## Доступность

- Tree/Treeitem, aria-level/posinset/setsize, aria-checked mixed. Стрелки/Home/End перемещают, Right/Left раскрывают/сворачивают, Space/Enter выбирают. Поиск сохраняет поле и контекст родителей.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Раскройте группу и выберите объекты внутри. Отметка родителя показывает, выбрана вся группа или только часть.

## Структура

- **Контекст** — Выбирает объекты из иерархии групп и дочерних элементов.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Группа бывает выбрана целиком, частично или не выбрана. Вложенные пункты можно раскрыть. Ограничения и подключение Выбранные leaf ids, parent отражает true/mixed/false. Disabled исключается из выбора и распространяется вниз. До 1000 узлов; без виртуализации. На touch весь ряд 44px выбирает; раскрытие нажатием стрелки, через expand API/клавиатуру.

## Варианты

- `dkTreeSelect(el, opts)` — Разметка и параметры компонента. При задаче, описанной выше.

## Размеры

Ширина задаётся контейнером; вложенность обозначается отступами. Справочник должен оставаться обозримым.

## Код

```html
<div id="advanced-tree"></div>
<script>
document.addEventListener("DOMContentLoaded", function(){
dkTreeSelect(document.getElementById('advanced-tree'), {label:'Службы',nodes:[{id:'all',label:'Все службы',children:[{id:'heat',label:'Тепло'},{id:'water',label:'Вода'}]}]});
});
</script>
```

## Параметры

- `dkTreeSelect(el, opts)` (API): nodes:{id,label,disabled?,children?}[], value: id[], onChange(ids). value(), expand(id), update({value}), destroy().
