# Экспорт среза

Сохраняет переданные строки в файл или текущий график в изображение.

## Когда использовать

- Нужно скачать текущий срез или сохранить изображение графика.

## Когда выбрать другое

- Полный серверный набор недоступен браузеру автоматически. Для его выгрузки приложение подключает отдельный запрос.

## Контент: так

- Формат и объём понятны: «Скачать выбранные строки в CSV».

## Контент: не так

- «Скачать всё», когда приложению доступна только одна страница.

## Доступность

- Нативная кнопка с ясным названием формата. Экспорт не требует сервера; файл создаётся браузером. Об успешном скачивании ОС API не сообщает.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Кнопка скачивает переданные приложением строки или изображение графика. Она не получает скрытые данные с сервера автоматически.

## Структура

- **Контекст** — Сохраняет переданные строки в файл или текущий график в изображение.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Формат выгрузки и её состав заданы приложением. Если выгрузка невозможна, причина сообщается пользователю. Ограничения и подключение Canvas-графики экспортируются PNG, не SVG. SVG с внешними ресурсами/скриптами отклоняется. Имя очищается. Blob возвращается без скачивания, если name не передан.

## Варианты

- `dkExport.csv(rows, columns, name?)` — Разметка и параметры компонента. При задаче, описанной выше.

## Размеры

Кнопка использует общую шкалу контролов. Размер не зависит от объёма экспортируемых данных.

## Код

```html
<div class="dk-export"><button type="button" class="dk-btn" id="advanced-export">CSV текущего среза</button><p role="status" id="advanced-export-status"></p></div>
<script>
document.addEventListener("DOMContentLoaded", function(){
document.getElementById('advanced-export').addEventListener('click',function(){dkExport.csv([{region:'Ивановская область',risk:92}], [{key:'region',label:'Регион'},{key:'risk',label:'Риск'}], 'regions-filtered');document.getElementById('advanced-export-status').textContent='CSV подготовлен браузером';});
});
</script>
```

## Параметры

- `dkExport.csv(rows, columns, name?)` (Blob): UTF-8 BOM, CRLF, quotes; formula-like strings prefixed with apostrophe. Передавайте текущий срез, не исходные строки.
- `dkExport.chart(chart, name?)` (Promise<Blob>): PNG через dkChart.exportImage(). SVG только из переданного самодостаточного DOM SVG: dkExport.svg(svg,name?).
