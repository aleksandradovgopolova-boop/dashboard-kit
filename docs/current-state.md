# Dashboard Kit — принятый срез 28.10.2026

Этот документ фиксирует текущие решения; старые записи DECISIONS/HANDOFF и
архивные изображения не отменяют последующие прямые уточнения пользователя.

- Только Graphite Dark/Light. Синий акцент действий, бирюзовый/сиреневый для
  сопоставимых серий; семантика статусов последовательна. Signature и три
  последующих Apple-направления отвергнуты. Третья плотность остаётся предложением.
- Полезность и аналитическая иерархия важнее количества виджетов. КПЭ равны,
  в ипотеке шесть мини-виджетов одной полосой; единицы не отделяются от числа.
- Заголовок слева, компактные фильтры/действия справа рядом с темой. Поля
  фиксированы в рамках breakpoint, место для сброса зарезервировано. Выбор
  длинного значения не меняет строку или координаты; полное имя доступно в списке.
- `dkStableView` фиксирует рамку исходного вида для текущего viewport. Смена
  представления не сдвигает соседей; resize пересчитывает базу. Подключено к
  карте и календарю; для новых переключаемых виджетов контракт применяется явно.
- Карта сохраняет координаты всех 89 регионов, без точек в плитках. Кликабельная
  легенда под заголовком. Телефонная карта сдвигается внутри ограниченного окна;
  полный обзор с читаемыми подписями на одном телефоне не заявлен. До 1023px
  графики ипотеки идут по одному; таблица на телефоне группирует числовые поля.
- Короткая детализация — [DASHBOARD-DETAIL-MODAL-001](2026-10-28/DASHBOARD-DETAIL-MODAL-001.md).
  Длительная работа с большим объёмом — отдельная страница. Никаких фиктивных
  переходов и выводов о причинах только по факт/план.
- Учебный набор ипотеки: 534 наблюдения, 89 регионов × 6 месяцев. Источник,
  формулы и ограничения — [методика](family-mortgage.md). Ноль отличается от
  отсутствия данных; КПЭ и все представления используют один срез.
- Общий слой данных, учебный API и необязательный React-адаптер сохранены
  как ранее подготовленные части кита. Патч ИИ-среды не применён к другому
  продукту. Реальный backend, права, production и физические устройства
  не подтверждены этими примерами.
