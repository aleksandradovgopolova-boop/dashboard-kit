# Просмотр визуальных вариантов

Открыть `index.html` через существующий сервер 127.0.0.1:8772. По умолчанию
масштаб 100%; «Весь экран» вписывает композицию, 150% увеличивает детали.
Прокрутка и перетаскивание мышью перемещают увеличенное изображение.

1. `01-graphite.png` — дымчатый графит, серебристые кромки, cyan/lilac.
2. `02-pearl.png` — светлый перламутр, голубые/лавандовые переливы.
3. `03-plum.png` — глубокий сливовый, фиолетовые отражения.

Это три существующих растровых эскиза, не действующий интерфейс или источник
данных. Все файлы 1487×1058, скопированы без изменения пикселей. Выбор ещё
не получен, новый стиль в продукт не перенесён. Браузером проверены три
загрузки, 100%/150%, вписывание и перетаскивание; ошибок галереи нет.
