# DASHBOARD-DETAIL-MODAL-001

Общий стандарт быстрого просмотра объекта. Требования получены из переданного
пользователем текста и его уточнения: изображение концептуальное, не источник
данных и не утверждение новой палитры. Действует выбранный Graphite, Dark/Light.
Три предложенных Apple-направления отвергнуты; к их выбору не возвращаемся.

## Выбор поверхности

Небольшой обзор, понятный без длительной работы, открывается в modal. Большой
набор связанных представлений, длительное сравнение и самостоятельный сценарий
работы требуют отдельной страницы дашборда с реальным маршрутом и возвратом
к прежнему срезу. Не строить фиктивный переход «Открыть объект». В текущей
семейной ипотеке четыре КПЭ и шесть месячных строк оправдывают модалку;
отдельная страница с дублирующими данными не добавлена.

## Контракт компонентов

| ID | Правило | Реализация в Kit и ипотеке |
| --- | --- | --- |
| MOD-001 | Заголовок/контекст → КПЭ → детали → примечания → действия; пустые секции скрыты | `dk-modal__head`, `dk-modal__metrics`, таблица, `dk-banner`, `dk-modal__foot`; пустая таблица заменяется сообщением |
| MOD-002 | Одна главная метрика на карточку; подпись, значение, единица, сравнение/статус при наличии | Существующий `dk-tile`, общая сетка `dk-modal__metrics` на 1–4 колонки; единица объёма на одной строке |
| MOD-003 | Период слева, числа справа, локализованные значения, сортировка, прогресс с текстом и отдельное отклонение | `dkTable`, `dkFmt`, `dk-td-num`, `dk-progress`, `dk-status`; raw sort values; CSV в текущем порядке строк |
| MOD-004 | Темы, семантика, типографика и материал общие | `dk-modal--detail` в components.css; семантические токены; никаких сырых цветов в host |
| MOD-005 | Сначала результат, затем объясняющие показатели; факт/план не доказывает причину | Выполнение плана первым; формулы и ограничение интерпретации видимы в примечании |
| MOD-006 | Ограниченная высота, внутренний scroll, доступные X/действия, клавиатура и возврат фокуса | Нативный dialog + `dkModal`; fullscreen до 767 px; header/footer вне прокручиваемого тела |

`dk-modal--detail`: standard до 800 px; `dk-modal--wide` вместе с ним — до
960 px. Desktop max-height 90dvh, padding 24 px; mobile fullscreen, padding
16 px. Шаги 8/12/16/24 px вычисляются из существующих space tokens.
Таблица имеет собственную горизонтальную прокрутку; длинные данные доступны
целиком. Вкладки нужны только самостоятельным представлениям, а не для
разделения шести строк. Footer содержит только реально доступные действия.

## Достоверность и смысл

Факт, план, процент и отклонение получают из одного snapshot и одного среза.
Отклонение = факт − план. Выполнение = факт / план × 100%; при нулевом или
неизвестном знаменателе — «Нет данных». Ноль остаётся наблюдением. Полоса
прогресса ограничена целью 100%, точный процент остаётся текстом и в ARIA.
Порог/направление желательности задаёт предметная модель: рост и превышение
плана нельзя автоматически считать благоприятными для любого показателя.
В ипотечном примере применяется действующая классификация выдач/плана.
Период данных и время актуализации показаны отдельно; источник явно учебный.

## Состояния

| Состояние | Требуемое поведение | Текущее покрытие |
| --- | --- | --- |
| loading | Недоступные действия не активны, статус загрузки объявлен | Начальный host skeleton, inert фильтры, aria-busy; отдельного запроса модалки нет — она читает уже загруженный snapshot |
| empty | Понятное сообщение, путь восстановления, без пустой таблицы и фиктивной выгрузки | Host empty + сброс проверены в браузере; guard пустых monthly и disabled CSV проверен по коду, отдельной UI fixture нет |
| error | Ошибка/повтор не теряют выбранный срез; недостоверные данные не показываются | Host retry/map retry существуют; некорректный источник отклоняется unit-тестами; сетевой отказ в текущем CUA-прогоне не воспроизводился |
| partial | Явно указать неполноту; не превращать null в ноль | Coverage и null-safe форматирование; unit-тест частичного источника пройден; визуальный partial-fixture не прогонялся |
| selected/focus/disabled | Единая система состояний, видимый фокус, недоступность реальна | Легенда, сортировка, X, Escape, focus loop/return, сохранение региона; disabled экспорт при пустом срезе |

## Проверка 28.10.2026

CUA: Dark/Light, CSS viewport 320/390/600/768/1024/1100/1280/1536 px,
900 px высотой; отдельная проверка модалки 320/390 и desktop.
На 320 px тело модалки прокручивается, header/footer остаются в пределах
экрана; на 390 px таблица доступна горизонтально с клавиатуры. X и Escape
закрывают окно, фокус возвращается к исходному региону, фильтр Алтая сохраняется.
Длинное название Ханты-Мансийского АО — Югры проверено через фильтр/модалку.
Сортировка и реальный CSV проверены; 6 строк файла следуют текущей сортировке.

Проверенные текстовые пары modal на opaque surface: Dark primary 14.04:1,
caption 8.29:1, critical 4.79:1, warning 6.33:1; Light primary 15.15:1,
caption 7.17:1, critical 5.04:1. Статусы/прогресс имеют текст, цвет не единственный
канал. Это выборочная проверка контраста, не сертификат WCAG 2.2 AA:
VoiceOver, реальные телефоны, все состояния и все интерактивные пары не проверены.

Приёмка: единые компоненты/токены, ключевой результат до таблицы, читаемые
числа, согласованные вычисления, предметная семантика и keyboard/responsive
подтверждены в указанном объёме. Loading/error/partial имеют названные выше
ограничения. Полный browser/AX suite не запускался. См. design-qa.md и снимки
в `docs/2026-10-28/stable-views/`.
