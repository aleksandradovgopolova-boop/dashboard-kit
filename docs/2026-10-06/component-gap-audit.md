# Состав dashboard-kit: сверка с VKUI

Дата: 6 октября 2026. Источник каталога: https://vkui.io/components/counter/ (навигация содержит список компонентов); отдельно изучены Avatar и Chip.

Сравнение по пользовательским задачам, а не по числу React-компонентов. dashboard-kit остаётся статическим HTML/CSS/JS.

| Задача / VKUI | В dashboard-kit | Пробел / действие |
|---|---|---|
| Avatar, UsersStack | dk-avatar, dk-avatars | Были спрятаны в странице бейджа. Добавлена отдельная страница «Аватар», фото/инициалы/группа |
| Chip | dk-fchip, dk-chipbar | Добавлена отдельная страница «Чип» с удалением и клавиатурным фокусом |
| Counter | dk-counter | Добавлен отдельный числовой индикатор, S/M, обычный/приглушённый/ошибка |
| ChipsInput, ChipsSelect | dkChipsInput, dkChipsSelect | Уже есть самостоятельные страницы; это ввод/выбор набора, а не один Chip |
| Badge, ContentBadge, InfoRow | dk-badge, dk-row | Есть, требуется ясное разделение счётчика, метки и статуса |
| Button, IconButton, ToolButton | dk-btn, dk-iconbtn | Есть |
| Checkbox, Radio, Switch | Страница check | Есть |
| Input, Textarea, FormItem, FormStatus | Страница field | Есть |
| Select, CustomSelect, NativeSelect | dkSelect | Есть управляемый фильтр; отдельное нативное поле выбора не выделено |
| Slider | Нет | Приоритет: диапазон чисел, минимум/максимум, клавиатура и подпись значения |
| File, DropZone | Нет | Приоритет: загрузка данных, формат/лимит, ошибка, повтор, клавиатура |
| Calendar, CalendarRange, DateInput | Период с Air Datepicker | Покрывает фильтр по дате; самостоятельный ввод даты в форме не выделен |

| Skeleton, Spinner | Состояния empty | Общая загрузка есть; отдельные атомы не выделены |
| Snackbar, Alert | banner / modal | Есть уведомление и подтверждение; не все варианты VKUI нужны |

| Popover, ActionSheet | Popover только стили | Нет завершённого общего контроллера размещения, закрытия и фокуса; приоритет |

| Layout, Spacing, Typography | Сетка, токены и типографика | Есть; React-провайдеры VKUI не переносим в статический кит |

## Следующий порядок реализации

1. Загрузка файла и числовой диапазон: закрывают отсутствующие задачи ввода.
2. Общий popover/tooltip: размещение, Escape, внешний клик, фокус, обе темы.
3. Документированные строки с аватаром и счётчиком, отдельные страницы прогресса и загрузки.
4. Изображения и галерея — по конкретной задаче продукта.

Это исследование каталога и трёх атомов, а не аудит всех состояний каждого компонента VKUI. Не считать остальные пробелы реализованными.

Изучены также https://vkui.io/components/accordion/ и https://vkui.io/components/banner/. Баннеры в ките уже есть: ошибка, предупреждение, штатное состояние, сообщение с закрытием; примеры приведены к нейтральному контексту данных и отчётов.

## Перенесённые практики VKUI

- Avatar: до двух инициалов, размер текста по размеру аватара, сохранение пропорций фото, группа с отдельным «ещё N». Градиенты не переносим в рабочий дашборд.
- Counter: числовое содержимое, два размера, контраст внутри основной кнопки, точное доступное число для 99+.
- Chip: различаем обычный, второстепенный, только чтение и недоступное удаление; текст доступного имени удаления включает значение чипа.
- Accordion: цель раскрытия — весь заголовок, стрелка справа, независимые разделы или группа с одним открытым; нативная клавиатура.
- Banner: короткий заголовок и подзаголовок, необязательное действие/закрытие; важный сбой нельзя скрыть как необязательное сообщение.

Визуальная адаптация использует существующие нейтральные поверхности, единые размеры контролов, контурные иконки и отсутствие теней. Источники: страницы Avatar, Counter, Chip, Accordion и Banner VKUI, приведённые выше.

## Реализованные утилиты и продолжение

Добавлены AdaptiveIconRenderer, CustomScrollView, OnboardingTooltip, PopoutWrapper, ScrollArrow, Touch, FocusTrap, Flex, CardScroll и CardGrid в статической архитектуре кита. Пошаговые подсказки не заменяют общий Tooltip/Popover.
