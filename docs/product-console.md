# Пульт продукта dashboard-kit

Пульт показывает состояние проекта, ближайший шаг, существующий план,
открытые задачи GitHub, проверки и три продуктовые метрики. Нового плана,
процента готовности или выдуманных внедрений нет.

## Открыть локально

```sh
python3 tools/product-console.py serve --port 8772
```

Адрес: http://127.0.0.1:8772/product-console.html. Сервер слушает только loopback,
читает состояние и не запускает агентов, изменения Git, обновления или публикации.
Кнопка обновления перечитывает локальные файлы; GitHub имеет отдельную дату снимка.
Конфигурация установки и скрытые каталоги через сервер не выдаются. Разрешены
только паспорт/Delivery и журналы проверок самого пульта.

## Снимок без сервера

```sh
python3 tools/product-console.py snapshot
```

После этого product-console.html открывается с сохранёнными данными даже без API.
Он явно называется снимком; дата не заменяется датой открытия страницы.

## Источники

| Область | Источник |
|---|---|
| Установка AI Ops | .ai-ops.yaml; релиз и фактический канал в product-console/upstream.json |
| Локальные и неопубликованные изменения | git status и diff ветки относительно подтверждённого main |
| Единственный план | planning/plan.yaml |
| GitHub | product-console/github.json: публичные issues, main и подтверждённые прогоны опубликованного SHA |
| Результаты локальных проверок | .ai/project/product-console/checks.json и журналы |
| Определения метрик | .ai-ops/PRODUCT_PASSPORT.md; подтверждение владельца от 06.10.2026 |

Снимок GitHub обновляется отдельно, с проверкой исходных публичных API-ответов.
На 26.11.2026 подтверждены main a0c373e, CI42221198356 и Pages42221289606.
Пульт не объявляет их новым локальным прогоном. Данные о применении продукта,
времени сборки, числе дашбордов и ручных исправлениях не измерены.

## Записать проверку текущих исходников

```sh
python3 tools/product-console.py check quick
python3 tools/product-console.py check browser
python3 tools/product-console.py check runtime
python3 tools/product-console.py check aiops
python3 tools/product-console.py check full
```

Это существующие команды кита, а не новая система проверок. Веб-страница их
не запускает. Результат содержит время, команду, код выхода, журнал и подпись
исходников/входных данных. Изменившиеся исходники превращают прежний PASS/FAIL
в исторический результат. Неизвестные и повреждённые источники не становятся нулями.

```sh
python3 tools/check-product-console.py
node tools/check-product-console.mjs
```

Проверяется реальный локальный API, отсутствие измерений, потеря актуальности
доказательств, защищённые пути, оба оформления и четыре ширины, фильтры,
клавиатура, восстановление обновления, XSS и сохранённый снимок, текст 200%.
Речь скринридера и физические устройства требуют отдельной приёмки.
