# Разбор отказов

## Страница не работает
Проверить ошибки браузера, пути файлов и подключение dk-theme первым, dk-util до компонентов; открыть showcase.html и повторить python3 tools/check.py.

## График/карта пусты
Проверить локальный ECharts, размеры контейнера, данные и сообщение ошибки; сверить README и REVIEW про нулевой размер. Не заменять отсутствие данных нулём.

## Регрессия фильтра
Запустить node tools/check-select.mjs; проверить сохранение фокуса/ввода, пустое состояние и сброс.

## Уязвимость или неверные реальные данные
Не публиковать секреты и детали уязвимости; приватный канал пока unknown. Данные приложения-хозяина требуют его владельца; не объявлять демо доказательством production.

## Откат
Подготовить revert проблемного изменения отдельным PR после воспроизведения; production-процедуру должен подтвердить оператор.
