# Главная и редактура кита · 29.10.2026

Это отчёт о первом проходе. По последующим замечаниям владельца изменены
каркас, эмодзи и отрисовка карточек; актуальные снимки и проверки —
[в актуальном проходе](../kit-header-mega/README.md). Публикация приостановлена.

Локальная ветка: `codex/kit-home-editorial-2026-10-29`, основана на локальном
`origin/main` (`4b8b913`, опубликованный PR61). Коммиты, push, PR, merge и deploy
не выполнялись. Управляемый слой и настройки AI Ops не изменены.

## Что сделано

1. **Главная — работает.** Выбранная композиция варианта 1: задача и основное
   действие слева, живые компоненты справа, три шага, четыре карточки с
   настоящими снимками, остальные примеры по раскрытию и отдельный справочник.
   [Тёмная тема](docs-index-dark-1280.png), [светлая](docs-index-light-1280.png),
   [телефон](docs-index-light-320.png).
2. **Создание — работает.** Форма принимает задачу, аудиторию, описание данных
   и ограничения. Готовый запрос содержит правила кита, проверку данных и
   границу демонстрационных значений. Работают валидация, сохранение черновика
   в сессии, копирование с объяснением отказа и скачивание TXT. Фактически
   скачанный `dashboard-task.txt` прочитан и содержит введённую задачу.
3. **Компоненты — отредактированы все 56.** Назначение, пример, выбор и
   сочетания идут до подробностей реализации. Адреса, классы и API сохранены.
   HTML, Markdown, поиск и опись обновлены из общих исходников. Короткое
   название «Из чего состоит» заменяет «Анатомия»; «С чем сочетать» находится
   до токенов и кода. Экспериментальный статус не скрыт.
4. **Связи и демонстрации — исправлены.** Плитка отсылает к существующему
   сравнению с целью; чип, бейдж и легенда различаются; карта описывает
   доступный список. Описание доступного имени графика соответствует dkChart.
   Убраны устаревший капс Graphite, обязательная карусель и произвольные
   количественные запреты. У плотности есть таблица для сравнения интервалов,
   у сохранённых видов — видимые служба и период для восстановления.
5. **Витрина и остальные страницы — просмотрены.** Упрощены пояснения витрины
   и сетки. Предметные данные и расчёты примеров сохранены. Встраивание
   намеренно демонстрирует независимость кита от оформления внешней страницы.
