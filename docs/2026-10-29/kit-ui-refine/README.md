# Эмодзи, каркас и полоса в превью · 29.10.2026

Это промежуточная итерация. [Текущая версия хедера и статичной иллюстрации](../kit-header-mega/README.md).

По новым замечаниям владельца. Публикация приостановлена; push, PR, merge и
развёртывание не выполнялись.

## Изменения

- Меню прижато к краю окна: убраны внешнее поле и центрирование общего
  контейнера. Ширина сайдбара 224 px, поля статьи сохранены. На широком экране
  измерено `nav.left = 0`; в выдвижном меню узкого экрана тоже `left = 0`.
- Эмодзи возвращены в 14 пунктов меню и добавлены в заголовки документации,
  шаги, примеры и справочник. Декоративные символы скрыты от скринридера.
  Классы и API рабочих компонентов не менялись.
- Полупрозрачные карточки документации используют существующие подложку,
  блик и край Graphite без живого `backdrop-filter`. На присланном скриншоте
  была видна прямоугольная граница внутри превью; после изменения она не
  наблюдалась в текущем IAB при смене карты/графика, размера окна и темы.
  Универсальная первопричина браузерного композитинга не объявляется доказанной.
- Карточки примеров компактнее. Две колонки первого экрана сохраняются от
  681 px, включая фактическую ширину панели владельца около 744 px. На
  телефоне остаётся одна колонка. Три шага собраны в общий горизонтальный ряд,
  на узком телефоне — вертикально.
- Выдвижное меню получает плотную поверхность: текст страницы не просвечивает
  через пункты меню. Само содержимое карточек сохраняет полупрозрачный материал.
