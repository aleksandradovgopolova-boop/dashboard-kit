## Порядок проверки и публикации

Публикационный commit содержит только разрешение и протокол, без новых
изменений интерфейса. PR и merge помечаются skip ci, сохраняя AI Ops STOP;
полный продуктовый dashboard-check (Chrome и MCP) запускается вручную для
точного head. После PASS — merge, сравнение деревьев и ручная GitHub Pages.
Итоги run, SHA и проверка публичных файлов добавляются по факту.

Managed-слой и настройки AI Ops не меняются. Выпускается сайт; версия SDK
и установленные потребители не продвигаются. Физические устройства,
Safari/Firefox и речь настоящего скринридера не проверены.
