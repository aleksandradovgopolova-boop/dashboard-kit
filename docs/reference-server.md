# Локальный сервер эталонного дашборда

`tools/reference-server.py` демонстрирует серверную фильтрацию, агрегацию,
пагинацию и создание поручений. Он использует стандартную библиотеку Python,
не требует установки пакетов и слушает только `127.0.0.1`.

```sh
python3 tools/reference-server.py --port 8772
```

Для CI `--port 0` выбирает свободный порт ОС; фактический адрес печатается
после запуска сервера.

Открыть: `http://127.0.0.1:8772/reference-dashboard.html?source=server`.
Сервер читает учебный `data/reference-dashboard.json` один раз при запуске.
Изменение файла требует перезапуска. Это демонстрация контракта, а не
production backend: здесь нет аутентификации, прав доступа, базы данных,
защищённого журнала действий или фоновой обработки задач.

## Данные

`POST /api/dashboard`, `Content-Type: application/json`:

```json
{
  "filters": {"region": ["Москва"], "service": []},
  "period": {"from": "2026-10-01", "to": "2026-10-20"},
  "page": 1,
  "pageSize": 20
}
```

Пустой массив фильтра означает все значения. Неизвестное значение даёт пустой
результат; неизвестный идентификатор фильтра — ошибку. `period: null` использует
весь период источника. Допустимый размер страницы — 1–100. Номер страницы
должен быть положительным безопасным целым JavaScript. Страница за концом
выборки возвращает пустые `rows`, сохраняя полные `rowCount`, `totals`, `series`.

Ответ соответствует серверному режиму [контракта данных](dashboard-data.md):

- `query` — нормализованный запрос;
- `rows` — только текущая страница;
- `rowCount` — число наблюдений во всём выбранном срезе;
- `totals` — показатели по всему срезу, независимо от страницы;
- `series` — ряд по датам, до 366 точек, с покрытием данных каждой метрики;
- `source`, `period`, `dimensions`, `metrics` — контекст и определения.

Сумма и среднее считаются только по известным значениям; `observed`, `total`
и `partial` явно показывают пропуски. Отсутствующие данные не превращаются
в нули. Для пустой выборки значение метрики — `null`, покрытие — 0 из 0,
`partial: false`. Даты запроса должны находиться внутри покрытия источника.

## Демонстрационное действие

`POST /api/tasks`, `Content-Type: application/json`, обязательный заголовок
`Idempotency-Key`, например UUID одной попытки пользователя:

```json
{"rowId": "observation-1", "sourceId": "reference-demo"}
```

Ответ `200`: `{ "id": "demo-task-1", "label": "…", "message": "…" }`.
Сообщение явно сообщает, что поручение демонстрационное. Повтор с тем же ключом
и телом возвращает тот же результат, в том числе при одновременных запросах.
Повтор с другим телом — `409`. Неизвестная строка — `404`, неверный источник
или ключ — `400`. Ключ: до 128 ASCII-символов, буквы, цифры, `.`, `_`, `:`, `-`.

Поручения существуют только в памяти процесса, максимум 1000. При перезапуске
они исчезают вместе с историей ключей. Сервер отвергает источник `kind: live`
для действий: подключение реальной системы требует отдельного адаптера,
авторизации, проверки доступа к объекту и устойчивого хранения idempotency key.

## Границы и проверки

Тело запроса ограничено 64 КиБ. Принимается только JSON с `Content-Length`,
без сжатия и `Transfer-Encoding`; повторные JSON-ключи отклоняются.
Неизвестные API-маршруты не выполняют действий. Ответы не кешируются, CORS
не включён. Все маршруты проверяют локальный `Host` и совпадающий `Origin`, если он
передан. Статическая раздача закрывает скрытые каталоги, пути наружу,
символьные ссылки и исходники инструментов. Тела запросов не записываются
в журнал. Эти меры ограничивают локальный пример, но не заменяют production
модель безопасности.

```sh
python3 tools/check-reference-server.py
```

Проверка не открывает порт: бизнес-функции и HTTP-обработчики вызываются
напрямую. Она использует 20 000 синтетических наблюдений, сравнивает агрегаты
между страницами, проверяет пропуски, пустую выборку, лимиты, повторные действия
и границы HTTP/файлов. Это не нагрузочный тест сервера, не замер браузерной
производительности и не доказательство готовности к миллионам записей.

При реальном объёме фильтрация, агрегация и пагинация выполняются на стороне
источника/базы данных; браузер получает ограниченную страницу и агрегаты.
Демонстрационная реализация читает учебный набор в память и служит образцом
ответа API, а не рекомендуемым хранилищем для production.
