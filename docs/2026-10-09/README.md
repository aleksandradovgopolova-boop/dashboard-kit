### 09.10.2026 — детализация выбранного референса и контроль предпросмотра

У обзорных KPI появились три миниграфика на существующих рядах аварий,
обращений и времени реакции. `dkChart` принимает `type: 'spark'` вместе
с `sparkStyle: 'bar'` и смысловым `tone: 'crit' | 'calm' | 'event'`.
Контейнер `.dk-tile__spark` отделяет миниграфик от числа и переносит его
на узком экране. Для показателей без истории миниграфики не придумываются.
`bar-h` с `palette: 'risk'` и двумя порогами `steps: [60, 78]` кодирует риск
по значению (calm/high/crit), а не по позиции округа. `forecastStyle: 'dashed'`
показывает прогноз пунктиром и пустыми кругами; обычный стиль остаётся доступным.

Таблица событий имеет пять колонок: время, событие, регион, статус, люди.
Её отдельный семантический стиль `--type-table-compact` — 10/16 px,
не новый размер основного текста кита. Светлый фон уточнён до `#EEF2F8`;
порог различимости поверхностей 1.12 не понижен, сайдбар сохранён.

При просмотре обнаружено кеширование CSS/JS старым сервером на порту 8770.
Для проверки актуальной версии используется сервер без кеширования на 8771;
сам факт открытия URL ещё не доказывает актуальность ресурсов. Визуальная
приёмка после исправлений остаётся открытой; сравнивать снимки при одинаковом
логическом размере и нормализованном DPR, отдельно от автоматических проверок.

Последние изменения миниграфиков, типографики и прогноза требуют финального
повторного прогона; предыдущий результат не удостоверяет эти последующие правки.
