# Иерархия сводки · 09.10.2026

Задача: при первом взгляде различить проблему, основные показатели и детали.
Пользователь выбрал оформление существующей сводки по предоставленному
референсу; её состав и левый сайдбар сохранены.

- Верхний баннер выделяет 23 аварии и переход к работе с ними.
- Четыре KPI используют крупную метрику при достаточной ширине карточки;
  на телефоне сохраняются полные названия и раскладка 2×2.
- Вторичные действия графика не конкурируют с данными; недоступные кнопки убраны.
- «Без изменений» имеет нейтральный цвет.
- Новые варианты banner/tile доступны в каталоге и манифесте. Остальные
  потребители компонентов не меняются автоматически.

UI-008/UI-014/UI-027/UI-041: приоритет выражен числом, порядком и семантическим
цветом; опасность подписана текстом. UI-001/UI-010: состав данных сохранён,
демонстрационный период виден, новые данные или выводы не придуманы.

Проверки: полный `python3 tools/test.py`; Chrome, 62 страницы в трёх размерах;
сводка 1366×768 в обеих темах, мобильные 320/390, промежуточные размеры,
переключение вкладок с клавиатуры, возвращение к обзору, увеличенный текст.
Дополнительная регрессия измеряет контраст действия приоритетного баннера
(не ниже 4.5:1) и крупного числа (не ниже 3:1). Сайдбар сравнен с исходной
разметкой; chrome.css и глобальные токены не менялись.

Скриншоты: [светлая сводка](overview-light.png), [тёмная сводка](overview-dark.png),
[телефон, светлая](phone-light.png), [телефон, тёмная](phone-dark.png).

Визуальное принятие пользователем ещё не получено.
