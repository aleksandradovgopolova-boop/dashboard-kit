## Руководства и примеры

| Страница | Итог прохода |

| showcase.html | Вход по задачам вместо ролей; понятные названия примеров; общая иерархия разделов. |

| dashboard.html | Убрано неподтверждённое утверждение о переходе между уровнями риска в карточке; числа сохранены. |
| mobile.html | Убрано неподтверждённое утверждение о переходе между уровнями риска; остальные сценарии сохранены. |
| family-mortgage.html | Единица бюджета приведена к порядку «млрд ₽»; показатели, фильтры и расчёты сохранены. |
| regions.html | Проверены заголовки, пороги и объяснение карты; содержательных изменений в этом проходе не требовалось. |
| accidents.html | Проверены заголовки показателей, графиков и таблицы; сценарий сохранён. |
| ai-value.html | Сохранены явные ограничения источника, тестовые значения и неизвестные определения; не скрывать ради краткости. |
| reference-dashboard.html | Сохранены границы демонстрации, подпись экспорта текущей страницы и объяснение среза. |

## Проверка перед выпуском

- `python3 tools/check.py --fast`: без нарушений.
- `node --check js/docs.js`: синтаксис корректен.
- `node tools/check-docs.mjs`: запуск заблокирован `listen EPERM` на 127.0.0.1.
- Остаётся проверить переносы, геометрию, работу примеров, клавиатуру и обе темы в браузере. Наличие обновлённого шаблона не доказывает визуальную приёмку всех страниц.
