# Архив визуальных экспериментов

Исходные изображения прежних раундов подбора оформления сохранены для истории.
Наличие файла не означает согласование или использование в продукте. Текущий
выбор — Graphite Dark/Light; Signature и последующие Apple-направления отвергнуты.
Используемые PNG-фоны находятся в `assets/graphite-dark.png` и
`assets/graphite-light.png`. Эти архивные изображения не входят в runtime-пакет.
