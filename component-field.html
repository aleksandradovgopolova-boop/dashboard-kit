✍️Поле и форма

Принимает текст, числа и другие данные; объясняет требования и помогает исправить ошибку.

Статус: стабильный ПримерКак выбратьС чем сочетатьКод и API

В работе

Подпись объясняет, что ввести, подсказка уточняет требования, ошибка помогает исправить значение. Введите данные и проверьте форму.

Когда использовать

Когда использовать
  • Нужно ввести текст, число или другие данные: название работы, количество жителей, комментарий.
  • Изменения проверяются и применяются по кнопке. Длинную форму лучше вынести на самостоятельную страницу.
Когда выбрать другое
  • Выбор значения из известного списка для среза данных — Фильтр: он применяется сразу.
  • Выбор дат — Период.
  • Подтверждение действия без ввода — Модальное окно.
Правила сочетания
  • Текст интерфейса
  • Микровзаимодействия
  • Размеры элементов
  • Проверка реального сценария
  • Текст для действия и восстановления

Из чего состоит

4Подсказка под полем
5Не короче 5 знаков — сейчас 3

  1. Сводка ошибок — dk-form__alarm над формой после неудачной отправки: сколько полей не заполнено.
  2. Подпись над полем — dk-label; пометка «обязательно» или «если известно» — у того, чего меньше.
  3. Поле — dk-field вокруг input или select: заливка вместо рамки; внутри пример значения, а не название.
  4. Подсказка — dk-hint: единица, формат, куда попадёт значение.
  5. Ошибка — dk-err под полем и aria-invalid на input: говорит, что сделать, а не что не так.
  6. Подвал — dk-form__foot: основная кнопка справа, обычная левее.

Варианты и размеры

Высота задаётся токеном контрола; не фиксируйте её поверх темы. Ширину задаёт сетка формы: dk-ff занимает половину строки, dk-ff--wide — всю строку. На телефоне сохраняйте удобную область ввода.

Класс или параметрЧто делаетКогда
dk-formФорма с сеткой полей.Всегда; внутри — dk-ff.
dk-ff / dk-ff--wideПоле в полстроки или во всю.Названия и комментарии — wide, числа и даты — половина.
dk-fieldОбёртка input или select.Все однострочные поля.
dk-field--searchПоле поиска со значком слева.Поиск по списку, не в форме.
dk-areaМногострочное поле.Комментарий, текст для рассылки.
dk-err + aria-invalidТекст ошибки под полем и пометка на input.Ставит dk-form.js; руками — только в статичном примере.

Состояния

Не короче 5 знаков — сейчас 3
Проверка не бьёт по рукам на каждом нажатии. Первая — когда человек ушёл из поля или отправил форму; после этого поле проверяется на каждое изменение, чтобы ошибка исчезла сразу, как исправлена.

Текст и подписи

Понятно
  • Подпись — название данных: «Затронуто жителей». Внутри поля — пример: «1240».
  • Ошибка говорит, что сделать: «Не короче 5 знаков — сейчас 3».
  • Подсказка отвечает на вопрос, который возникнет: «Человек, а не квартир».
  • Отмечено то, чего меньше: обязательные или необязательные, но не оба сразу.
Вызывает вопросы
  • Название данных плейсхолдером внутри поля — исчезает при вводе.
  • «Неверное значение», «Ошибка» — человек и так знает, что ошибся.
  • Звёздочка без расшифровки.
  • Кнопка «Отправить» — что именно произойдёт?

Доступность

  • Подписи. <label for> у каждого поля; подсказка и ошибка связаны через текст под полем и aria-invalid.
  • Фокус после ошибки уходит на первое неверное поле — форма, которая молча не отправилась, заставляет перечитывать её сверху.
  • Сводка над формой объявляется скринридеру как живой регион.
  • Клавиатура. Enter в поле отправляет форму; Escape ничего не сбрасывает — потерять набранное дороже, чем нажать «Очистить».

С чем сочетать

  • Флажок, радио, тумблер — выбор внутри формы
  • Фильтр — выбор из списка для среза, не для формы
  • Период — даты
  • Модальное окно — короткая форма в окне

Код и API

Разметка — обычная форма с браузерными правилами (required, minlength, min/max); dk-form.js добавляет тексты ошибок, сводку и фокус.

Исходники: css/components.css · js/dk-form.js

<form class="dk-form" id="work">
  <div class="dk-form__alarm" hidden></div>
  <div class="dk-ff dk-ff--wide">
    <label class="dk-label" for="name">Название работы <span class="dk-label__req">обязательно</span></label>
    <div class="dk-field"><input id="name" name="name" placeholder="Замена задвижки на вводе" required minlength="5"></div>
    <div class="dk-hint">Так её увидят диспетчеры смены</div>
  </div>
  <div class="dk-form__foot">
    <button type="submit" class="dk-btn dk-btn--primary">Добавить работу</button>
  </div>
</form>

<script>
var api = dkForm(document.getElementById('work'), {
  check: function (el) { /* своя проверка сверх браузерной; вернуть текст или null */ return null; },
  onSubmit: function (data) { /* data — FormData; форма прошла проверку */ }
});
api.validate();   // true, если всё верно
api.clear();      // снять ошибки
</script>

Параметры и методы

ПараметрТипЧто делает
onSubmit(data)функцияЗовётся только после успешной проверки; data — FormData.
check(el)функцияСвоя проверка поля поверх браузерной: вернуть текст ошибки или null.
validate()методПроверить все поля, показать ошибки; вернуть true/false.
clear()методСнять ошибки и сводку.
required, minlength, min, max, typeатрибуты inputПравила задаёт браузер; кит только формулирует ошибку по-русски.
