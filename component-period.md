# Период

Ограничить срез по времени: готовые пресеты или свой диапазон. Стоит первым среди фильтров, потому что ограничивает всё остальное.

## Когда использовать

- Данные на странице зависят от интервала времени.
- Обычно хватает пресетов, но иногда нужен произвольный диапазон.
- Период должен переноситься ссылкой.

## Когда выбрать другое

- Одна дата в форме (начало работы) — Поле с type="datetime-local".
- Показ работ по дням — Календарь: это не фильтр, а представление.
- Два–три фиксированных интервала без календаря — Сегмент «7 дней / 30 дней».

## Контент: так

- Пресет назван словами: «Последние 14 дней», «Сегодня».
- Свой диапазон — «11–24 сен», без года, если он текущий.
- Строка применённых фильтров называет период так же, как поле.

## Контент: не так

- «14д» в поле — это сокращение для сегмента, не для фильтра.
- «11.09.2026 – 24.09.2026» — восемь лишних знаков.
- Период по умолчанию не выбран: данные «за всё время» на дашборде — почти всегда ошибка.

## Доступность

- Роли. Поле — кнопка с aria-haspopup="dialog"; в aria-label — и название пресета, и точные даты.
- Клавиатура. По пресетам — стрелки, Enter; Escape закрывает меню и возвращает фокус. Календарь — клавиатура Air Datepicker.
- Не только цветом. Выбранный пресет отмечен aria-pressed; диапазон в календаре — заливкой и подписью в поле.
- Не проверялось. Календарь — сторонняя библиотека; её доступность со скринридером не измерялась (HANDOFF.md).

## Размеры

Высота как у фильтра: M по умолчанию, size: 'sm'. Календарь всегда 280 px шириной.

## Код

```html
<!-- Период — первым в строке фильтров: он ограничивает всё остальное. -->
<div class="dk-toolbar">
  <div class="dk-toolbar__group">
    <div id="period"></div>
    <div id="okrug"></div>
  </div>
</div>

<script>
var p = dkPeriod(document.getElementById('period'), {
  label: 'Период',
  value: { preset: 7 },              // или { from: '2026-09-11', to: '2026-09-24' }
  url: 'period',                      // ?period=14d | 2026-09-11..2026-09-24
  onChange: function (v) { /* v = { from: Date, to: Date, preset: 14|null } или null */ }
});
p.value; p.text;                      // «Последние 14 дней»
p.set({ preset: 30 }); p.clear();
</script>
```

## Параметры

- `value` ({preset} | {from, to}): Начальное значение; адрес главнее.
- `presets[]` (массив {name, days}): Свой список пресетов.
- `minDate / maxDate` (дата): Границы календаря; по умолчанию до сегодня.
- `url` (строка): Ключ в адресе.
- `onChange(v)` (функция): После применения; черновик не считается.
- `value / text / set(v) / clear()` (API): Читать и менять снаружи.
