# Вкладки

Помогают перейти между разделами одного уровня и показывают текущий раздел.

## Когда использовать

- Разделы одного уровня, у каждого свой адрес: «Обзор», «Записи», «Отчёты».
- При переходе меняется вся страница или её основная часть.
- Разделов от двух до шести — больше не помещается в строку на узком экране.

## Когда выбрать другое

- Переключение вида одних данных внутри виджета — Сегмент.
- Больше шести разделов — боковое меню каркаса (css/chrome.css).
- Действие, а не переход — Кнопка.

## Контент: так

- Существительное во множественном числе: «Обзор», «Записи», «Отчёты».
- Счётчик — число объектов, требующих действия, а не всего объектов в разделе.
- Порядок вкладок постоянный: люди запоминают положение, а не название.

## Контент: не так

- Глаголы: «Смотреть аварии».
- Счётчик «1 284» — это статистика, а не сигнал; ей место в разделе.
- Вкладка «Ещё…» с выпадающим списком — значит, разделов слишком много для вкладок.

## Доступность

- Роль.  со ссылками, а не tablist: это переходы между страницами, и скринридер должен ждать загрузку.
- Текущая — aria-current="page", скринридер объявляет «текущая страница».
- Клавиатура. Обычные ссылки: Tab и Enter. Кольцо фокуса — только при навигации табом.
- Контраст. Черта текущей вкладки — --control-on, тот же серый, что у выбранного управления: не ниже 3:1 к поверхности.

## Пример

Сравните активную вкладку, обычную ссылку и вкладку со счётчиком.

## Структура

- **Текущая вкладка** — aria-current="page": цвет текста ink, жирность и черта снизу цветом --control-on — двумя признаками, не одним.
- **Обычная вкладка** — ссылка  с адресом; при наведении подпись темнеет.
- **Счётчик** — dk-tab__n: сколько объектов в разделе ждут внимания. Ноль не показывается.

## Состояния

Текущая Обычная Фокус С счётчиком 7 Недоступных вкладок не бывает. Раздел, в который нельзя попасть, не показывают; если доступа нет — показывают страницу «Нет доступа» ( Состояния ), а не серую вкладку.

## Варианты

- `dk-tabs` — Строка вкладок,  с aria-label. Всегда.
- `dk-tab` — Вкладка-ссылка. На каждый раздел.
- `aria-current="page"` — Текущий раздел. Ровно у одной вкладки.
- `dk-tab__n` — Счётчик в вкладке. Когда в разделе есть что-то, требующее внимания.

## Размеры

Размер один: строка вкладок стоит под заголовком страницы и не бывает мельче текста. На узком экране строка листается вбок, вкладки не переносятся и не прячутся — спрятанная вкладка выглядит как отсутствующий раздел.

## Код

```html
<nav class="dk-tabs" aria-label="Разделы мониторинга">
  <a class="dk-tab" href="dashboard.html" aria-current="page">Сводка</a>
  <a class="dk-tab" href="accidents.html">Аварии <span class="dk-tab__n">23</span></a>
  <a class="dk-tab" href="calendar.html">Календарь</a>
</nav>
```

## Параметры

- `aria-current="page"` (атрибут): Текущий раздел.
- `dk-tab__n` (элемент): Счётчик; не показывать при нуле.
- `aria-label` (атрибут nav): Название группы разделов для скринридера.
