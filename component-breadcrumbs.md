# Навигационный путь

Показывает место объекта в иерархии и путь к родителю.

## Когда использовать

- Есть вложенные разделы или drill-down по объектам.

## Когда выбрать другое

- Один уровень навигации: используйте tabs.

## Контент: так

- Есть вложенные разделы или drill-down по объектам.
- Показывайте полные названия, единицы и источник данных.

## Контент: не так

- Один уровень навигации: используйте tabs.
- Не выдавайте отсутствие наблюдений за ноль и не используйте цвет как единственное объяснение.

## Доступность

- Ссылки доступны Tab и Enter, текущий объект не ссылка. На узком экране путь переносится; названия не обрезаются.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Размеры

Компонент следует ширине контейнера и системным токенам. Ссылки доступны Tab и Enter, текущий объект не ссылка. На узком экране путь переносится; названия не обрезаются.

## Код

```html
<nav class="dk-breadcrumbs" aria-label="Навигационный путь"><ol><li><a href="dashboard.html">Мониторинг</a></li><li><a href="regions.html">Регионы</a></li><li><span aria-current="page">Ивановская область</span></li></ol></nav>
```

## Параметры

- `aria-current="page"` (атрибут): Только последний пункт, текущий объект.
