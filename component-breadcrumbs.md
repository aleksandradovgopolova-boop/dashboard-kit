# Навигационный путь

Показывает положение объекта в иерархии и путь к родительскому разделу.

## Когда использовать

- Нужно видеть место объекта во вложенных разделах и возвращаться к родителю.

## Когда выбрать другое

- Разделы одного уровня — Вкладки.

## Контент: так

- «Мониторинг → Регионы → Ивановская область»: путь соответствует иерархии.

## Контент: не так

- «Назад → Далее»: не объясняет, где находится объект.

## Доступность

- Ссылки доступны Tab и Enter, текущий объект не ссылка. На узком экране путь переносится; названия не обрезаются.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Путь показывает, где открыт объект и как вернуться к родителю. Последний пункт — название текущего объекта, а не ссылка.

## Структура

- **Контекст** — Показывает положение объекта в иерархии и путь к родительскому разделу.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Ссылки ведут к родителям. Текущий объект остаётся последним пунктом без ссылки. Ограничения и подключение Состояния: родитель-ссылка и текущий объект. Нет JS API и внешних зависимостей.

## Варианты

- `aria-current="page"` — Разметка и параметры компонента. При задаче, описанной выше.

## Размеры

Путь переносится по ширине контейнера; названия остаются полными.

## Код

```html
<nav class="dk-breadcrumbs" aria-label="Навигационный путь"><ol><li><a href="dashboard.html">Мониторинг</a></li><li><a href="regions.html">Регионы</a></li><li><span aria-current="page">Ивановская область</span></li></ol></nav>
```

## Параметры

- `aria-current="page"` (атрибут): Только последний пункт, текущий объект.
