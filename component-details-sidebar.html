Варианты и размеры

Компонент следует ширине контейнера и системным токенам. Именованный dialog, Tab/Shift+Tab удерживаются, Escape закрывает, фокус возвращается. На телефоне занимает всю ширину. Содержимое прокручивается, фон недоступен.

Класс или параметрЧто делаетКогда
dkModal(el)Основной контракт API/markup.При задаче, описанной выше.

Состояния

Закрыто/открыто. Браузер должен поддерживать dialog.showModal; отсутствие поддержки не выдаётся за открытие. Общий API modal сохранён.

Контент

Так
  • Нужно сверить сведения об одном объекте с контекстом дашборда.
  • Показывайте полные названия, единицы и источник данных.
Не так
  • Подтверждение разрушительного действия: используйте обычный modal.
  • Не выдавайте отсутствие наблюдений за ноль и не используйте цвет как единственное объяснение.

Доступность

  • Именованный dialog, Tab/Shift+Tab удерживаются, Escape закрывает, фокус возвращается. На телефоне занимает всю ширину. Содержимое прокручивается, фон недоступен.
  • Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.
