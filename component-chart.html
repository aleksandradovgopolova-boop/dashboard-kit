График

Обёртка над ECharts, которая закрывает опасное и оставляет нужное: тема из токенов, «данных нет» вместо пустого прямоугольника, легенда от двух серий, линия порога, пунктир прогноза. Двух осей Y и сглаживания не будет.

стабильный код: js/dk-charts.js · js/dk-chart-theme.js · vendor/echarts.min.js

Живой пример

Четыре типа из одиннадцати: столбцы с линией нормы, линия с прогнозом, накопительные столбцы палитрой состояний, пончик с числом в центре. Остальные — на витрине.

Когда использовать

Когда использовать
  • Читатель должен увидеть динамику, сравнить величины, увидеть состав или долю — вопрос выбирает тип (таблица на витрине).
  • Есть ширина: график с осями живёт в M и L, в S — только спарклайн.
  • Значений на оси категорий до сорока; дальше это сырые данные, а не картинка.
Когда выбрать другое
  • Одно текущее значение — KPI-плитка, а не столбчатый график из одного столбца.
  • Больше семи значимых категорий — Таблица, а не ещё больше цветов.
  • «Где» на территории — Регионы.

Анатомия

Номера на схеме — те же, что в списке.

1Аварии по дням

2345
  1. Заголовок виджета — что и за какой период; единица — в подписи оси или в заголовке, не в каждой подписи.
  2. Ось значений — от нуля у столбцов всегда; шаг целый, если данные целые. У спарклайна оси нет.
  3. Линия порога — target: серый пунктир с подписью; ось её не обрезает.
  4. Прогноз — forecast: n: последние n точек пунктиром той же серии; в легенде отдельной строкой не стоит.
  5. Легенда — появляется от двух серий и стоит внизу, под тем, что объясняет.

Варианты и размеры

Высота — классами контейнера: dk-chart--sm 180, по умолчанию 220, --lg 340, --xl 440, --spark 48. Ширина — от сетки; график перестраивается при изменении ширины больше чем на десятую часть.

Пустое состояние с третьей строкой. «Данных нет» без «что делать» — тупик; обёртка по умолчанию отвечает на три вопроса, тексты меняются через empty.

Контент

Так
  • Заголовок виджета с периодом: «Аварии по дням · 14 дней».
  • Единица один раз: в заголовке или в подписи оси (unit).
  • До шести серий; седьмая повторит цвет первой, и обёртка предупредит в консоли.
  • Ноль на столбце подписан, если категорий до восьми; в плотном ряду ноль — промежуток.
Не так
  • Две оси Y — обёртка не соберёт.
  • Сглаженная линия — показывает значения, которых не было.
  • Красная серия «потому что третья»: красный означает «плохо».
  • Пончик из девяти секторов — обёртка свернёт хвост в «Прочее».

Доступность

  • Холст без текста. График — canvas; скринридер видит только заголовок виджета. Значения, которые важны, повторяются текстом: плитка, таблица, число в центре пончика (оно — элемент разметки).
  • Движение. Системная настройка «меньше движения» выключает анимацию графика.
  • Цвет. Палитра серий проверена на три вида дальтонизма (ПАЛИТРА); палитра состояний — на различимость смысла (СМЫСЛ).
  • Подсказка при наведении не заменяет текст: на таче и с клавиатуры её нет.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

Код

Подключать после echarts и dk-chart-theme.js. Контейнер с высотой; обёртка сама следит за темой и размером.

<div class="dk-chart" id="hours"></div>

<script>
var c = dkChart(document.getElementById('hours'), {
  type: 'bar',
  categories: ['00', '01', '02'],
  series: [{ name: 'Аварий', data: [1, 0, 2] }],
  target: { value: 4, label: 'норма' },
  unit: 'шт.',
  empty: { title: 'За сутки аварий не было', text: 'Ни одной записи.', hint: 'Расширьте период.' }
});
c.update({ series: [ … ] });   // перерисовать с новыми данными
c.instance;                    // экземпляр ECharts — в обход обёртки
c.destroy();                   // сторож похоронит и сам, когда узел уйдёт
</script>
ПараметрТипЧто делает

categories / series / dataмассивыДанные; у pie/donut — data, у sankey — nodes и links.
targetчисло | {value, label}Линия порога на графиках с осями.
palette: 'status'строкаЧетыре цвета состояния по порядку категорий.
highlight, forecast, trend, total, unit, labelsсм. вариантыМодификаторы типов.
labelстрокаЗаголовок для скринридера. Подпись из данных — крайние значения, доли, норма — дописывается сама.
