Когда использовать

Когда использовать
  • Нужно увидеть изменение, сравнить величины или понять состав. Тип графика выбирается по вопросу к данным.
  • Достаточно места для названий и осей. В маленьком блоке лучше оставить мини-график без осей.
  • Плотный ряд можно обобщить по периоду или открыть подробнее, сохранив доступ к точным значениям.
Когда выбрать другое
  • Одно текущее значение — KPI-плитка, а не столбчатый график из одного столбца.
  • Больше семи значимых категорий — Таблица, а не ещё больше цветов.
  • «Где» на территории — Регионы.
Правила сочетания
  • Масштаб и пропорции
  • Дашборд по вопросу пользователя
  • Иерархия без декоративного шума

Из чего состоит

1Аварии по дням

2345
  1. Заголовок виджета — что и за какой период; единица — в подписи оси или в заголовке, не в каждой подписи.
  2. Ось значений — от нуля у столбцов всегда; шаг целый, если данные целые. У спарклайна оси нет.
  3. Линия порога — target: серая сплошная линия с подписью; ось её не обрезает.
  4. Прогноз — forecast: n: последние n точек тонкой линией с ромбами и подписью «Прогноз»; в легенде отдельной строкой не стоит.
  5. Легенда — по умолчанию снизу; у donut с legendPosition: right при ширине от 320 px — справа со значениями.

Варианты и размеры

Высоту задаёт контейнер: dk-chart--sm, обычный, dk-chart--lg, dk-chart--xl или dk-chart--spark. Ширина приходит из сетки. Для осей и подписей нужен полноценный виджет, для небольшого KPI — мини-график.

Текст и подписи

Понятно
  • Заголовок виджета с периодом: «Аварии по дням · 14 дней».
  • Единица один раз: в заголовке или в подписи оси (unit).
  • До шести серий; седьмая повторит цвет первой, и обёртка предупредит в консоли.
  • Ноль на столбце подписан, если категорий до восьми; в плотном ряду ноль — промежуток.
Вызывает вопросы
  • Разные единицы без объяснимого сравнения.
  • Сглаживание приписывает данным ненаблюдавшиеся значения.
  • Красная серия обозначает обычную категорию вместо риска.
  • Слишком много секторов: сгруппируйте малые категории и сохраните их состав в деталях.

Доступность

  • Описание. dkChart формирует доступное имя из названия, категорий и значений. Задайте понятный label; для точного чтения большого ряда добавьте таблицу или текстовую сводку.
  • Движение. Системная настройка уменьшения движения отключает анимацию.
  • Цвет. Названия серий, подписи и значения дополняют палитру. Автоматическая проверка цветов не заменяет проверку реального экрана.
  • Подсказка. Наведение помогает изучать данные, но не должно быть единственным способом прочитать важное значение.

С чем сочетать

  • KPI-плитка — спарклайн в четверти колонки
  • Фильтры-легенда — легенда, которая ещё и фильтрует
  • Витрина: графики — все одиннадцать типов и таблица выбора
  • Список модулей ECharts — что собрано в урезанный движок

Код и API

Подключать после echarts и dk-chart-theme.js. Контейнер с высотой; обёртка сама следит за темой и размером.

Исходники: js/dk-charts.js · js/dk-chart-theme.js · vendor/echarts.min.js

<div class="dk-chart" id="hours"></div>

<script>
var c = dkChart(document.getElementById('hours'), {
  type: 'bar',
  categories: ['00', '01', '02'],
  series: [{ name: 'Аварий', data: [1, 0, 2] }],
  target: { value: 4, label: 'норма' },
  unit: 'шт.',
  empty: { title: 'За сутки аварий не было', text: 'Ни одной записи.', hint: 'Расширьте период.' }
});
c.update({ series: [ … ] });   // перерисовать с новыми данными
c.instance;                    // экземпляр ECharts — в обход обёртки
c.destroy();                   // сторож похоронит и сам, когда узел уйдёт
</script>
