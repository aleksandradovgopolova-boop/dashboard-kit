🎯Значение и цель

Сравнивает фактическое значение с целью и заданными диапазонами.

Статус: экспериментальный ПримерКак выбратьС чем сочетатьКод и API

В работе

Полоса показывает факт, метка — цель. Подписи позволяют оценить результат без опоры только на цвет.

Код примера ↗

Когда использовать

Когда использовать
  • Нужно сравнить одно значение с целью и оценить отклонение.
Когда выбрать другое
  • Изменение во времени — линейный график. Состав целого — график состава.

Из чего состоит

  1. Контекст — Сравнивает фактическое значение с целью и заданными диапазонами.
  2. Данные и действие — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

Варианты и размеры

Полоса занимает ширину контейнера; значения и цель доступны текстом.

Класс или параметрЧто делаетКогда
dkBullet(el, opts)Разметка и параметры компонента.При задаче, описанной выше.

Состояния

Факт и цель подписаны. Отсутствие значения нельзя заменять нулём.

Ограничения и подключение

Отсутствующий факт обозначается текстом и нейтральной заливкой; отсутствующая цель не рисуется. Факт вне шкалы визуально ограничивается, полное число остаётся в тексте. max должен быть больше min.

Текст и подписи

Понятно
  • «Факт 72%, цель 90%»: обе величины имеют одну единицу.
Вызывает вопросы
  • Полоса без подписанной цели и границ шкалы.

Доступность

  • Факт, цель и шкала написаны словами. Декоративная полоса aria-hidden. Горизонтальная полоса работает без hover и не является контролом.
  • Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

С чем сочетать

  • Таблица — точные числа
  • Подключение — dk-theme первым, dk-util до компонента
