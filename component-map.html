Регионы: карта и плитки

Два вида на одних данных. Карта отвечает «где», плитки — «у кого хуже»: на карте площадь региона перебивает его значение. Переключатель — часть виджета, а не настройка.

стабильный код: js/dk-map.js · data/regions.topojson · data/regions-tiles.json

Живой пример

89 регионов, шкала одного тона от светлого к тёмному, «нет данных» серым и в легенде. Переключите на плитки — по ним ходят стрелками.

Когда использовать

Когда использовать
  • Показатель задан по регионам, и важно «где» — карта.
  • Важно сравнить регионы между собой равным весом — плитки.
  • Нужен доступ с клавиатуры — плитки: карта нарисована на canvas.
Когда выбрать другое
  • Топ-5 регионов — Рейтинг.
  • Несколько показателей на регион — Таблица.
  • Динамика одного региона — График.

Анатомия

Номера на схеме — те же, что в списке.

1

  1. Переключатель — сегмент «карта / плитки»; в виджете с шапкой сам встаёт в неё справа, иначе — своя строка над картой.
  2. Плитка — кнопка с сокращением и значением; заливка — ступень шкалы через --fill.
  3. Значение в плитке — стоит в самой плитке, не только в подсказке: подсказку не получить ни пальцем, ни с клавиатуры.
  4. Нет данных — серый --nodata и прочерк — отдельная категория, а не ноль.
  5. Легенда — внизу, под тем, что объясняет: пороги названы числами, единица справа.

Варианты и размеры

Размер один: карта 420 px высотой (280 на узком экране), плитки 19×11 клеток по ширине виджета. Виджет — L: в половине колонки карта нечитаема.

Состояния

Карта не загрузилась
Контуры регионов не пришли.
Откройте страницу по http, а не двойным кликом.
Без контуров карта сама переключается на плитки, если они есть; без плиток — честное «плитки не загрузились». Контейнер без размера карту не роняет: она ждёт размера и дорисовывается (проверка НОЛЬ).

Контент

Так
  • Пороги в легенде числами: «55–68», не «средне».
  • Единица измерения один раз, справа от легенды.
  • Сокращения регионов из файла раскладки — постоянные.
Не так
  • Радуга вместо лестницы одного тона.
  • Ноль вместо «нет данных».
  • Карта без переключателя на плитки — без мыши данных не получить.

Доступность

  • Плитки — кнопки с aria-label «регион · значение»; по сетке ходят стрелками, tabindex один на всю сетку.
  • Карта недоступна с клавиатуры (canvas) — поэтому плитки обязательны, а не опция.
  • Шкала — пять ступеней, все видны на своей доске в обеих темах (проверка ШКАЛА).
  • «Нет данных» в тёмной теме 1,69:1 к поверхности — ниже нормы; открыто в HANDOFF.md (ровная заливка и подпись «Нет данных»).

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

Код

Данные подаются объектами: на file:// fetch запрещён браузером, и виджет, который сам лезет за файлом, на двойной щелчок не открылся бы.

<div class="dk-widget">
  <div class="dk-widget__head"><h3 class="dk-widget__title">Регионы</h3></div>
  <div id="regions"></div>
</div>

<script>
var m = dkMap(document.getElementById('regions'), {
  topo: topojson, object: 'ru89',      // контуры
  tiles: tilesJson,                    // раскладка плиток
  values: { 'RU-CR': 82, 'RU-NVS': 73 },
  unit: 'баллов риска',
  // controls не нужен: в виджете с шапкой переключатель встанет туда сам
  onSelect: function (id, value) { }
});
m.view = 'tiles';
m.setValues(next);                     // шкала пересчитается
</script>
