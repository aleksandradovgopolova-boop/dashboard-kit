Счётчик

Количество объектов внутри кнопки, вкладки или строки меню.

стабильный код: css/components.css

Когда использовать

Когда использовать
  • Количество объектов внутри кнопки, вкладки или строки меню.
Когда выбрать другое
  • Главное число дашборда — KPI-плитка.
  • Состояние объекта — статус с текстовой подписью.

Анатомия

Номера на схеме — те же, что в списке.

  1. Содержимое — Подпись и значение доступны без цвета.
  2. Контекст — Находится рядом с объектом, к которому относится.

Варианты и размеры

S — 16, M — 20 пикселей по высоте. Ширина растёт с числом; счётчик не является отдельной кнопкой.

Состояния

Пусто0Один объект1Большое количество99+

Контент

Так
  • Только число: 12; для больших значений — 99+ с точным доступным именем.
  • Название объекта находится рядом: «Сообщения 12».
Не так
  • Слово «новое» внутри счётчика — это бейдж.
  • Цвет ошибки для обычного количества объектов.

Доступность

  • Внутри подписанной кнопки число входит в её доступное имя.
  • Для 99+ укажите точное число и объект в aria-label.
  • Ноль показывайте только если отсутствие объектов важно для решения; скрытие счётчика не должно менять размер кнопки.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

HTML и общие стили кита. Изменение данных выполняет приложение.
