# Аккордеон

Раскрывает дополнительные сведения по запросу: определения, настройки и пояснения.

## Когда использовать

- Дополнительные сведения, которые не нужны при первом просмотре.
- Несколько самостоятельных вопросов или групп настроек.

## Когда выбрать другое

- Ключевые показатели и ошибки должны быть видны сразу.
- Переход между страницами — навигация, а не аккордеон.

## Контент: так

- Заголовок называет содержимое: «Как считается конверсия?».
- Краткий ответ без повторения заголовка.

## Контент: не так

- Заголовок «Подробнее» у всех разделов.
- Кнопка или ссылка внутри summary; разместите действия в раскрываемой части.

## Доступность

- Нативные details/summary обеспечивают клавиатуру и состояние раскрытия; не добавляйте им role="button".
- Не ставьте aria-hidden на содержимое вручную: браузер управляет доступностью скрытой части.
- Фокус остаётся на summary при раскрытии и закрытии.

## Пример

Откройте и закройте раздел с клавиатуры или нажатием на заголовок.

## Структура

- **summary** — Весь заголовок — одна цель раскрытия.
- **Стрелка** — Поворачивается при раскрытии; декоративна для скринридера.
- **Содержимое** — Находится внутри details, скрывается браузером.

## Состояния

Как считается конверсия? Число заказов / число посещений × 100%. Закрытый раздел Подробности.

## Варианты

- `dk-fold` — На нейтральной поверхности. Самостоятельный блок.
- `dk-fold--plain` — Без заливки. Раздел внутри страницы.
- `details name="metric-definitions"` — Одинаковое name у соседних details. Только один раздел открыт одновременно в современных браузерах.

## Размеры

Заголовок минимум 44 пикселя по высоте. Содержимое определяет высоту открытого блока.

## Код

```html
<details class="dk-fold "><summary class="dk-fold__head"><span class="dk-fold__title">Как считается конверсия?</span><svg class="dk-i dk-i--sm" aria-hidden="true"><use href="#ti-chevron-down"/></svg></summary><div class="dk-fold__body">Число заказов / число посещений × 100%.</div></details>
```

## Параметры

- `open` (HTML-атрибут): Раздел открыт.
- `name` (HTML-атрибут): Общее имя для группы с одним открытым разделом.
- `dk-fold--plain` (класс): Вариант без заливки.
