# Модальное окно

Помогает выполнить короткую задачу или подтвердить действие, сохраняя контекст страницы.

## Когда использовать

- Действие необратимо или дорого: удалить запись, удалить срез — нужно подтверждение своими словами.
- Короткая форма из одного–трёх полей, после которой человек возвращается туда же.
- Нужно остановить всё остальное, пока не решено.
- Быстрый обзор региона: 3–5 ключевых метрик, одна короткая таблица и возврат к исходному срезу.

## Когда выбрать другое

- Большой объём данных, сложные сравнения или длительная работа с регионом — отдельная страница дашборда с сохранённым контекстом; не растягивать модалку и не добавлять бесконечные вкладки.
- Длинная форма — отдельная страница или форма в панели.
- Уведомление о результате — Уведомление.

## Контент: так

- Заголовок и кнопка подтверждения — одно и то же действие: «Удалить запись».
- Текст — последствие: «Запись будет удалена без возможности восстановления».
- «Отмена» — всегда так, слева, тихая.

## Контент: не так

- «Вы уверены?» — не говорит, в чём.
- «ОК / Отмена» — что сделает «ОК»?
- Крестик как единственный способ закрыть без решения.

## Доступность

- Ловушка фокуса, фон недоступен, возврат фокуса на кнопку-открыватель — делает .
- Escape закрывает ровно один слой: открытый внутри окна список закрывается первым, окно с заполненной формой остаётся.
- Заголовок связан через aria-labelledby.
- Не проверялось со скринридером; в старых браузерах без showModal окно не откроется и напишет ошибку.

## Пример

Окно помогает решить короткую задачу и вернуться к исходному действию. В примере можно открыть его, закрыть и проверить возврат фокуса.

## Структура

- **Заголовок** — в подтверждении — действие, в краткой детализации — полное название объекта и его контекст.
- **Текст** — последствие простыми словами: что произойдёт после «да».
- **Подвал** — тихая «Отмена» слева, основная справа; порядок один во всём ките.
- **Подтверждение** — называет действие своим именем — не «ОК» и не «Да»; value кнопки возвращается через returnValue.

## Состояния

Окно с ожиданием Сохраняем срез Сохраняем Отмена Сохраняем… Второе окно не открывается поверх первого. Если решение требует второго решения, второе живёт внутри первого окна. Попытка открыть второе закрывает первое и пишет предупреждение в консоль.

## Варианты

- `dk-modal--detail / dk-modal__metrics` — Краткая детализация: компактная шапка, период и обновление, 3–5 равных КПЭ, основной контент, пояснение и реальные действия. Стандартная ширина до 800 px, с dk-modal--wide до 960 px; max-height 90dvh. На телефоне — fullscreen, поля 16 px, шапка и действия доступны при внутренней прокрутке. Быстрый обзор без длительного анализа; вкладки только при необходимости, отсутствие данных отличается от нуля.
- `dk-modal` — Окно на . Всегда.
- `dk-modal--wide` — Широкое окно. Форма в две колонки, таблица.
- `form method="dialog"` — Закрытие кнопками без скрипта. Всегда: value кнопки — результат.
- `data-modal="#id"` — Кнопка-открыватель. Соглашение страниц кита; dkModal вешает клик сама или страница.

## Размеры

Два размера: по умолчанию до 520 px, dk-modal--wide до 880 — для формы в две колонки. Высота по содержимому, тело прокручивается само.

## Код

```html
<button class="dk-btn dk-btn--primary" data-modal="#confirm">Удалить запись</button>

<dialog class="dk-modal" id="confirm" aria-labelledby="confirm-t">
  <form method="dialog" class="dk-modal__form">
    <div class="dk-modal__head"><h2 class="dk-modal__title" id="confirm-t">Удалить запись</h2><button type="button" class="dk-iconbtn dk-modal__close" data-modal-close aria-label="Закрыть окно" title="Закрыть"><svg class="dk-i" aria-hidden="true"><use href="#ti-x"/></svg></button></div>
    <div class="dk-modal__body"><p>Запись будет удалена без возможности восстановления.</p></div>
    <div class="dk-modal__foot">
      <button class="dk-btn dk-btn--ghost" value="cancel">Отмена</button>
      <button class="dk-btn dk-btn--primary" value="ok">Удалить запись</button>
    </div>
  </form>
</dialog>

<script>
var m = dkModal('#confirm');
button.addEventListener('click', m.open);
m.el.addEventListener('close', function () { if (m.returnValue === 'ok') closeAccident(); });
</script>
```

## Параметры

- `dkModal(el | селектор)` (функция): Обёртка над dialog; null, если окна нет.
- `open()` (метод): Открыть; предыдущее окно закроется с предупреждением.
- `close(value)` (метод): Закрыть с результатом.
- `returnValue` (свойство): value нажатой кнопки; пусто при Escape.
- `el` (свойство): Сам  — на него вешают close.
