# Боковые детали

Открывает подробности объекта рядом с текущим срезом данных.

## Когда использовать

- Нужно сверить сведения об одном объекте с контекстом дашборда.

## Когда выбрать другое

- Подтверждение разрушительного действия: используйте обычный modal.

## Контент: так

- Название выбранного объекта и его данные в текущем срезе.

## Контент: не так

- Общие итоги страницы под заголовком отдельного объекта.

## Доступность

- Именованный dialog, Tab/Shift+Tab удерживаются, Escape закрывает, фокус возвращается. На телефоне занимает всю ширину. Содержимое прокручивается, фон недоступен.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Откройте детали региона, затем закройте панель и вернитесь к исходному действию.

## Структура

- **Контекст** — Детали выбранного объекта без перехода с текущего среза.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Закрыто/открыто. Браузер должен поддерживать dialog.showModal; отсутствие поддержки не выдаётся за открытие. Общий API modal сохранён.

## Варианты

- `dkModal(el)` — Основной контракт API/markup. При задаче, описанной выше.

## Размеры

На широком экране панель стоит сбоку, на телефоне занимает доступную ширину. Длинное содержимое прокручивается.

## Код

```html
<button type="button" class="dk-btn" data-modal="#advanced-details">Детали региона</button><dialog class="dk-modal dk-sidebar" id="advanced-details" aria-labelledby="advanced-details-title"><div class="dk-modal__body"><h2 id="advanced-details-title">Ивановская область</h2><p>Риск: 92 из 100. Порог высокого риска: 78.</p><form method="dialog"><button class="dk-btn" type="submit">Закрыть</button></form></div></dialog>
```

## Параметры

- `dkModal(el)` (существующий API): open(), close(value), returnValue; sidebar — вариант modal, отдельного контроллера нет.
