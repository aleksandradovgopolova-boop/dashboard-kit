Флажок, радио, тумблер

Три способа сказать «да»: флажок — независимое «да / нет» по кнопке, радио — один из немногих, тумблер — режим, который срабатывает сразу. Отмеченное показано серым, не акцентом.

стабильный код: css/components.css

Живой пример

Подпись всегда кликабельна: попасть в квадратик 18 пикселей тяжело, в строку с текстом — легко.

Когда использовать

Когда использовать
  • Флажок: несколько независимых «да / нет», которые применяются по кнопке — например, в форме.
  • Радио: один вариант из двух–пяти, все видны сразу.
  • Тумблер: режим, который включается сразу и сразу виден — «Слой событий» на карте.
Когда выбрать другое
  • Больше пяти вариантов — Фильтр.
  • Переключение вида — Сегмент.
  • Тумблер в форме, которую надо сохранять, — обман: человек переключил, ушёл, ничего не сохранилось. Там флажок.

Микровзаимодействия

  • Для действия описать триггер, изменение состояния, обратную связь и повторное использование.
  • Выбор виден сразу; исправление снимает ошибку; после успешного сохранения виден результат. Предварительное подтверждение — только по риску действия.
  • Отдельные взаимодействия не должны сбрасывать ввод, переносить фокус неожиданно или создавать поток уведомлений.

Пример: Выбранное значение видно в контроле; связанные данные согласованно обновлены.

Проверка: Повторить действие, исправить ошибку и проверить последовательность состояний.

Размеры элементов

  • Размеры берутся из токенов кита; контроли одной строки имеют согласованную высоту.
  • Различать CSS-пиксели, физические пиксели и платформенные dp/pt; не умножать CSS-размеры на плотность экрана.
  • На таче цели минимум 44px по политике проекта; кнопки-значки квадратные. Не уменьшать шрифт ради вместимости.

Пример: Перестроить сетку, сохранить читаемость и достаточную область нажатия.

Проверка: Проверить реальные размеры цели, 320px, 200% текст и соседние действия.

Выбор значений

  • Checkbox — независимый множественный выбор; radio — один из вариантов; switch — немедленное включение настройки.
  • Короткий переключатель представления — segment; длинный справочник — select с поиском; иерархия справочника — tree-select.
  • Название, текущий выбор и недоступность понятны; выбор не должен неожиданно отправлять всю форму.

Пример: «Службы» с несколькими выбранными значениями; один вид карты выбирается сегментом.

Проверка: Проверить выбранное, пустое, mixed когда применимо, disabled, поиск и клавиатуру.

Анатомия

Номера на схеме — те же, что в списке.

  1. Настоящий input — скрыт, но живой: клавиатура, формы и скринридер работают через него.
  2. Квадрат с галочкой — dk-check__box: пустой — поверхность третьего уровня, отмеченный — серый --control-on с галочкой. Отличие ещё и формой, не только заливкой.
  3. Круг радио — dk-check--radio: форма говорит «только одно»; точка внутри цветом подписи.
  4. Дорожка тумблера — dk-switch__track: включённый — серый, выключенный — поверхность.
  5. Подпись — часть <label>, поэтому кликабельна целиком.

Варианты и размеры

Размер один: квадрат 18, тумблер 36×18. Мельче — не попасть пальцем, крупнее — контрол спорит с текстом.

Состояния

Частичное — не «ничего». Черта в шапке списка значит «выбрана часть»; галочка означала бы «все», и это было бы неправдой.

Контент

Так
  • Подпись — утверждение, которое становится правдой при отметке: «Показывать события».
  • У радио первый вариант — тот, что по умолчанию.
  • Недоступный вариант остаётся виден с пояснением: «Архив (недоступен)».
Не так
  • Отрицание в подписи: «Не показывать события» — двойное отрицание при снятии.
  • Вопрос вместо утверждения: «Показывать события?».
  • Тумблер «Сохранить настройки» — тумблер ничего не сохраняет, он включает.

Доступность

  • Настоящие input. Флажок и радио — <input> внутри <label>: клавиатура, формы и скринридер бесплатно.
  • Тумблер — тот же checkbox с другим видом; скринридер читает «флажок», и это честно: семантика та же.
  • Частичное состояние ставится и в input.indeterminate, и классом — первое для скринридера, второе для глаза.
  • Контраст. Отмеченный квадрат к поверхности 4,07:1 в тёмной и 5,04:1 в светлой теме; галочка на нём 4,79 / 5,04 (проверка ТИШИНА).

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

Код

Обычная разметка форм; скрипт не нужен. Для «выбрать все» в таблице — dkTable.

<label class="dk-check">
  <input type="checkbox" name="events" checked>
  <span class="dk-check__box"><svg class="dk-i"><use href="#ti-check"/></svg></span>
  Показывать события
</label>

<label class="dk-check dk-check--radio">
  <input type="radio" name="period" value="7" checked>
  <span class="dk-check__box"></span>
  7 дней
</label>

<label class="dk-switch">
  <input type="checkbox" name="layer">
  <span class="dk-switch__track"><span class="dk-switch__knob"></span></span>
  Слой событий
</label>
