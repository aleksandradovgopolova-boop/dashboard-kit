Доступность служб

Полоса из делений по времени: работала служба или нет. Легенда стоит всегда, а не только когда появился сбой, и «нет данных» не притворяется «работает».

стабильный код: css/components.css · js/dk-uptime.js

Живой пример

Три службы, сутки по получасу. Последние деления — «нет данных»: замер ещё не пришёл.

Когда использовать

Когда использовать
  • Служба либо работает, либо нет, и важно, когда именно не работала.
  • Несколько служб сравнивают по одной шкале времени.
  • Период — сутки или неделя с равными делениями.
Когда выбрать другое
  • Значение, а не да/нет, во времени — График.
  • Доля выполненного — Прогресс.
  • Событие с длительностью и описанием — Календарь.

Анатомия

Номера на схеме — те же, что в списке.

1Телеметрия сетей2396%
424 ч назадсейчас
5легенда: работает · сбой · нет данных
  1. Название службы — слева, одной строкой.
  2. Полоса делений — dk-uptime__strip: одно деление — один шаг времени; цвет состояния: работает, сбой, нет данных. Углы прямые: деление — это интервал, а не плитка.
  3. Доступность — процент рабочих делений от известных; «нет данных» в знаменатель не входит.
  4. Ось — подписи краёв: откуда и докуда.
  5. Легенда — всегда, даже когда сбоев нет: в момент первого сбоя человек увидит новый цвет и должен знать, что он значит.

Варианты и размеры

Размер один: полоса тянется по ширине виджета, деление — доля ширины. Делений до 96 (неделя по два часа); мельче не попасть курсором за подсказкой.

Класс или параметрЧто делаетКогда
rows[].dataМассив состояний: 'up' | 'down' | 'none'.Каждая служба.
stepПодпись шага: «30 минут».Идёт в подсказку деления.
labelsПодписи краёв оси.['24 ч назад', 'сейчас'] по умолчанию иначе.

Состояния

Неизвестное состояние — это «нет данных». Значение вне трёх известных не даёт невидимого деления и подписи «undefined»: оно рисуется как отсутствие данных и считается так же.

Контент

Так
  • Название службы так, как её зовут дежурные: «Приём заявок».
  • Подпись шага и краёв оси словами: «30 минут», «24 ч назад».
  • Процент — от известных делений.
Не так
  • Зелёная полоса там, где замеров не было.
  • Легенда, которая появляется только при сбое.
  • 100% при половине делений «нет данных».

Доступность

  • Полоса фокусируема и описана целиком в aria-label: сколько делений с перебоями.
  • Не только цветом. Легенда со словами; процент числом.
  • Подсказка у деления — title: время и состояние.
  • Контраст. Три цвета делений различимы между собой в обеих темах — проверка СМЫСЛ.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

Код

Контейнер пустой; данные — массив строк.

<div id="uptime"></div>

<script>
var u = dkUptime(document.getElementById('uptime'), {
  step: '30 минут',
  labels: ['24 ч назад', 'сейчас'],
  rows: [
    { name: 'Приём заявок', data: ['up', 'up', 'down', 'up', 'none'] }
  ]
});
u.setRows(newRows);
</script>

Связанное
