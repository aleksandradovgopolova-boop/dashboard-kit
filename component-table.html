Когда использовать

Когда использовать
  • Нужно сравнить объекты по нескольким признакам и прочитать точные значения.
  • Сортировка помогает найти отклонения, выбор строк — выполнить общее действие.
  • На телефоне важные поля остаются видимыми; остальные доступны в карточке строки или горизонтальной прокрутке.
Когда выбрать другое
  • Один показатель по многим объектам — Рейтинг.
  • Несколько главных чисел — KPI-плитки.
  • Изменение во времени — График.
  • События с коротким описанием — Список.
Правила сочетания
  • Пространство
  • Проверка реального сценария
  • Таблицы для чтения и сравнения

Новосибирская областьВ работе73

  1. Колонка выбора — флажок «все на странице» и по флажку на строку. Выбрано — не только заливкой, но и числом в строке действий.
  2. Заголовок колонки — надписью, поверхностью отделён от тела. Границ нет.
  3. Сортировка — стрелка показывает, куда отсортировано, а не «здесь можно». Скринридеру то же говорит aria-sort.
  4. Числовая колонка — dk-td-num: вправо, табличными цифрами (--font-num), единица в заголовке.
  5. Главная ячейка — название; при нужде с подстрокой и значком (dk-td-main).
  6. Статус — всегда со значком и подписью, никогда одним цветом.
  7. Значение — цвет смысла только у чисел, которые сравнивают с порогом.
  8. Группа — строка dk-tr-group: название надписью, подытог числом.
  9. Итог — <tfoot>, в закреплённой таблице прилипает к низу.

Варианты и размеры

Ширина зависит от колонок. На узком экране таблица прокручивается внутри своей области. Плотность можно менять компонентом «Плотность данных», сохраняя текст и области нажатия.

Класс или параметрЧто делаетКогда
dk-tableБез разделителей: шапка поверхностью, строки наведением.По умолчанию.
dk-table--zebraЧередование строк полупрозрачной заливкой.Длинная плотная таблица.
dk-table--cardsНа телефоне строка — карточка «подпись — значение», шапка — пилюли сортировки. Нужен dkTable: он ставит подписи.Таблица шире экрана телефона: больше трёх колонок.
dk-table--ruledВолосяные линейки между строками.Печать и очень плотные данные; включается вручную.
dk-table--sticky-headШапка и итог закреплены при прокрутке.Обёртка dk-tablewrap--tall с --table-max.
dk-table--sticky-colПервая колонка (и колонка выбора) закреплены.Колонок больше, чем помещается.
dk-tablewrapГоризонтальная прокрутка; --table-min — минимальная ширина.Всегда, если колонок больше четырёх.

Текст и подписи

Понятно
  • Единица — в заголовке колонки: «События, шт.», в ячейках только числа.
  • Нет значения — прочерк «—». Ноль — это ответ, отсутствие — нет.
  • Числа через dkFmt: разряды неразрывным пробелом, дробь запятой, минус настоящий.
  • Дельта со знаком всегда: «+4», «−8 мин».
  • Заголовки короткие, именительный падеж: «Регион», «Балл».
Вызывает вопросы
  • «73 события» в каждой ячейке — единица повторяется сорок раз.
  • Пустая ячейка или «0» вместо отсутствующего значения.
  • «1240» рядом с «1 240» — читается как два разных числа.
  • Цвет статуса без значка и подписи — его видят не все.
  • Действия, спрятанные под наведение, — на тачскрине наведения нет.

Доступность

  • Клавиатура. Заголовок с сортировкой — кнопка, флажки — настоящие input; кольцо фокуса только при навигации табом.
  • Роли. Настоящая <table>: скринридер ходит по ячейкам сам. Сортировка — aria-sort; выбранная строка — aria-selected.
  • Подписи. У каждого флажка свой aria-label с названием строки; у колонки действий — скрытый заголовок.
  • Контраст. Заголовок на своей поверхности и числа на строке проверяются в обеих темах (КОНТРАСТ, СТУПЕНИ).
  • Не проверялось. Живой скринридер и тач-устройства — как и у всего кита.

С чем сочетать

  • Рейтинг — один показатель по многим объектам
  • Бейдж и статус — что стоит в ячейках
  • Фильтр — что стоит над таблицей
  • Пагинация — как листать длинную таблицу
  • Страница «Аварии» — таблица в живом дашборде

Код и API

Разметка остаётся разметкой: без скрипта таблица показывает данные, просто не сортируется. Ширины колонок объявляет первый ряд <th>.

Исходники: css/components.css · js/dk-table.js

<div class="dk-tablewrap dk-tablewrap--tall" style="--table-min:860px;--table-max:420px">
  <table class="dk-table dk-table--zebra dk-table--sticky-head dk-table--sticky-col" id="regions">
    <thead><tr>
      <th class="dk-th-pick"><label class="dk-check" aria-label="Выбрать все на странице">
        <input type="checkbox" data-pick-all><span class="dk-check__box">…</span></label></th>
      <th style="width:24%" data-sortable="Регион">Регион</th>
      <th style="width:12%" class="dk-td-num" data-sortable="Балл">Балл</th>
    </tr></thead>
    <tbody>
      <tr data-id="RU-CR">
        <td class="dk-td-pick">…<input type="checkbox" data-pick value="RU-CR">…</td>
        <td>Крым</td>
        <td class="dk-td-num" data-sort="82">82</td>
      </tr>
      <tr class="dk-tr-group"><td colspan="2">Сибирский округ</td><td class="dk-td-num">73</td></tr>
    </tbody>
    <tfoot><tr><td></td><td>Итого</td><td class="dk-td-num">155</td></tr></tfoot>
  </table>
</div>

<script>
var t = dkTable(document.getElementById('regions'), {
  onSelect: function (ids) { /* выбрано видно числом: ids.length */ },
  onSort:   function (e)   { /* e.column, e.dir — если сортирует сервер */ }
});
t.selected; t.clear();
</script>

Параметры и методы

ПараметрТипЧто делает
onSelect(ids)функцияПри каждой смене выбора с массивом data-id.
onSort(e)функцияПередан — таблица не сортирует сама, а сообщает e.column и e.dir.
data-sortableатрибут thИмя колонки для сортировки.
data-sortатрибут tdЗначение для сортировки, когда текст ячейки — не оно.
--table-min, --table-maxпеременные на обёрткеМинимальная ширина и высота прокрутки; по умолчанию 720 и 480.
update({selected}) / destroy()APIВосстановление выбора по data-id; cleanup обработчиков/observer без удаления таблицы. Sort host связывает через onSort.
