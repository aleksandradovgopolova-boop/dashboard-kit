# Флажок, радио, тумблер

Флажок выбирает независимое значение, радио — один вариант, тумблер сразу меняет режим.

## Когда использовать

- Флажок: несколько независимых «да / нет», которые применяются по кнопке — например, в форме.
- Радио: один вариант из двух–пяти, все видны сразу.
- Тумблер: режим, который включается сразу и сразу виден — «Слой событий» на карте.

## Когда выбрать другое

- Больше пяти вариантов — Фильтр.
- Переключение вида — Сегмент.
- Тумблер в форме, которую надо сохранять, — обман: человек переключил, ушёл, ничего не сохранилось. Там флажок.

## Контент: так

- Подпись — утверждение, которое становится правдой при отметке: «Показывать события».
- У радио первый вариант — тот, что по умолчанию.
- Недоступный вариант остаётся виден с пояснением: «Архив (недоступен)».

## Контент: не так

- Отрицание в подписи: «Не показывать события» — двойное отрицание при снятии.
- Вопрос вместо утверждения: «Показывать события?».
- Тумблер «Сохранить настройки» — тумблер ничего не сохраняет, он включает.

## Доступность

- Настоящие input. Флажок и радио —  внутри : клавиатура, формы и скринридер бесплатно.
- Тумблер — тот же checkbox с другим видом; скринридер читает «флажок», и это честно: семантика та же.
- Частичное состояние ставится и в input.indeterminate, и классом — первое для скринридера, второе для глаза.
- Контраст. Отмеченный квадрат к поверхности 4,07:1 в тёмной и 5,04:1 в светлой теме; галочка на нём 4,79 / 5,04 (проверка ТИШИНА).

## Пример

Измените выбор и сравните три типа управления. Проверьте, где допустимо несколько значений.

## Структура

- **Настоящий input** — скрыт, но живой: клавиатура, формы и скринридер работают через него.
- **Квадрат с галочкой** — dk-check__box: пустой — поверхность третьего уровня, отмеченный — серый --control-on с галочкой. Отличие ещё и формой, не только заливкой.
- **Круг радио** — dk-check--radio: форма говорит «только одно»; точка внутри цветом подписи.
- **Дорожка тумблера** — dk-switch__track: включённый — серый, выключенный — поверхность.
- **Подпись** — часть , поэтому кликабельна целиком.

## Состояния

Пусто Отмечено Частично Фокус Недоступно Частичное — не «ничего». Черта в шапке списка значит «выбрана часть»; галочка означала бы «все», и это было бы неправдой.

## Варианты

- `dk-check` — Флажок с подписью. Независимое да / нет.
- `dk-check--radio` — Круглый переключатель. Один из двух–пяти вариантов; input type=radio с общим name.
- `dk-check__box--mixed` — Частично отмечен, черта вместо галочки. «Выбрано не всё» в шапке списка; ставится скриптом.
- `dk-switch` — Тумблер. Режим, срабатывает сразу.
- `disabled` — Атрибут input. Причина недоступности видна рядом.

## Размеры

Видимый флажок и тумблер компактнее области нажатия. На сенсорном экране вместе с подписью она должна быть не меньше 44 × 44 px.

## Код

```html
<label class="dk-check">
  <input type="checkbox" name="events" checked>
  <span class="dk-check__box"><svg class="dk-i"><use href="#ti-check"/></svg></span>
  Показывать события
</label>

<label class="dk-check dk-check--radio">
  <input type="radio" name="period" value="7" checked>
  <span class="dk-check__box"></span>
  7 дней
</label>

<label class="dk-switch">
  <input type="checkbox" name="layer">
  <span class="dk-switch__track"><span class="dk-switch__knob"></span></span>
  Слой событий
</label>
```

## Параметры

- `input[type=checkbox|radio]` (элемент): Состояние живёт в input; классы только рисуют.
- `dk-check__box--mixed` (класс): Частичное; вместе с input.indeterminate = true.
- `disabled` (атрибут): Недоступно; подпись приглушается сама.
