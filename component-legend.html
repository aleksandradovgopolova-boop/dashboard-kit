Фильтры-легенда

Объясняет цвета категорий и позволяет включать или исключать их из среза.

Статус: стабильный ПримерКод и API

В работе

Переключите категорию. Состояние выбора различается и без опоры только на цвет.

Код примера ↗

Когда использовать

Когда использовать
  • Категорий две–шесть, и у каждой есть свой цвет на графике или карте рядом.
  • Нужно одновременно объяснить цвета и дать их включать / выключать.
  • Рядом с категорией важно число: «Высокий 23».
Когда выбрать другое
  • Категорий больше шести или у них нет цвета — Фильтр.
  • Категории без данных рядом — обычная легенда графика, её рисует dkChart сам.
  • Один вариант из нескольких — Сегмент.

Анатомия

  1. Чип — кнопка с aria-pressed; включённый залит своим цветом на 22 %, чтобы не спорить с данными.
  2. Метка цвета — dk-lg__sw берёт --swatch; без него — серый.
  3. Число — сколько записей за категорией; ноль показывается приглушённым.

Варианты и размеры

Три размера по высоте контролов: dk-lg--sm 28, по умолчанию 32, dk-lg--lg 40; метка цвета растёт вместе.

Класс или параметрЧто делаетКогда
dk-lgЧип-фильтр.Каждая категория.
is-on + aria-pressedВключён.Ставит скрипт страницы.
--swatchЦвет категории через стиль.Всегда, кроме «Все».
dk-lg--sm / dk-lg--lgРазмер.По соседям.

Состояния

Выключенные категории не исчезают. Чип остаётся на месте с приглушённой меткой: человек видит, что именно он отключил, и может вернуть.

Текст и подписи

Понятно
  • Название категории — как в легенде графика рядом, слово в слово.
  • Первым — «Все» с общим числом.
  • Порядок — по смыслу (от худшего к лучшему), а не по алфавиту.
Вызывает вопросы
  • Разные названия на чипе и в легенде графика: «Высокий» и «Крит.».
  • Чип без числа: выбор вслепую.
  • Цвет, розданный по кругу, а не по смыслу.

Доступность

  • Роль. Кнопки с aria-pressed; скринридер читает «нажата / не нажата».
  • Не только цветом. Включённый чип отличается заливкой всего чипа, не только меткой; число и подпись на месте.
  • Контраст. Заливка 22 % своего цвета поверх поверхности — та же ступень, что у выбранной строки таблицы.
  • Клавиатура. Обычные кнопки: Tab, Enter, пробел.

Код

Поведение задаёт страница: компонент не знает, что делать с данными при выключении категории.

Исходники: css/components.css

<div class="dk-legend">
  <button class="dk-lg is-on" aria-pressed="true"><i class="dk-lg__sw"></i>Все<b class="dk-lg__n">89</b></button>
  <button class="dk-lg" aria-pressed="false" style="--swatch:var(--crit)"><i class="dk-lg__sw"></i>Высокий<b class="dk-lg__n">23</b></button>
</div>

<script>
legend.addEventListener('click', function (e) {
  var b = e.target.closest('.dk-lg');
  if (!b) return;
  var on = b.getAttribute('aria-pressed') !== 'true';
  b.setAttribute('aria-pressed', String(on));
  b.classList.toggle('is-on', on);
  // дальше — перерисовать данные
});
</script>

Параметры и методы

ПараметрТипЧто делает

С чем сочетать

  • Фильтр — когда категорий больше шести
  • График — легенду самого графика рисует обёртка
  • Регионы — легенда шкалы под картой
