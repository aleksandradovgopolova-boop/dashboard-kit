# Таблица

Помогает сравнивать объекты по нескольким признакам и находить точные значения.

## Когда использовать

- Для последних событий используйте dk-table--events: Время, Событие, Регион, Статус, Пострадавшие. Значок в dk-td-main__icon, численность с единицей чел.; фактические статусы и числа сохраняются.
- Объектов больше семи и у каждого несколько показателей — сравнивать нужно по колонкам.
- По строке нужно действие: назначить, открыть, снять с контроля.
- Точное число важнее формы: «73 события», а не «примерно столько же, сколько у соседа».

## Когда выбрать другое

- Один показатель по многим объектам, вопрос «у кого хуже» — Рейтинг: полоса читается быстрее числа.
- Одно–четыре главных числа — KPI-плитки, а не таблица из одной строки.
- Динамика во времени — График: таблица покажет числа, но не форму.
- Список с одним значением на строку — Список, у него меньше шума.

## Контент: так

- Единица — в заголовке колонки: «События, шт.», в ячейках только числа.
- Нет значения — прочерк «—». Ноль — это ответ, отсутствие — нет.
- Числа через dkFmt: разряды неразрывным пробелом, дробь запятой, минус настоящий.
- Дельта со знаком всегда: «+4», «−8 мин».
- Заголовки короткие, именительный падеж: «Регион», «Балл».

## Контент: не так

- «73 события» в каждой ячейке — единица повторяется сорок раз.
- Пустая ячейка или «0» вместо отсутствующего значения.
- «1240» рядом с «1 240» — читается как два разных числа.
- Цвет статуса без значка и подписи — его видят не все.
- Действия, спрятанные под наведение, — на тачскрине наведения нет.

## Доступность

- Клавиатура. Заголовок с сортировкой — кнопка, флажки — настоящие input; кольцо фокуса только при навигации табом.
- Роли. Настоящая : скринридер ходит по ячейкам сам. Сортировка — aria-sort; выбранная строка — aria-selected.
- Подписи. У каждого флажка свой aria-label с названием строки; у колонки действий — скрытый заголовок.
- Контраст. Заголовок на своей поверхности и числа на строке проверяются в обеих темах (КОНТРАСТ, СТУПЕНИ).
- Не проверялось. Живой скринридер и тач-устройства — как и у всего кита.

## Пример

Посмотрите, как читаются названия, числа и статусы. Доступные действия обозначены в заголовках и строках.

## Структура

- **Колонка выбора** — флажок «все на странице» и по флажку на строку. Выбрано — не только заливкой, но и числом в строке действий.
- **Заголовок колонки** — надписью, поверхностью отделён от тела. Границ нет.
- **Сортировка** — стрелка показывает, куда отсортировано, а не «здесь можно». Скринридеру то же говорит aria-sort.
- **Числовая колонка** — dk-td-num: вправо, табличными цифрами (--font-num), единица в заголовке.
- **Главная ячейка** — название; при нужде с подстрокой и значком (dk-td-main).
- **Статус** — всегда со значком и подписью, никогда одним цветом.
- **Значение** — цвет смысла только у чисел, которые сравнивают с порогом.
- **Группа** — строка dk-tr-group: название надписью, подытог числом.
- **Итог** — , в закреплённой таблице прилипает к низу.

Повторить Наведение, выбор и сортировка — в живом примере выше. Пустое состояние отвечает на три вопроса: что случилось, почему и что делать.

## Варианты

- `dk-table` — Без разделителей: шапка поверхностью, строки наведением. По умолчанию.
- `dk-table--zebra` — Чередование строк полупрозрачной заливкой. Длинная плотная таблица.
- `dk-table--cards` — На телефоне строка — карточка «подпись — значение», шапка — пилюли сортировки. Нужен dkTable: он ставит подписи. Таблица шире экрана телефона: больше трёх колонок.
- `dk-table--ruled` — Волосяные линейки между строками. Печать и очень плотные данные; включается вручную.
- `dk-table--sticky-head` — Шапка и итог закреплены при прокрутке. Обёртка dk-tablewrap--tall с --table-max.
- `dk-table--sticky-col` — Первая колонка (и колонка выбора) закреплены. Колонок больше, чем помещается.
- `dk-tablewrap` — Горизонтальная прокрутка; --table-min — минимальная ширина. Всегда, если колонок больше четырёх.

## Размеры

Ширина зависит от колонок. На узком экране таблица прокручивается внутри своей области. Плотность можно менять компонентом «Плотность данных», сохраняя текст и области нажатия.

## Код

```html
<div class="dk-tablewrap dk-tablewrap--tall" style="--table-min:860px;--table-max:420px">
  <table class="dk-table dk-table--zebra dk-table--sticky-head dk-table--sticky-col" id="regions">
    <thead><tr>
      <th class="dk-th-pick"><label class="dk-check" aria-label="Выбрать все на странице">
        <input type="checkbox" data-pick-all><span class="dk-check__box">…</span></label></th>
      <th style="width:24%" data-sortable="Регион">Регион</th>
      <th style="width:12%" class="dk-td-num" data-sortable="Балл">Балл</th>
    </tr></thead>
    <tbody>
      <tr data-id="RU-CR">
        <td class="dk-td-pick">…<input type="checkbox" data-pick value="RU-CR">…</td>
        <td>Крым</td>
        <td class="dk-td-num" data-sort="82">82</td>
      </tr>
      <tr class="dk-tr-group"><td colspan="2">Сибирский округ</td><td class="dk-td-num">73</td></tr>
    </tbody>
    <tfoot><tr><td></td><td>Итого</td><td class="dk-td-num">155</td></tr></tfoot>
  </table>
</div>

<script>
var t = dkTable(document.getElementById('regions'), {
  onSelect: function (ids) { /* выбрано видно числом: ids.length */ },
  onSort:   function (e)   { /* e.column, e.dir — если сортирует сервер */ }
});
t.selected; t.clear();
</script>
```

## Параметры

- `onSelect(ids)` (функция): При каждой смене выбора с массивом data-id.
- `onSort(e)` (функция): Передан — таблица не сортирует сама, а сообщает e.column и e.dir.
- `data-sortable` (атрибут th): Имя колонки для сортировки.
- `data-sort` (атрибут td): Значение для сортировки, когда текст ячейки — не оно.
- `--table-min, --table-max` (переменные на обёртке): Минимальная ширина и высота прокрутки; по умолчанию 720 и 480.
- `update({selected}) / destroy()` (API): Восстановление выбора по data-id; cleanup обработчиков/observer без удаления таблицы. Sort host связывает через onSort.
