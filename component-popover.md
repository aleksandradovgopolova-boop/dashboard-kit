# Всплывающие сведения

Открывает дополнительные сведения и действия рядом с кнопкой.

## Когда использовать

- Нужны ссылки, настройки или длинное объяснение по запросу.

## Когда выбрать другое

- Короткий неинтерактивный текст — Подсказка. Большая задача — отдельный экран или диалог.

## Контент: так

- Конкретное название: «Данные и методика», «Настройки периода».

## Контент: не так

- Ссылка или поле внутри Tooltip; неясное «Подробнее» без контекста.

## Доступность

- При открытии фокус в содержимом, Tab выходит в обычный порядок страницы; Escape/Закрыть возвращают фокус кнопке. Внешний клик не перехватывает фокус. Не модальный: фон доступен. В native dialog панель принадлежит тому же диалогу.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Внутри могут быть ссылки и настройки. Короткое объяснение без действий остаётся подсказкой.

## Структура

- **Контекст** — Открывает дополнительные сведения и действия рядом с кнопкой.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Закрыто, открыто, содержимое обновлено, закрытие по Escape или внешнему действию. После destroy обработчики и ARIA восстановлены. Ограничения и подключение Строка content вставляется как текст; HTMLElement передаётся во владение компонента. Скрипт/HTML из данных не выполняются. На scroll/resize положение пересчитывается, длинное содержимое прокручивается. В старом WebView без Popover API используется fixed fallback. Старые классы dk-pop сохраняют только прежний стиль и не запускают контроллер автоматически. Вложенные Popover не поддерживаются; Tooltip и Onboarding остаются отдельными компонентами. Нативный механизм: HTML Popover .

## Варианты

- `dkPopover(trigger,{label,content,placement})` — Разметка и параметры компонента. При задаче, описанной выше.

## Размеры

Ширина до 360 px, высота ограничена доступным окном; поля равны с четырёх сторон, длинное содержимое прокручивается.

## Код

```html
<button class="dk-btn dk-btn--sm" type="button" id="context-info">Данные и методика</button>
<script>
document.addEventListener("DOMContentLoaded", function(){
var content=document.createElement('div'); content.innerHTML='<p>Учебные наблюдения. Выполнение = сумма факта / сумма плана × 100%.</p><a href="docs/named-metrics.md">Контракт метрик</a>'; dkPopover(document.getElementById('context-info'),{label:'Данные и методика',content:content});
});
</script>
```

## Параметры

- `dkPopover(trigger,{label,content,placement})` (API): trigger — button, label — доступное название, content — текст или HTMLElement; placement: auto/top/bottom.
- `open()/close()/toggle()/update()/destroy()` (методы): open возвращает Promise после завершения входной анимации родительского dialog. Ожидание отменяется close/destroy/уходом фокуса. Один открытый Popover; update сохраняет фокус, destroy очищает обработчики и ARIA.
