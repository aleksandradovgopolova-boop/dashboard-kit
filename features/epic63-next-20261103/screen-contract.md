# #37 / #67 / #68 · проверяемая статическая сборка

Реализованы scoped structural checks, минимальный общий parameter contract
и закрытый компилятор screen-spec/1. База — PR75/406cd89 поверх PR74/fab9e75.
Это локальный кандидат rc.7, не выпуск stable и не обновление потребителей.

## Реальный результат

- #37: overview максимум семь самостоятельных KPI, вложенные числа не
  удваиваются, operations/detail/catalog не получают чужой лимит. Пустые
  колонки, явный reserve/reset и незарегистрированный page.css проверяются
  отдельно от смысла текста. Scope размечен у семи рабочих примеров.
- #67: tile/chart/table/select имеют один источник схем и зависимости/действия.
  Manifest, CLI schema/validate, MCP и generated skill reference согласованы.
  Ошибки типов, неизвестные поля, версии, комбинации и ID с newline отклоняются.
- #68: plan-fact JSON компилируется в самостоятельные HTML/CSS/JS и pinned kit.
  Проверяются ссылки, циклы, типы, единицы, grain, действия и состав экрана.
  Источник и метрики проверяются настоящими JS API после проверки external pin.
  Повторная сборка идентична по байтам; существующий output сохраняется.

Фильтры, сброс, numeric sort, детали и методика работают. Независимые ответы:
100 выдач / 200 план / 50% исполнения / 6,6% взвешенная ставка; Север —
40 / 80% / 4,5%. При partial нет ложного полного KPI или точки графика;
при неполном источнике весь ряд остаётся без числовой оценки.

## Редакционная приёмка семи примеров

Отдельный read-only reviewer осмотрел каждый пример на 1470/390 в обеих темах.
Dashboard: названия, единицы, статус и объектные описания сохранены.
Regions: пороги — легенда, правила карты и методика — по запросу; очевидный
клик не объясняется постоянно. Accidents: реальные описания аварий — данные,
не инструкция; рабочие статусы и действия сохранены. Calendar: названия
событий и даты — содержание. Mortgage: период, единицы, no-data и partial
не удалены. Reference: частичность — краткий статус, причина через Tooltip;
осевая единица не дублирует заголовок и не обрезается. Mobile: ложный empty
и неподтверждённый trend удалены; статичный учебный характер обозначен,
несвязанные фильтры отключены с причиной, ссылки ведут на реальные страницы.

Обнаруженное незавершённое кольцо было анимацией обновления ECharts:
теперь reduced motion отключает animation целиком. Новый runtime assertion
и свежие снимки показывают полные кольца. После исправлений reviewer повторно
осмотрел mobile, reference, dashboard и accidents: APPROVE. Copy collection
остаётся вспомогательным, не доказательством полноты смысловой проверки.

## Границы

Четыре адаптера — не полный JS API. Только local snapshot, day, ≤1000 строк,
single-select, plan-fact. Server page, derived chart series и иные рецепты
отклоняются. Статическая policy не вычисляет CSS cascade и не оценивает
редакционный смысл по пунктуации. AX/Chrome не заменяют настоящий скринридер
или физические устройства. Увеличение canvas-шрифта ECharts до 200% отдельно
не утверждается. Никакого framework, вложенного Claude или сетевых операций.
