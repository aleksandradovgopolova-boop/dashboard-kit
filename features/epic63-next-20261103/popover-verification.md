# Popover #22 · локальная приёмка

Один интерактивный немодальный контроллер dkPopover; существующий Tooltip
и Onboarding не заменены. Старый style-only manifest stub объединён с реальным
компонентом без удаления legacy dk-pop CSS. Страница и Markdown справочника
генерируются из одного источника. Строки content — textContent, HTMLElement
передаётся компоненту; внутри допустимы реальные ссылки/поля/действия.

12 сочетаний Chrome PASS: native/fallback × Dark/Light × 320/390/1280.
Настоящие Tab/Shift+Tab/Escape, touch на телефоне, внешний клик без кражи
фокуса, края viewport, scroll/resize, крупный текст, длинная прокрутка,
диалог и вложенный select, update/destroy/reinit/removal и один открытый слой.
Два снимка (native Dark390 и fallback Light320) просмотрены вручную.
Это не проверка физического устройства или настоящего скринридера.

Дополнительный проход обнаружил временный containing block transform-анимации
родительского dialog: fallback терял фокус до завершения входа. open теперь
ждёт фактических конечных анимаций родителя; close/destroy/уход фокуса отменяют
ожидание. В тесте проверены оба отменяющих сценария. Не добавлен таймаут,
не скрыта проверка фокуса и не изменён общий Glass/modal.

Fast PASS после пересборки. Reduced-motion assertion добавлен в общий suite;
адресный fallback Dark320 с этой проверкой — PASS. Полный Chrome/MCP CI этого
пакета ещё предстоит. Root выполнил кодовый и визуальный проходы; это не
независимое внешнее ревью. Нативный механизм — HTML Popover standard;
сторонний runtime или код не переносился.
