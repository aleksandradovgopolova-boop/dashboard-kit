# Наблюдения для продолжения

1. Независимые константы должны различать правдоподобные неверные формулы.
   Равные знаменатели случайно скрывали среднее процентов; отдельный случай
   230/300 вместо 70% устранил этот пробел.
2. Добавление Tooltip делает прежний неинтерактивный компонент интерактивным:
   update теперь обязан сохранять фокус, а destroy — освобождать подсказку.
3. Проверки на localhost зависят от политики среды. EPERM не является пропуском
   с результатом PASS. Полный suite позже прошёл в штатном GitHub Actions;
   ручной screenshot review остаётся открытым. Старый PASS базы не переносится на новый код.
4. Для draft-пакета сохранить точные команды, хеши и причины блокировки полезнее,
   чем отмечать завершёнными неисполненные стадии AI Ops.

5. UI-тест должен отделять остаточный pointer предыдущего случая от focus
   нового. После Escape важно подтвердить устойчивое закрытие без blur/hide,
   а при падении записывать сценарий и события. Успешный повторный прогон
   сам по себе не доказывает первопричину первого сбоя.
