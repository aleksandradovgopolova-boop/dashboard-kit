# Каталог метрик

## Статус
Каталог предложений; ни одна метрика ниже не имеет утверждённой цели или baseline.

| ID | Определение / единица | Источник и метод | Ограничение |
|---|---|---|---|
| build-success | Выполненные без помощи задания сборки / все начатые задания, % | Записанный протокол заданий + check.py --page | Определить одинаковую сложность и критерии |
| build-time | Медиана длительности от начала до принятой страницы, минуты; незавершённые отдельно | Временные отметки наблюдаемого задания | Не подменять временем генерации AI |
| task-success | Выполненные без подсказок сценарии / все начатые сценарии, % | Исследование роли: найти риск, объяснить число, изменить срез, детали | Экспертный walkthrough не baseline |
| understanding | Верно объяснённые значение, порог и источник / все ответы, % | Заранее заданная рубрика ответов | Не собирать выдуманные результаты |
| accessible-task-success | task-success отдельно для клавиатуры, реального screenreader и устройств | Фактические реплики/действия, среда записана | AX tree не screenreader |
| regressions | Подтверждённые дефекты после изменения, количество за период | REVIEW/issue с воспроизведением | Период и каталог дефектов согласовать |
