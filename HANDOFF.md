# Где мы остановились

Файл для начала новой сессии. Он не пересказывает кит — для этого есть
[README.md](README.md). Он говорит ровно одно: что уже сделано, что открыто и
как здесь принято работать, чтобы следующий заход не начался с нуля.

## Что это

`dashboard-kit` — дизайн-система мониторинговых дашбордов ЖКХ. Ванильные CSS и
JS, без сборки, офлайн-первый, две темы, русский интерфейс. Три слоя токенов,
компоненты, необязательный каркас страницы.

Страницы: `showcase.html` (каталог), `component-*.html` (39 страниц компонентов,
собираются `tools/build-component-pages.py`), `dashboard.html`, `regions.html`, `calendar.html`, `accidents.html`,
`embed.html` (проверка встраивания).

## Как здесь принято работать

Это важнее списка задач. Правила выведены из ошибок, а не из вкуса:

1. **Измерять, а не смотреть.** Каждое утверждение про контраст, различимость,
   ширину, выравнивание подтверждается числом. За сессию трижды случалось, что
   правка «выглядела сделанной» и не работала: ECharts молча выбрасывал имена
   свойств, CSS-правило проигрывало специфичность, обработчик остался подписан
   на узел, который переехал.
2. **Проверка важнее правки.** Если дефект можно поймать в `tools/check.py` —
   ловить там. Двадцать две проверки появились именно так. Проверка, которая
   обещает больше, чем делает, хуже отсутствующей. Новую проверку испытывают
   нарочными поломками в копии кита: каждая должна быть поймана.
3. **Причина пишется рядом с кодом.** Комментарий объясняет, из-за какой ошибки
   правило появилось, а не что делает строка. 41% объёма CSS — комментарии, и
   это осознанная цена.
4. **Решение записывается, а не запоминается.** Открытые пункты — в
   [REVIEW.md](REVIEW.md), вопросы об устройстве — в [DECISIONS.md](DECISIONS.md).
   Один раз они жили только в переписке и чуть не потерялись.
5. **Цена называется вслух.** У каждой правки есть обратная сторона; её пишут
   рядом, а не прячут.

Запуск: `python3 -m http.server 8766` в корне. Проверки: `python3 tools/check.py`
(полминуты: последняя, ТЕЛЕФОН, открывает страницы в Chrome; `--fast` её
пропускает и печатает «?»). Только телефон: `node tools/check-mobile.mjs`.
Тему графиков после правки токенов пересобрать: `python3 tools/build-chart-theme.py`.
ECharts после правки `vendor/echarts.modules.json` пересобрать: `python3 tools/build-echarts.py`
(нужны node, npm и сеть). Страницы компонентов после правки `tools/component_pages/`:
`python3 tools/build-component-pages.py`. Опись кита для скилла после любой из
этих правок: `python3 tools/build-manifest.py`; читать её — `python3 tools/kit.py list`.

## Что закрыто

Три волны ревью (цвет и контраст, доступность, визуальная), ревью
фронтенд-разработчика целиком — экранирование, утечки, падения на данных,
сортировка, живые области, клавиатура, встраивание, загрузка, мигание темы.
Пять спорных пунктов решены разведением случаев, а не выбором стороны.
Подробности — в REVIEW.md.

Актуальный полный цикл — `python3 tools/test.py`; исторические прогоны ниже сохранены с датами.

анимация идёт раз в секунду. Замер без фиксированного окна и без выключенной
анимации ничего не доказывает — сначала проверь, что замер повторяем.
