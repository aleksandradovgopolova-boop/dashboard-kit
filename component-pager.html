📑Пагинация

Показывает текущую часть набора данных и позволяет перейти к следующей странице.

Статус: стабильный ПримерКак выбратьС чем сочетатьКод и API

В работе

Номер страницы и диапазон записей показывают, где вы находитесь в наборе. Переходы вперёд и назад работают в примере.

Когда использовать

Когда использовать
  • Записей больше, чем помещается на экране, и они равноправны: журнал аварий, список заявок.
  • Человеку важно знать, сколько всего и где он сейчас.
  • Сортировка и фильтры должны работать по всему набору, а не по видимой странице.
Когда выбрать другое
  • Записей до тридцати — просто прокрутка; полосу прокрутки не прячут.
  • Лента событий, которую читают сверху вниз, — кнопка «Показать ещё» в Списке.
  • Рейтинг — Рейтинг: там показывают верх, а не листают.
Правила сочетания
  • Фильтрация
  • Таблицы для чтения и сравнения

Из чего состоит

141–60 из 89 регионов
…
  1. Счётчик — «41–60 из 89 регионов»: диапазон, всего и существительное в нужном падеже.
  2. Стрелки — назад и вперёд; на краях недоступны, но не исчезают.
  3. Страницы — первая, последняя и соседи текущей; между ними «…». Текущая — aria-current="page", серая.
  4. Размер страницы — необязательный выбор «по 10 / 20 / 50»; при смене счётчик пересчитывается.

Варианты и размеры

Размер один; на узком экране номера страниц сворачиваются в «3/5» между стрелками — счётчик и стрелки остаются всегда.

Класс или параметрЧто делаетКогда
sizes: [10, 20, 50]Выбор размера страницы.Длинные журналы.
sizes: nullРазмер не меняется.По умолчанию.
noun: ['запись', 'записи', 'записей']Склонение существительного.Всегда, если считаем не записи.

Состояния

1–20 из 89 регионов
…
0 регионов
Первая страница и пустой список. На первой странице стрелка «назад» недоступна, но на месте. При нуле записей пагинация не прячется, а честно пишет «0 регионов» — пустое состояние показывает сам список.

Текст и подписи

Понятно
  • «21–40 из 89 регионов» — диапазон, всего, существительное в падеже.
  • Существительное — то, что считаем: регионов, заявок, аварий.
  • Итог отрицательным не бывает: сдвиг ограничен нулём.
Вызывает вопросы
  • «Страница 3 из 5» — не говорит, сколько записей.
  • «89 записей» для аварий — записи бывают у бухгалтера.
  • Пагинация, которая исчезает на одной странице: человек не знает, что видит всё.

Доступность

  • Роли. Текущая страница — aria-current="page"; стрелки — кнопки с aria-label.
  • Живая область. Счётчик объявляется скринридеру при смене страницы.
  • Клавиатура. Обычные кнопки: Tab, Enter.
  • Контраст. Текущая страница залита --control-on, цифра на ней 4,79 / 5,04:1.

С чем сочетать

  • Таблица — что листают
  • Список — «Показать ещё» вместо страниц
  • Страница «Аварии» — пагинация журнала с сортировкой по всему набору

Код и API

Контейнер пустой, разметку строит скрипт. Данные листает страница по onChange.

Исходники: css/components.css · js/dk-pager.js

<div id="pager"></div>

<script>
var pg = dkPager(document.getElementById('pager'), {
  total: 89, size: 20, page: 1,
  sizes: [10, 20, 50],                         // или null
  noun: ['регион', 'региона', 'регионов'],
  onChange: function (e) { /* e.page, e.size — запросить и показать срез */ }
});
pg.page; pg.size; pg.setTotal(120);
</script>
