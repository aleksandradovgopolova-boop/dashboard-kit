# Бейдж, статус, прогресс

Обозначает короткую метку, состояние объекта или долю выполненной работы.

## Когда использовать

- Бейдж: число или короткая метка рядом с названием — «23» у вкладки, «БПЛА» у региона.
- Статус: состояние объекта в строке таблицы или карточке.
- Прогресс: доля выполненного, когда есть известный конец: устранение, готовность.

## Когда выбрать другое

- Категория, которую можно снять, — чип-фильтр, не бейдж.
- Главное число экрана — KPI-плитка, бейдж для этого мелок.
- Доступность во времени — Полоса доступности, не прогресс.

## Контент: так

- Статус — одно-два понятных слова: «Отстаёт», «По плану», «Нет данных». Выбирайте самую короткую формулировку, которая сохраняет смысл.
- Метка — существительное-категория: «БПЛА», «Плановое».
- Прогресс с числом рядом и понятным концом: 64% устранения.

## Контент: не так

- Статус одним цветом или одним значком.
- Бейдж «новое» на всём подряд — акцент перестаёт значить «новое».
- Прогресс без числа и без известного конца — там неопределённая полоса.

## Доступность

- Не только цветом. Статус — значок + подпись; бейдж цвета смысла всегда с числом.
- Прогресс — число рядом читается скринридером; сама полоса декоративна.
- Аватары — инициалы с aria-label полного имени.
- Контраст. Подписи статусов и бейджей на своих заливках проверяются проверкой КОНТРАСТ в обеих темах.

## Пример

Сравните бейдж, статус и прогресс: каждый отвечает на свой вопрос.

## Структура

- **Бейдж с числом** — цвет смысла — только если число сравнивают с порогом (балл риска); иначе нейтральный.
- **Бейдж-метка** — dk-badge--pill: короткое слово-категория, всегда нейтральный.
- **Значок статуса** — обязателен: цвет видят не все, в чёрно-белой печати его нет вовсе.
- **Подпись статуса** — обязательна по той же причине; статус без слова — не статус.
- **Дорожка прогресса** — поверхность третьего уровня; заливка — --accent со значением по умолчанию.
- **Число** — рядом с полосой всегда: полоса показывает «примерно», число — «сколько».

## Состояния

Авария В работе Устранено Нет данных 0% 100% — «Нет данных» — отдельное состояние, а не ноль. Статус без модификатора и прогресс с прочерком говорят «не знаем», а не «ничего». Ноль процентов — это ответ.

## Варианты

- `dk-badge` — Нейтральный бейдж с числом или словом. По умолчанию.
- `dk-badge--crit / --high / --calm` — Цвет смысла. Число сравнивают с порогом.
- `dk-badge--brand` — Акцентный: «новое». Единственный бейдж с акцентом; открыто в REVIEW.md.
- `dk-badge--pill` — Метка-категория. Слово, не число.
- `dk-status / --crit / --high / --calm` — Статус со значком и подписью. Состояние объекта; без модификатора — «нет данных».
- `dk-progress / --indeterminate` — Полоса; неопределённая бежит. Известен конец / не известен.
- `dk-avatar / --sm / --more` — Инициалы человека; «+4». Кто отвечает, кто следит.

## Размеры

Размер один — под строку таблицы и текст карточки. Крупнее нужен не бейдж, а число KPI.

## Код

```html
<span class="dk-badge dk-badge--crit">23</span>
<span class="dk-badge dk-badge--pill">БПЛА</span>

<span class="dk-status dk-status--high">
  <svg class="dk-i"><use href="#ti-clock"/></svg>В работе
</span>

<div class="dk-progress">
  <span class="dk-progress__track"><span class="dk-progress__fill" style="width:64%;--accent:var(--high)"></span></span>
  <span class="dk-progress__value">64%</span>
</div>
```

## Параметры

- `dk-badge--crit | --high | --calm | --brand | --pill` (класс): Вид бейджа.
- `dk-status--crit | --high | --calm` (класс): Цвет статуса; без модификатора — «нет данных».
- `--accent` (переменная в style): Цвет заливки прогресса; по умолчанию акцент (открыто в REVIEW.md).
- `dk-progress--indeterminate` (класс): Конец неизвестен.
- `dk-avatar--sm | --more` (класс): Маленький аватар; «ещё N».
