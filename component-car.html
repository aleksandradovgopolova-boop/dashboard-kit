Лента карточек

Показывает последовательность карточек, у каждой из которых свой контекст.

Когда использовать

Когда использовать
  • Три–семь объектов, и у каждого есть рассказ: было → стало, причина, где.
  • Верх телефонного экрана под главной карточкой: «что изменилось сегодня».
Когда выбрать другое
  • Объектов больше семи или их надо сравнивать между собой — Рейтинг или Таблица: в ленте видна одна карточка за раз.
  • Одно число с тем, из чего оно сложено — Главная карточка.
  • Список событий по времени — Список.

  1. Заголовок ленты — dk-car__title: что объединяет карточки.
  2. Счётчик — dk-car__pos «1 из 3» — словами; точки под лентой только подсказка.
  3. Метки — dk-car__tags: пилюли dk-trend — почему карточка здесь.
  4. Кто — dk-car__name и dk-car__sub: объект и где он.
  5. Было → стало — dk-car__change: прежнее мельче, нынешнее крупным числом смысла.
  6. Рассказ — dk-car__text, две строки: причина словами.

Варианты и размеры

Карточка 300 px, но не шире 82% экрана: на телефоне от следующей остаётся видимая полоса. Размер один.

Текст и подписи

Понятно
  • Заголовок отвечает, почему эти карточки вместе: «Резко выросли за день».
  • Было → стало числами: «30 → 57».
  • Рассказ — причина: «авария теплосети», а не «рост показателя».
Вызывает вопросы
  • Лента из одной карточки — это главная карточка.
  • Двадцать карточек: до последней не долистают.
  • Пустая лента без слов, когда изменений нет.

Доступность

  • Лента — список: ul role="list", карточки — пункты; скринридер называет, сколько их.
  • Позиция словами: счётчик «1 из 3»; точки скрыты от скринридера (aria-hidden).
  • Было → стало — aria-label на паре чисел: «было 30, стало 57», стрелка скрыта.
  • Стрелки — кнопки с подписью; на краях ленты отключаются.

Код

Разметку пишет страница, dkCar только оживляет её: счётчик, точки и стрелки.

Исходники: css/components.css · js/dk-car.js

<div class="dk-car" id="car">
  <div class="dk-car__head">
    <h3 class="dk-car__title">Резко выросли за день</h3>
    <span class="dk-push dk-car__pos">1 из 5</span>
    <span class="dk-car__nav">
      <button type="button" class="dk-iconbtn dk-iconbtn--sm" data-car="prev" aria-label="Предыдущая">…</button>
      <button type="button" class="dk-iconbtn dk-iconbtn--sm" data-car="next" aria-label="Следующая">…</button>
    </span>
  </div>
  <ul class="dk-car__track" role="list">
    <li class="dk-car__item" style="--accent:var(--crit)">
      <span class="dk-car__tags"><span class="dk-trend" style="--accent:var(--crit-ink)">+27 за день</span></span>
      <span class="dk-car__row">
        <span class="dk-car__who"><span class="dk-car__name">Санкт-Петербург</span><span class="dk-car__sub">СЗФО</span></span>
        <span class="dk-car__change" aria-label="было 30, стало 57">
          <span class="dk-car__from">30</span><span class="dk-car__arrow" aria-hidden="true">→</span>
          <span class="dk-car__to" style="--to:var(--crit-ink)">57</span></span>
      </span>
      <p class="dk-car__text">Авария теплосети; отключения ГВС и отопления.</p>
    </li>
  </ul>
  <div class="dk-car__dots"></div>
</div>

Параметры и методы

ПараметрТипЧто делает
dkCar(el)функцияОживляет разметку ленты; возвращает управление.
indexчисло, чтениеНомер текущей карточки, с нуля.
go(i)функцияПролистать к карточке; движение гасится системной настройкой.
destroy()функцияСнять обработчики; сторож dk-util.js сделает это сам, когда узел уйдёт.

С чем сочетать

  • Главная карточка — одно главное число экрана
  • Рейтинг и сводка — много объектов для сравнения
  • Список — события по времени
