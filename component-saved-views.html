Когда использовать

Когда использовать
  • Пользователь регулярно возвращается к одним фильтрам и периодам.
Когда выбрать другое
  • Нужны общие виды команды: локальное хранилище не является синхронизацией.

Фильтрация

  • Область фильтра понятна; применённые значения видны. Все затронутые виджеты используют один срез.
  • Поиск, фильтрация и сортировка имеют разные роли. После изменения набора страница результатов остаётся допустимой.
  • Нет результатов — честное состояние с возможностью снять ограничение; не подменять его похожими данными молча. Сброс — компактный крестик.
  • Модель применения понятна: сразу либо черновик с явным «Применить». Черновик не выдаётся за текущий срез; отмена сохраняет предыдущий срез.

Пример: KPI, карта и таблица обновлены из одного среза; возврат сохраняет фильтры.

Проверка: Проверить совместные фильтры, пустую выдачу, сброс, пагинацию и возвращение из деталей.

Источник · Все правила выбора

Анатомия

Номера на схеме — те же, что в списке.

  1. Контекст — Возвращает локальный рабочий срез со всеми согласованными параметрами.
  2. Данные и действие — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

Варианты и размеры

Компонент следует ширине контейнера и системным токенам. Названия и действия видимы, status сообщает ошибки хранения. После действий фокус остаётся в контексте. Переименование использует поле Название вида.

Класс или параметрЧто делаетКогда
dkState(el, initial)Основной контракт API/markup.При задаче, описанной выше.

Состояния

Формат version=1, v0 views мигрирует; неизвестная версия не применяется. Storage отказ сохраняет работу в памяти. Состояние отделено от компонентов: host подписывается на dk:statechange и обновляет фильтры/период/таблицу/карту.

Контент

Так
  • Пользователь регулярно возвращается к одним фильтрам и периодам.
  • Показывайте полные названия, единицы и источник данных.
Не так
  • Нужны общие виды команды: локальное хранилище не является синхронизацией.
  • Не выдавайте отсутствие наблюдений за ноль и не используйте цвет как единственное объяснение.

Доступность

  • Названия и действия видимы, status сообщает ошибки хранения. После действий фокус остаётся в контексте. Переименование использует поле Название вида.
  • Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.
