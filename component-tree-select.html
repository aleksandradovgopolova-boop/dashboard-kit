🌳Выбор в иерархии

Выбирает объекты из иерархии групп и дочерних элементов.

Статус: экспериментальный ПримерКак выбратьС чем сочетатьКод и API

В работе

Раскройте группу и выберите объекты внутри. Отметка родителя показывает, выбрана вся группа или только часть.

Когда использовать

Когда использовать
  • Нужно выбирать объекты, объединённые в реальные группы: территории, подразделения, службы.
Когда выбрать другое
  • Плоский справочник — Фильтр или Выбор нескольких значений.
Правила сочетания
  • Выбор значений

Из чего состоит

  1. Контекст — Выбирает объекты из иерархии групп и дочерних элементов.
  2. Данные и действие — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

Варианты и размеры

Ширина задаётся контейнером; вложенность обозначается отступами. Справочник должен оставаться обозримым.

Класс или параметрЧто делаетКогда
dkTreeSelect(el, opts)Разметка и параметры компонента.При задаче, описанной выше.

Состояния

Группа бывает выбрана целиком, частично или не выбрана. Вложенные пункты можно раскрыть.

Ограничения и подключение

Выбранные leaf ids, parent отражает true/mixed/false. Disabled исключается из выбора и распространяется вниз. До 1000 узлов; без виртуализации. На touch весь ряд 44px выбирает; раскрытие нажатием стрелки, через expand API/клавиатуру.

Текст и подписи

Понятно
  • Полные названия групп и объектов; частичный выбор виден у родителя.
Вызывает вопросы
  • Одинаковые подписи дочерних объектов без контекста группы.

Доступность

  • Tree/Treeitem, aria-level/posinset/setsize, aria-checked mixed. Стрелки/Home/End перемещают, Right/Left раскрывают/сворачивают, Space/Enter выбирают. Поиск сохраняет поле и контекст родителей.
  • Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

С чем сочетать

  • Таблица — точные числа
  • Подключение — dk-theme первым, dk-util до компонента
