🏷️Выбор нескольких значений · ChipsSelect

Выбирает несколько значений из справочника и сохраняет выбранный набор на виду.

Статус: стабильный ПримерКак выбратьС чем сочетатьКод и API

В работе

Выберите несколько пунктов из справочника. Метки сохраняют выбор на виду и позволяют удалить отдельное значение.

Когда использовать

Когда использовать
  • Пользователь выбирает несколько объектов из известного справочника.
  • Выбранный набор важен для задачи и должен оставаться видимым.
Когда выбрать другое
  • Нужно создавать новые значения — Ввод нескольких значений.
  • В компактной строке фильтров достаточно подписи и счётчика — Фильтр.
  • Несколько вариантов должны быть видны одновременно — Флажки.
Правила сочетания
  • Выбор значений
  • Фильтрация

Из чего состоит

2 Приём заявок
3
  1. Подпись — называет выбираемый набор.
  2. Выбранные значения — показывают названия из справочника; каждое можно удалить отдельно.
  3. Список добавления — позволяет выбрать следующее значение из options.

Варианты и размеры

Отдельных размеров нет. Поле и кнопки используют размеры существующих компонентов; выбранные значения переносятся на следующую строку.

Класс или параметрЧто делаетКогда
valueНачальный набор значений.Чтобы показать ранее введённые или выбранные данные.
disabledОтключает изменение набора.Когда поле временно недоступно.
placeholderПодсказка в пустом поле.Для примера ввода; не заменяет подпись.

Состояния

Пустое: видны подпись и поле добавления. Заполненное: каждое значение показано отдельно и доступно для удаления. Отключённое: набор остаётся видимым, изменение недоступно.

Текст и подписи

Понятно
  • Подпись называет набор: «Метки», «Службы».
  • Названия значений сохраняют смысл без соседних элементов.
  • Кнопка удаления называет конкретное значение.
Вызывает вопросы
  • Placeholder вместо постоянной подписи.
  • Все выбранные значения скрыты за счётчиком.
  • Обязательные условия ввода описаны только после ошибки.

Доступность

  • В текстовом поле Enter добавляет значение. Backspace в пустом поле переводит фокус на удаление последней метки; Enter или пробел выполняет удаление.
  • Выбор из списка использует нативный select. Уже выбранные и отключённые варианты недоступны для повторного выбора.
  • Поле имеет постоянную видимую подпись. Кнопки удаления получают доступное название с именем значения.
  • Добавление и удаление должны быть доступны с клавиатуры; фокус остаётся в рабочем контексте поля.
  • Отключённое состояние запрещает изменение, сохраняя выбранные значения для чтения.
  • Проверьте работу с длинными названиями, увеличенным текстом и на телефоне. Полная проверка со скринридером требует отдельного прохода.

С чем сочетать

  • Ввод нескольких значений — произвольные метки
  • Фильтр — компактный выбор из списка
  • Флажки — небольшой набор видимых вариантов

Код и API

Подключите js/dk-chips.js после js/dk-util.js и js/dk-icons.js. Компонент сообщает значения; сохранение и применение фильтра выполняет приложение.

Исходники: css/components.css · js/dk-chips.js

<div id="services"></div>
<script>
var services = dkChipsSelect(document.getElementById('services'), {
  label: 'Службы',
  options: [
    { value: 'requests', label: 'Приём заявок' },
    { value: 'telemetry', label: 'Телеметрия сетей' }
  ],
  value: ['requests'],
  placeholder: 'Выберите службу',
  onChange: function (value) { /* применить выбранные идентификаторы */ }
});
services.value(['telemetry']);
// services.destroy();
</script>

Параметры и методы

ПараметрТипЧто делает
labelстрокаПостоянная подпись поля.
valueмассив строкНачальные значения.
placeholderстрокаПодсказка в поле добавления.
disabledbooleanЗапрет изменения набора.
onChange(value)функцияПолучает новый массив значений после изменения пользователем.
instance.value(nextArray)методБез аргумента возвращает набор; с массивом заменяет значения.
instance.disabled(bool)методБез аргумента возвращает состояние; с boolean переключает доступность.
instance.destroy()методУдаление компонента и его обработчиков.
optionsмассив {value, label, disabled?}Справочник: value — идентификатор, label — видимое название; disabled запрещает выбор пункта.
