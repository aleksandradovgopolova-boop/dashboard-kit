# Доступность служб

Показывает доступность службы по временным интервалам, включая сбои и пропуски.

## Когда использовать

- Служба либо работает, либо нет, и важно, когда именно не работала.
- Несколько служб сравнивают по одной шкале времени.
- Период — сутки или неделя с равными делениями.

## Когда выбрать другое

- Значение, а не да/нет, во времени — График.
- Доля выполненного — Прогресс.
- Событие с длительностью и описанием — Календарь.

## Контент: так

- Название службы так, как её зовут дежурные: «Приём заявок».
- Подпись шага и краёв оси словами: «30 минут», «24 ч назад».
- Процент — от известных делений.

## Контент: не так

- Зелёная полоса там, где замеров не было.
- Легенда, которая появляется только при сбое.
- 100% при половине делений «нет данных».

## Доступность

- Полоса фокусируема и описана целиком в aria-label: сколько делений с перебоями.
- Не только цветом. Легенда со словами; процент числом.
- Подсказка у деления — title: время и состояние.
- Контраст. Три цвета делений различимы между собой в обеих темах — проверка СМЫСЛ.

## Пример

Каждое деление — интервал наблюдения. Легенда отличает нормальную работу, сбой и отсутствие измерений.

## Структура

- **Название службы** — слева, одной строкой.
- **Полоса делений** — dk-uptime__strip: одно деление — один шаг времени; цвет состояния: работает, сбой, нет данных. Углы прямые: деление — это интервал, а не плитка.
- **Доступность** — процент рабочих делений от известных; «нет данных» в знаменатель не входит.
- **Ось** — подписи краёв: откуда и докуда.
- **Легенда** — всегда, даже когда сбоев нет: в момент первого сбоя человек увидит новый цвет и должен знать, что он значит.

## Состояния

Неизвестное состояние — это «нет данных». Значение вне трёх известных не даёт невидимого деления и подписи «undefined»: оно рисуется как отсутствие данных и считается так же.

## Варианты

- `rows[].data` — Массив состояний: 'up' | 'down' | 'none'. Каждая служба.
- `step` — Подпись шага: «30 минут». Идёт в подсказку деления.
- `labels` — Подписи краёв оси. ['24 ч назад', 'сейчас'] по умолчанию иначе.

## Размеры

Полоса занимает ширину виджета; деления соответствуют выбранным интервалам. Для длинного ряда укрупняйте интервалы, чтобы состояния оставались различимы.

## Код

```html
<div id="uptime"></div>

<script>
var u = dkUptime(document.getElementById('uptime'), {
  step: '30 минут',
  labels: ['24 ч назад', 'сейчас'],
  rows: [
    { name: 'Приём заявок', data: ['up', 'up', 'down', 'up', 'none'] }
  ]
});
u.setRows(newRows);
</script>
```

## Параметры

- `rows[]` (массив {name, data[]}): Состояния делений: 'up', 'down', 'none'.
- `step` (строка): Подпись шага для подсказки.
- `labels` (массив из двух строк): Края оси.
- `setRows(list)` (метод): Обновить данные.
