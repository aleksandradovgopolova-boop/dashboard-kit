# Стекло (глассморфизм) — статус и как продолжить

Эталон вкуса — рефы Google/Gemini: матовое стекло, цветная подложка-vibrancy,
светящийся ореол на фокусе/активном, плавающие пилюли, круглые иконки-кнопки.
Данные остаются **плотным цветом**; стеклом красится только «обвязка» (панели,
контролы, оверлеи, подложка). Всё машинно проверяется `tools/check.py` (26
проверок) — держать зелёным перед коммитом.

## Архитектура

- **Токены** — `css/tokens.primitives.css` (сырьё) → `css/tokens.semantic.css`
  (смысл). Стекло: `--glass-surface/-surface-2/-chip`, `--glass-edge/-edge-soft`,
  `--glass-sheen`, `--glass-blur/-blur-sm`, `--glass-vibrancy/-sm`,
  `--glass-hover/-hover-strong`, `--glass-glow-1..4/-c` (подложка),
  `--glass-focus-glow/-primary-glow/-active-glow` (свечение). Радиусы: добавлен
  `--round-6: 28px` → `--radius-2xl` (крупное скругление, нижнее меню).
- **Слой дашборда** — `css/glass.css`, включается классом **`dk-glass`** на
  `.dk-page`. Отключаемый: нет класса — страница плоская (так документация кита
  и встроенные блоки остаются нейтральными). Даёт цветную подложку, матовые
  панели/каркас/оверлеи, свечение на фокусе. Зарегистрирован в
  `tools/manifest_parts.py` (CSS_ORDER после chrome.css; часть `glass`) и в
  `tools/build-manifest.py` → `CSS_FILES` (чтобы класс `dk-glass` считался
  определённым). После правок: `python3 tools/build-manifest.py`.
- **Компоненты** — общий стеклянный язык кнопок/фильтров/сегментов/чипов/бейджей
  лежит в `css/components.css` (секция «СТЕКЛО: общие компоненты», действует
  везде). Заголовок виджета сведён к одному стилю — нежирный капс
  (`--type-overline-regular`), и у `.dk-widget__title`, и у `.dk-tile__label`.

## Включено на страницах (класс `dk-glass`)

`dashboard.html`, `regions.html`, `mobile.html`, `accidents.html`,
`ai-value.html`, `calendar.html`. **НЕ** включать: `index.html`, `showcase.html`,
`component-*.html` (документация кита — нейтральная); `grid.html` — эталон
размеров, намеренно нейтральный.

## Сделано

- Токены стекла + подложка (насыщенность с упором в центр, чтобы читалось и на
  плотных дашбордах).
- Панели, каркас (меню/шапка/таб-бар), оверлеи (меню, поповер, модалка,
  подсказка, аккордеон), карусель, фильтры (пустые и заполненные), зум карты,
  клетки календаря, строки-карточки таблицы, легенды карты — на стекле.
- Цвет на стекле: данные плотные, статус-обвязка (трендовые пилюли, бейджи) —
  цветное стекло; зазор секторов круговой диаграммы сделан прозрачным
  (`tools/build-chart-theme.py`).
- Единый заголовок виджета (капс, не жирный); убраны подписи «Демонстрационные
  данные…»; выравнивание шапки виджета по верху (отступ сверху = слева); зазор
  под шапкой страницы; нативные треугольники `▶`/глифы дерева (`▾▸☑◩☐`) заменены
  иконками кита.
- Свечение на фокусе/активном; у поиска убрано жёсткое синее кольцо (роль берёт
  box-shadow-свечение — a11y-проверка его засчитывает). Нижнее меню телефона —
  скругление 28px. Одиночные иконки-кнопки — круглые.

## Осталось (для продолжения)

1. **Таблица в карточном режиме** (`.dk-table--cards`): сорт-пилюли-заголовки
   `th:is([aria-sort], .dk-th-pick)` и ячейка `.dk-td-num` ещё плотные
   (`--surface-3`). У правила тройная специфичность
   (`.dk-table--cards.dk-table--cards.dk-table--cards > thead > …`) — чтобы
   перебить в `glass.css`, нужен селектор такой же/выше специфичности под
   `.dk-glass`. Видно на `accidents.html` узким экраном.
2. **Рефы, следующий пункт:** нижние контролы как отдельные плавающие стеклянные
   пилюли (сейчас цельная панель-меню). Более заметная перекройка нижней
   навигации — согласовать с владельцем.
3. Пройтись по оставшимся `component-*` страницам, если решим включать стекло в
   документацию (сейчас намеренно нет).

## Как проверять

- `python3 tools/check.py` — обязана быть зелёной («Система цела»).
- Поиск плотных «плашек» на дашборде (вставить в консоль страницы с `dk-glass`):

```js
const opaque=['rgb(24, 25, 30)','rgb(31, 33, 40)','rgb(37, 39, 47)','rgb(48, 51, 61)'];
const dataRe=/dk-(map__tile|bar|spark|chart|rank__v|dot|i|trend|badge|cal__e|cal__t|bullet|map__canvas|tile__spark)/;
const hits={};
document.querySelectorAll('.dk-glass *').forEach(e=>{const c=getComputedStyle(e),r=e.getBoundingClientRect();
  if(r.width<60||r.height<24||dataRe.test(e.className))return;
  if(opaque.includes(c.backgroundColor)){const k=[...e.classList].filter(x=>x.startsWith('dk-')).slice(0,2).join('.')||e.tagName;hits[k]=(hits[k]||0)+1;}});
console.table(hits); // пусто = плотных поверхностей нет
```

## Паттерн фикса плотной поверхности

- Непрозрачный фон на панели/контроле → заменить на стеклянный токен:
  крупная панель — `var(--glass-sheen), var(--glass-surface)` + blur + edge;
  вложенная/мелкая — `var(--glass-chip)` (без своего blur, чтобы не мутить).
- Если плотность задаёт **страничное ID-правило** (`#id .dk-… { background: var(--bg|--surface) }`),
  оно бьёт слой стекла по специфичности — убрать фон из страничного CSS или
  поднять специфичность стеклянного правила.
- Не добавлять `border` там, где элемент — тач-цель 44px (border-box ужмёт
  инпут ниже 44 → упадёт проверка ТЕЛЕФОН). Хватает фона-стекла.
- Данные (плитки карты, полосы, серии графиков, крупные числа) **не трогать**.
