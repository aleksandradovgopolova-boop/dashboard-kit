# Сравнение периодов

Сравнивает показатель за два периода и показывает абсолютное и относительное изменение.

## Когда использовать

- Нужно объяснить изменение KPI или сопровождать временной график.

## Когда выбрать другое

- Несопоставимые периоды или разные единицы: сначала приведите данные к общей базе.

## Контент: так

- «Март: 120; февраль: 100; изменение: +20%».

## Контент: не так

- Сравнение полного месяца с текущим неполным без пояснения.

## Доступность

- Рост/снижение названы словами, смысл дельты не определяется только знаком. Текст переносится и подходит для компактного KPI. Скринридер получает оба числа.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Сверьте оба значения и изменение. Рост сам по себе не означает улучшение.

## Структура

- **Контекст** — Показывает текущий и предыдущий показатель, абсолютную и относительную дельту.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

При previous=0 процент не определён. Нет данных не превращается в ноль. По умолчанию направление нейтрально. Процент считается по модулю предыдущего значения; отрицательная база требует объяснения.

## Варианты

- `dkComparison(current, previous, better)` — Основной контракт API/markup. При задаче, описанной выше.

## Размеры

Компактный блок помещается в KPI. Значения с единицами сохраняются, пояснения переносятся.

## Код

```html
<div id="advanced-comparison"></div>
<script>
document.addEventListener("DOMContentLoaded", function(){
dkPeriodComparison(document.getElementById('advanced-comparison'), {label:'Аварии за сутки',current:23,previous:19,better:'decrease'});
});
</script>
```

## Параметры

- `dkComparison(current, previous, better)` (чистая функция): Возвращает delta, percent, direction, meaning. better: increase/decrease/neutral.
- `dkPeriodComparison(el, opts)` (API): current, previous, better, label, unit; update(opts), destroy().
