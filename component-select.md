# Фильтр

Ограничить срез данных одним или несколькими значениями из известного списка. Главное правило: выбранное видно, не открывая меню, — иначе человек смотрит на срез и уверен, что видит всё.

## Когда использовать

- Значения известны заранее и их больше пяти: категории, статусы, исполнители.
- Выбор ограничивает данные на всей странице и применяется сразу.
- Рядом с каждым значением можно показать, сколько записей за ним.

## Когда выбрать другое

- Два–пять значений, видимых сразу, — Сегмент или Фильтры-легенда.
- Даты — Период.
- Ввод значения в форме, которое применяется по кнопке, — Поле с .

## Контент: так

- Подпись — название измерения: «Округ», «Уровень риска»; после выбора — «Округ: Сибирский».
- Число записей рядом с каждым значением.
- Строка применённых фильтров под панелью со «Сбросить всё» (dk-chipbar).

## Контент: не так

- «Все округа» после выбора — самая дорогая ошибка дашборда.
- «Выбрано несколько» вместо числа.
- Фильтр без счётчика результата: человек выбирает вслепую и попадает в пустой экран.

## Доступность

- Роли. Кнопка с aria-haspopup="listbox" и aria-expanded; меню — listbox с option и aria-selected.
- Клавиатура. Стрелки, Home, End, Enter, Escape с возвратом фокуса на фильтр. Поиск получает фокус при открытии.
- Не только цветом. Выбранное отмечено галочкой; активный фильтр — ещё и текстом подписи.
- Контраст. Серая заливка активного фильтра поверх поля — 1,19–1,28:1, как у прежней синей (проверка ТИШИНА).

## Размеры

Высота как у контролов: M по умолчанию, size: 'sm' для шапки виджета. Ширина по подписи; длинная подпись переносится и остаётся видимой целиком.

## Код

```html
<!-- Строка фильтров — прямо на странице, над содержимым. На телефоне она
     становится строкой пилюль, которая листается вбок. -->
<div class="dk-toolbar">
  <div class="dk-toolbar__group">
    <div id="period"></div>
    <div id="okrug"></div>
  </div>
</div>

<script>
var f = dkSelect(document.getElementById('okrug'), {
  label: 'Округ',
  options: [{ value: 'sfo', name: 'Сибирский', count: 10 }, /* … */],
  mode: 'single',        // или 'multi'
  url: 'okrug',          // ?okrug=sfo — ссылка на срез
  onChange: function (value) { /* строка или массив (multi) */ }
});
f.value;                 // текущее
f.set('sfo'); f.clear(); f.setOptions(list);
</script>
```

## Параметры

- `label` (строка): Название измерения; после выбора становится «Название: значение».
- `options[]` (массив {value, name, count}): Значения; count — записей за значением, ноль не прячется.
- `mode` ('single' | 'multi'): Одиночный закрывает меню, множественный — нет.
- `value` (строка | массив): Начальное значение; адрес (url) главнее.
- `search` (boolean): Поле поиска; по умолчанию от 9 значений.
- `url` (строка): Ключ в строке запроса; пусто — не пишется.
- `onChange(v)` (функция): При каждой смене выбора.
- `value / set(v) / clear() / setOptions(list)` (API): Читать и менять снаружи.
