# Фильтр

Ограничивает данные выбранными значениями из списка. Текущий выбор виден в закрытом фильтре.

## Когда использовать

- Нужно ограничить срез известными значениями: категориями, статусами, исполнителями.
- Выбор применяется сразу и отражается в связанных показателях. Область действия фильтра понятна.
- Для длинного списка нужен поиск; количество записей рядом со значением помогает оценить выбор.

## Когда выбрать другое

- Два–пять значений, видимых сразу, — Сегмент или Фильтры-легенда.
- Даты — Период.
- Ввод значения в форме, которое применяется по кнопке, — Поле с .

## Контент: так

- Подпись — название измерения: «Округ», «Уровень риска»; после выбора — «Округ: Сибирский».
- Число записей рядом с каждым значением.
- Выбранное значение внутри самого фильтра; общий сброс-иконка появляется только при изменённом срезе.

## Контент: не так

- «Все округа» после выбора — самая дорогая ошибка дашборда.
- «Выбрано несколько» вместо числа.
- Фильтр без счётчика результата: человек выбирает вслепую и попадает в пустой экран.

## Доступность

- Роли. Кнопка с aria-haspopup="listbox" и aria-expanded; меню — listbox с option и aria-selected.
- Клавиатура. Стрелки, Home, End, Enter, Escape с возвратом фокуса на фильтр. Поиск получает фокус при открытии.
- Не только цветом. Выбранное отмечено галочкой; активный фильтр — ещё и текстом подписи.
- Контраст. Активный фильтр различим по подписи и мягкому тону поверхности; клавиатурный фокус виден отдельно.

## Пример

Выберите значение из списка или найдите его поиском. Выбранный фильтр остаётся виден после закрытия; его можно сбросить.

## Структура

- **Активный фильтр** — data-active="true": серая заливка поверх поля и подпись «Округ: Сибирский» — выбранное видно, не открывая меню.
- **Стрелка** — поле с меню; aria-expanded говорит скринридеру, открыто ли.
- **Счётчик** — dk-select__count: сколько значений выбрано в множественном фильтре.
- **Последствие** — dk-result: сколько записей осталось после фильтра — то, что человек обязан видеть сразу.
- **Поиск** — появляется сам, когда значений больше восьми.
- **Пункт** — role="option"; выбранный отмечен галочкой, а не только цветом.
- **Число записей** — за каждым значением; ноль показывается приглушённым, а не прячется.

## Состояния

Пусто: Округ Выбрано: Сибирский Открыт Недоступен Пустой список — не пустое меню. Если под текущий срез не осталось значений, меню говорит «Ничего не найдено» и предлагает снять поиск; молча пустой список читается как поломка.

## Варианты

- `mode: 'single'` — Один вариант; выбор применяется и закрывает меню. По умолчанию.
- `mode: 'multi'` — Несколько; меню остаётся открытым, есть «Выбрать все». Уровни, виды работ.
- `search: true | false` — Поле поиска в меню. Само включается от 9 значений.
- `size: 'sm'` — Компактная высота через --control-sm; на таче цель не меньше 44 px. Шапка виджета.
- `url: 'ключ'` — Значение пишется в адрес и читается при открытии. Всегда на дашбордах — ссылка на срез.

## Размеры

Высота и радиус из общей шкалы контролов; в стеклянной теме обычный контрол — 44 px, size: 'sm' для шапки виджета. Ширина по подписи; длинная подпись переносится и остаётся видимой целиком.

## Код

```html
<!-- Строка фильтров — прямо на странице, над содержимым. На телефоне она
     переносится по доступной ширине. -->
<div class="dk-toolbar">
  <div class="dk-toolbar__group">
    <div id="period"></div>
    <div id="okrug"></div>
  </div>
</div>

<script>
var f = dkSelect(document.getElementById('okrug'), {
  label: 'Округ',
  options: [{ value: 'sfo', name: 'Сибирский', count: 10 }, /* … */],
  mode: 'single',        // или 'multi'
  url: 'okrug',          // ?okrug=sfo — ссылка на срез
  onChange: function (value) { /* строка или массив (multi) */ }
});
f.value;                 // текущее
f.set('sfo'); f.clear(); f.setOptions(list);
</script>
```

## Параметры

- `label` (строка): Название измерения; после выбора становится «Название: значение».
- `options[]` (массив {value, name, count}): Значения; count — записей за значением, ноль не прячется.
- `mode` ('single' | 'multi'): Одиночный закрывает меню, множественный — нет.
- `value` (строка | массив): Начальное значение; адрес (url) главнее.
- `defaultValue` (строка): Исходное значение одиночного фильтра, например all. Без активной заливки и крестика; clear() возвращает его.
- `search` (boolean): Поле поиска; по умолчанию от 9 значений.
- `url` (строка): Ключ в строке запроса; пусто — не пишется.
- `onChange(v)` (функция): При каждой смене выбора.
- `value / set(v) / clear() / setOptions(list)` (API): Читать и менять снаружи.
- `update({value,options}) / destroy()` (API): Тихое обновление; cleanup меню, focusout, anchor и подписок. Старые set/clear/setOptions сохранены.
