# Поиск

Находит объекты по названию и позволяет быстро очистить запрос.

## Когда использовать

- Объектов много, и человек знает имя нужного: регион, дом, котельная.
- Верх экрана на телефоне: поиск и дата данных — одной строкой над фильтрами.
- Список или таблица под поиском фильтруется по вводу.

## Когда выбрать другое

- Значений до двадцати и их надо видеть списком — Фильтр, в нём поиск уже есть.
- Поле в форме заявки — Поле и форма, dk-field--search.
- Ограничить срез по времени — Период.

## Контент: так

- Подсказка называет, что ищут: «Регион или округ».
- Дата короткая: «29.09», полная — в title.
- Ничего не нашлось — пустое состояние с тем, что сделать, а не пустота.

## Контент: не так

- «Поиск…» — не сказано, что искать.
- Поиск без подписи для скринридера: подсказка не подпись.
- Две строки поиска на экране.

## Доступность

- Подпись — aria-label на поле: подсказка исчезает при вводе и подписью не считается.
- Крестик — кнопка с aria-label="Очистить поиск", цель 44 px; после очистки фокус в поле.
- Фокус виден кромкой и кольцом акцента, а не только курсором.

## Пример

Поле принимает запрос и позволяет очистить его одним действием. Фильтрацию записей подключает приложение; сам пример данные не ищет.

## Структура

- **Значок** — dk-search__icon: говорит «поиск» до того, как прочитана подсказка.
- **Поле** — dk-search__input, type="search", кегль 16: меньше iOS увеличивает страницу при фокусе.
- **Дата данных** — dk-search__at: за какой день числа на экране. Пока ищут — прячется, на её месте крестик dk-search__clear.

## Состояния

29.09 29.09

## Варианты

- `dk-search` — Строка поиска на доске: нейтральная поверхность и тонкая кромка. Верх экрана, над фильтрами.
- `внутри dk-panel / dk-widget` — Та же строка, плоская. Поиск по списку внутри блока.
- `dk-search__at` — Дата, на которую данные. Если данные не «сейчас», а на день.
- `dk-search__clear` — Крестик очистки. Всегда: появляется сам, когда в поле есть текст.

## Размеры

В стеклянной теме высота согласована с фильтрами и кнопками через --control-lg. Ширина определяется строкой управления; поиск не должен вытеснять другие действия за экран.

## Код

```html
<div class="dk-search">
  <svg class="dk-i dk-search__icon" aria-hidden="true"><use href="#ti-search"/></svg>
  <input class="dk-search__input" type="search" placeholder="Регион или округ"
         aria-label="Найти регион или округ" enterkeyhint="search" autocomplete="off">
  <button type="button" class="dk-search__clear" aria-label="Очистить поиск">
    <svg class="dk-i" aria-hidden="true"><use href="#ti-x"/></svg></button>
  <span class="dk-search__at" title="Данные на 29 сентября">29.09</span>
</div>

<script>
document.querySelector('.dk-search__input').addEventListener('input', function (e) {
  /* фильтровать по e.target.value; пустая строка — показать всё */
});
</script>
```

## Параметры

- `dk-search__input` (input type=search): Поле; страница слушает input.
- `dk-search__clear` (кнопка): Очистка без подключения: dk-util.js.
- `dk-search__at` (элемент): Дата данных; необязательна.
- `aria-label` (атрибут поля): Подпись для скринридера — обязательна.
