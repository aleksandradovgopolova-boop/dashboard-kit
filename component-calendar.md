# Календарь работ

Показ работы: что происходит и когда. Не выбор периода. Цвет события — его вид, а не украшение: авария красная, плановое синее, завершённое зелёное.

## Когда использовать

- События привязаны к датам, и важно видеть их вместе: работы, отключения, проверки.
- Нужен и обзор месяца, и подробности недели по часам.
- События бывают нескольких видов с разным смыслом.

## Когда выбрать другое

- Выбор интервала дат для среза — Период.
- Лента последних событий без дат — Список.
- Работала служба или нет по времени — Доступность служб.

## Контент: так

- Название события — что делают: «Замена задвижки», «Подвоз воды».
- Вид события по смыслу: авария crit, ограничение high, плановое plan, завершено calm, прочее event.
- Дни соседних месяцев показаны приглушённо.

## Контент: не так

- Цвета розданы по кругу — человек ищет закономерность там, где её нет.
- Сетка в пять строк в короткий месяц — страница прыгает.
- Событие без времени в недельном виде.

## Доступность

- Клавиатура. Дни — кнопки; стрелки, Home, End, PageUp, PageDown, Enter — как в таблице.
- Не только цветом. У события есть название; вид дублируется значком в подсказке.
- Сегодня помечено атрибутом и цветом.
- Не проверялось со скринридером в недельном виде по часам.

## Размеры

Размер один: виджет L на всю ширину. Сетка месяца всегда шесть строк, чтобы страница не прыгала при перелистывании; высота часа в неделе — hourHeight, по умолчанию 48.

## Код

```html
<div id="cal"></div>

<script>
var cal = dkCalendar(document.getElementById('cal'), {
  view: 'month', month: '2026-09-01',
  events: [
    { date: '2026-09-14', name: 'Прорыв, Советский р-н', kind: 'crit' },
    { date: '2026-09-14', from: '08:00', to: '13:00', name: 'Плановое отключение ГВС', kind: 'plan' }
  ],
  onSelect: function (day) { },
  onEvent: function (e) { }
});
cal.view = 'week'; cal.goTo('2026-09-14'); cal.setEvents(list);
</script>
```

## Параметры

- `events[]` (массив): date, name, kind; from/to для недели.
- `view, month, week, value, today` (строки / даты): Что показать и что выбрано.
- `max, hourHeight` (числа): Событий в дне до «ещё N»; высота часа.
- `onSelect(day) / onEvent(e)` (функции): Клик по дню и по событию.
- `view / value / goTo(d) / setEvents(list)` (API): Управление снаружи.
- `update({events,view}) / destroy()` (API): Совместим со старым setEvents/view/goTo. На narrow/coarse неделя — agenda со временем словами и кнопками 44px, на desktop/fine — часовая сетка.
