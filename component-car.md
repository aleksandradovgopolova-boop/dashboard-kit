# Лента карточек

Показывает последовательность карточек, у каждой из которых свой контекст.

## Когда использовать

- Нужно последовательно рассмотреть несколько значимых изменений, у каждого есть свой контекст.
- Сравнивать карточки одновременно не требуется. Лента добавляется по задаче, а не как обязательный блок первого экрана.

## Когда выбрать другое

- Объектов больше семи или их надо сравнивать между собой — Рейтинг или Таблица: в ленте видна одна карточка за раз.
- Одно число с тем, из чего оно сложено — Главная карточка.
- Список событий по времени — Список.

## Контент: так

- Заголовок отвечает, почему эти карточки вместе: «Резко выросли за день».
- Было → стало числами: «30 → 57».
- Рассказ — причина: «авария теплосети», а не «рост показателя».

## Контент: не так

- Карточки нужно сравнивать, но одновременно видна только одна.
- Длинная лента без перехода к полному списку.
- Пустая лента без объяснения, что изменений нет.

## Доступность

- Лента — список: ul role="list", карточки — пункты; скринридер называет, сколько их.
- Позиция словами: счётчик «1 из 3»; точки скрыты от скринридера (aria-hidden).
- Было → стало — aria-label на паре чисел: «было 30, стало 57», стрелка скрыта.
- Стрелки — кнопки с подписью; на краях ленты отключаются.

## Пример

Каждая карточка объясняет отдельное изменение. Лента подходит для последовательного просмотра; сравнивать объекты удобнее в рейтинге или таблице.

## Структура

- **Заголовок ленты** — dk-car__title: что объединяет карточки.
- **Счётчик** — dk-car__pos «1 из 3» — словами; точки под лентой только подсказка.
- **Метки** — dk-car__tags: пилюли dk-trend — почему карточка здесь.
- **Кто** — dk-car__name и dk-car__sub: объект и где он.
- **Было → стало** — dk-car__change: прежнее мельче, нынешнее крупным числом смысла.
- **Рассказ** — dk-car__text, две строки: причина словами.

## Состояния

Сегодня резких изменений нет Ни один регион не вырос больше чем на 10 баллов за сутки. Лента вернётся, когда изменения появятся.

## Варианты

- `--accent на dk-car__item` — Оттенок карточки по смыслу. Свой у каждой: разные объекты — разный риск.
- `--from / --to` — Цвет прежнего и нынешнего значения. Смысл значения: high-ink, crit-ink.
- `a.dk-car__item / button.dk-car__item` — Карточка-ссылка или кнопка. Если карточка открывает объект.
- `dk-car__nav` — Стрелки назад и вперёд. Всегда в разметке; видны только с мышью.

## Размеры

Карточка 300 px, но не шире 82% экрана: на телефоне от следующей остаётся видимая полоса. Размер один.

## Код

```html
<div class="dk-car" id="car">
  <div class="dk-car__head">
    <h3 class="dk-car__title">Резко выросли за день</h3>
    <span class="dk-push dk-car__pos">1 из 5</span>
    <span class="dk-car__nav">
      <button type="button" class="dk-iconbtn dk-iconbtn--sm" data-car="prev" aria-label="Предыдущая">…</button>
      <button type="button" class="dk-iconbtn dk-iconbtn--sm" data-car="next" aria-label="Следующая">…</button>
    </span>
  </div>
  <ul class="dk-car__track" role="list">
    <li class="dk-car__item" style="--accent:var(--crit)">
      <span class="dk-car__tags"><span class="dk-trend" style="--accent:var(--crit-ink)">+27 за день</span></span>
      <span class="dk-car__row">
        <span class="dk-car__who"><span class="dk-car__name">Санкт-Петербург</span><span class="dk-car__sub">СЗФО</span></span>
        <span class="dk-car__change" aria-label="было 30, стало 57">
          <span class="dk-car__from">30</span><span class="dk-car__arrow" aria-hidden="true">→</span>
          <span class="dk-car__to" style="--to:var(--crit-ink)">57</span></span>
      </span>
      <p class="dk-car__text">Авария теплосети; отключения ГВС и отопления.</p>
    </li>
  </ul>
  <div class="dk-car__dots"></div>
</div>

<script>
var car = dkCar(document.getElementById('car'));
car.index;    // текущая карточка
car.go(2);    // пролистать к третьей
</script>
```

## Параметры

- `dkCar(el)` (функция): Оживляет разметку ленты; возвращает управление.
- `index` (число, чтение): Номер текущей карточки, с нуля.
- `go(i)` (функция): Пролистать к карточке; движение гасится системной настройкой.
- `destroy()` (функция): Снять обработчики; сторож dk-util.js сделает это сам, когда узел уйдёт.
