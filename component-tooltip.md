# Подсказка

Короткое дополнительное объяснение показателя без перекрытия рабочего потока.

## Когда использовать

- Нужно объяснить термин рядом с его употреблением.

## Когда выбрать другое

- Критические инструкции или интерактивные ссылки: используйте видимый текст или details sidebar.

## Контент: так

- Нужно объяснить термин рядом с его употреблением.
- Показывайте полные названия, единицы и источник данных.

## Контент: не так

- Критические инструкции или интерактивные ссылки: используйте видимый текст или details sidebar.
- Не выдавайте отсутствие наблюдений за ноль и не используйте цвет как единственное объяснение.

## Доступность

- Фокус/мышь показывают, Escape закрывает только подсказку; вложенный dialog остаётся открытым. Касание кнопки переключает. aria-describedby сохраняет прежние ссылки. Подсказка не содержит фокусируемых элементов.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Размеры

Компонент следует ширине контейнера и системным токенам. Фокус/мышь показывают, Escape закрывает только подсказку; вложенный dialog остаётся открытым. Касание кнопки переключает. aria-describedby сохраняет прежние ссылки. Подсказка не содержит фокусируемых элементов.

## Код

```html
<button type="button" class="dk-btn" id="advanced-tooltip">Что значит риск?</button>
<script>
document.addEventListener("DOMContentLoaded", function(){
dkTooltip(document.getElementById('advanced-tooltip'), {text:'Риск — оценка по текущим порогам, не прогноз.'});
});
</script>
```

## Параметры

- `dkTooltip(trigger, {text})` (API): Именованная кнопка. show(), hide(), update({text}), destroy().
