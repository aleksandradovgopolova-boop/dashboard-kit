# Подсказка

Кратко объясняет термин или действие рядом с местом его использования.

## Когда использовать

- Нужно объяснить термин рядом с его употреблением.

## Когда выбрать другое

- Критические инструкции или интерактивные ссылки: используйте видимый текст или details sidebar.

## Контент: так

- Короткое определение рядом с непонятным термином.

## Контент: не так

- Обязательная инструкция, спрятанная только в подсказке.

## Доступность

- Фокус/мышь показывают, Escape закрывает только подсказку; вложенный dialog остаётся открытым. Касание кнопки переключает. aria-describedby сохраняет прежние ссылки. Подсказка не содержит фокусируемых элементов.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Наведите указатель или переведите фокус на кнопку. Escape закрывает пояснение.

## Структура

- **Контекст** — Короткое дополнительное объяснение показателя без перекрытия рабочего потока.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Скрытая, открытая. Удаление trigger освобождает подсказку и глобальные обработчики. Без JS остаётся кнопка: обязательное объяснение пишите в тексте.

## Варианты

- `dkTooltip(trigger, {text})` — Основной контракт API/markup. При задаче, описанной выше.

## Размеры

Ширина ограничена окном; короткий текст переносится. Для длинного объяснения используйте видимый текст.

## Код

```html
<button type="button" class="dk-btn" id="advanced-tooltip">Что значит риск?</button>
<script>
document.addEventListener("DOMContentLoaded", function(){
dkTooltip(document.getElementById('advanced-tooltip'), {text:'Риск — оценка по текущим порогам, не прогноз.'});
});
</script>
```

## Параметры

- `dkTooltip(trigger, {text})` (API): Именованная кнопка. show(), hide(), update({text}), destroy().
