# Хедер страницы

Собирает название экрана, его контекст и общие действия из типографики, подписей и контролов кита.

## Когда использовать

- Нужен общий заголовок самостоятельной страницы или встраиваемого дашборда.

## Когда выбрать другое

- Заголовок одной карточки — хедер виджета.
- Путь по иерархии — компонент breadcrumbs; не маскировать под него описание экрана.

## Контент: так

- Название отвечает «что здесь», подпись уточняет контекст.
- Общий период применяется ко всем связанным блокам; ограничение явно подписано.

## Контент: не так

- Фиксированная высота и обрезанный заголовок.
- Фиктивная дата обновления или кнопка без результата.
- Повторять один общий фильтр в каждой карточке.

## Доступность

- Заголовки передают иерархию: один h1 страницы, h2 виджетов; в живых примерах справочника уровень сдвинут на один.
- Название не обрезается многоточием. При увеличении текста хедер растёт, действия переносятся.
- Переход — ссылка, изменение состояния — кнопка с доступным именем; декоративные SVG скрыты от скринридера.
- Цвет не заменяет текст состояния. Клавиатурный фокус остаётся видимым, сенсорная цель не меньше 44 px.

## Размеры

Название — --type-overview-title (32/36), на телефоне --type-h2. Подзаголовок — --type-body. Между ними --space-2; между группами --space-7. Внешние поля и липкость задаёт каркас, сам dk-head их не добавляет.

## Код

```html
<header class="dk-head">
  <div class="dk-head__titles">
    <h1 class="dk-head__title">Сводка по стране</h1>
    <p class="dk-head__subtitle">Мониторинг рисков в ЖКХ</p>
  </div>
  <div class="dk-head__actions">
    <span class="dk-caption">Демонстрационные данные за 30 дней</span>
    <a class="dk-btn dk-btn--sm" href="dashboard.html">Открыть сводку</a>
  </div>
</header>
```

## Параметры

- `dk-head` (HTML/CSS): Самостоятельный компонент без JS. Для каркаса страницы kit.py head page-header chrome.
- `Атомы` (Состав): Типографика + подпись + button/period/segment. Поведение контролов задают их API.
