# Счётчик

Показывает количество объектов рядом с названием раздела или действия.

## Когда использовать

- Количество объектов внутри кнопки, вкладки или строки меню.

## Когда выбрать другое

- Главное число дашборда — KPI-плитка.
- Состояние объекта — статус с текстовой подписью.

## Контент: так

- Только число: 12; для больших значений — 99+ с точным доступным именем.
- Название объекта находится рядом: «Сообщения 12».

## Контент: не так

- Слово «новое» внутри счётчика — это бейдж.
- Цвет ошибки для обычного количества объектов.

## Доступность

- Внутри подписанной кнопки число входит в её доступное имя.
- Для 99+ укажите точное число и объект в aria-label.
- Ноль показывайте только если отсутствие объектов важно для решения; скрытие счётчика не должно менять размер кнопки.

## Пример

Сравните короткое и длинное число. Счётчик дополняет название, а не заменяет его.

## Структура

- **Содержимое** — Подпись и значение доступны без цвета.
- **Контекст** — Находится рядом с объектом, к которому относится.

## Состояния

Пусто 0 Один объект 1 Большое количество 99+

## Варианты

- `dk-counter` — Нейтральная заливка. Количество объектов.
- `dk-counter--sm` — Меньший размер. Компактный контекст.
- `dk-counter--brand` — Акцентная заливка. Новые объекты.
- `dk-counter--crit` — Критическое состояние. Число ошибок.
- `dk-counter--plain` — Без заливки, цвет контекста. Внутри акцентной кнопки.
- `Внутри dk-btn--primary` — Автоматическая контрастная заливка. Основная кнопка.

## Размеры

S — 16, M — 20 пикселей по высоте. Ширина растёт с числом; счётчик не является отдельной кнопкой.

## Код

```html
<button class="dk-btn dk-btn--sm">Сообщения <span class="dk-counter">12</span></button>
```

## Параметры

- `dk-counter` (класс): Нейтральная заливка.
- `dk-counter--sm` (класс): Меньший размер.
- `dk-counter--brand` (класс): Акцентная заливка.
- `dk-counter--crit` (класс): Критическое состояние.
- `dk-counter--plain` (класс): Без заливки, цвет контекста.
