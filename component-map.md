# Регионы: карта и плитки

Два вида на одних данных. Карта отвечает «где», плитки — «у кого хуже»: на карте площадь региона перебивает его значение. Переключатель — часть виджета, а не настройка.

## Когда использовать

- Показатель задан по регионам, и важно «где» — карта.
- Важно сравнить регионы между собой равным весом — плитки.
- Нужен доступ с клавиатуры — плитки: карта нарисована на canvas.

## Когда выбрать другое

- Топ-5 регионов — Рейтинг.
- Несколько показателей на регион — Таблица.
- Динамика одного региона — График.

## Контент: так

- Пороги в легенде числами: «55–68», не «средне».
- Единица измерения один раз, справа от легенды.
- Сокращения регионов из файла раскладки — постоянные.

## Контент: не так

- Произвольная радуга вместо лестницы одного тона или осмысленной палитры риска с явными порогами.
- Ноль вместо «нет данных».
- Карта без переключателя на плитки — без мыши данных не получить.

## Доступность

- Плитки — кнопки с aria-label «регион · значение»; по сетке ходят стрелками, tabindex один на всю сетку.
- Карта недоступна с клавиатуры (canvas) — поэтому плитки обязательны, а не опция.
- Шкала — по умолчанию пять последовательных ступеней; palette: risk с двумя порогами даёт три состояния. Пороги и единица остаются в легенде.
- «Нет данных» в тёмной теме 1,69:1 к поверхности — ниже нормы; открыто в HANDOFF.md (ровная заливка и подпись «Нет данных»).

## Размеры

Размер один: карта 420 px высотой (280 на узком экране), плитки 19×11 клеток по ширине виджета. Для подробного сравнения — L. Компактная карта обзора даёт ориентир и переход к подробному экрану; плитки и числовая альтернатива сохраняются.

## Код

```html
<div class="dk-widget">
  <div class="dk-widget__head"><h3 class="dk-widget__title">Регионы</h3></div>
  <div id="regions"></div>
</div>

<script>
var m = dkMap(document.getElementById('regions'), {
  topo: topojson, object: 'ru89',      // контуры
  tiles: tilesJson,                    // раскладка плиток
  values: { 'RU-CR': 82, 'RU-NVS': 73 },
  unit: 'баллов риска',
  // controls не нужен: в виджете с шапкой переключатель встанет туда сам
  onSelect: function (id, value) { }
});
m.view = 'tiles';
m.setValues(next);                     // шкала пересчитается
</script>
```

## Параметры

- `topo, object / geo` (объект): Контуры регионов.
- `tiles` (объект): Раскладка плиток.
- `values` ({id: число}): Значения; отсутствие — «нет данных».
- `unit, steps, min, max` (строка, массив, числа): Легенда и шкала.
- `palette` ('risk'): С двумя порогами steps — risk-area-low/medium/high по возрастанию риска. Это заливки областей, не цвет текста или небольших значков; пороги и значения обязательны. Иначе остаётся последовательная шкала.
- `controls` (селектор | элемент | false): Куда поставить сегмент. По умолчанию — в шапку своего виджета.
- `onSelect(id, value)` (функция): Клик по региону или плитке.
- `scope / setScope(ids)` (массив id | null): Регионы в срезе фильтра; остальные приглушены, «вне среза» — в легенде и подписи. Шкала — общая по стране.
- `view / setValues(v) / destroy()` (API): Вид, данные, уборка.
- `update({values,scope,view}) / destroy()` (API): Обновление одним проходом; старые setValues/setScope/view сохранены.
