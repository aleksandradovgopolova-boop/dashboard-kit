Рейтинг и сводка

Правая колонка дашборда: главное число, тренд и ранжированный список — кто хуже всех. Строки разделяются ритмом и наведением, не линейками.

стабильный код: css/components.css

Сводка по стране и топ-5 регионов; справа — чипы по уровням риска.

Когда использовать

Когда использовать
  • Вопрос «у кого хуже» по одному показателю: регионы по баллу, бригады по просрочке.
  • Нужен верх списка, а не весь список — топ-5 или топ-10.
  • Строка ведёт к объекту: клик открывает регион.
Когда выбрать другое
  • Несколько показателей на объект — Таблица.
  • Доля от самого крупного полосой — Полосы (dk-bars).
  • Все 89 регионов — Плитки регионов.

Анатомия

Номера на схеме — те же, что в списке.

1 негатив растёт в 28
223/89
3Регионы
  1. Тренд сводки — dk-trend внутри dk-summary: куда идёт и в скольких объектах.
  2. Главное число — dk-score: значение и «из скольких» мельче.
  3. Шапка рейтинга — надпись и стрелка направления сортировки.
  4. Номер — dk-rank__i: место в списке, две цифры.
  5. Название — переносится и остаётся видимым целиком.
  6. Значение — dk-rank__v табличными цифрами; цвет смысла через --accent.

Варианты и размеры

Размер один: правая колонка макета dk-layout. Строк — пять или десять; больше — таблица с пагинацией.

Класс или параметрЧто делаетКогда
dk-summaryГлавное число с трендом.Верх правой колонки.
dk-rankРанжированный список кнопок.Топ-N.
dk-chipЧисло с подписью.Разбивка по категориям под сводкой.
--accent на dk-rank__v / dk-chip__nЦвет смысла значения.Порог: crit-ink, high-ink, calm-ink.

Состояния

Загрузка
Загружаем рейтинг
Ничья и нет данных
Равные значения делят место. Два региона с баллом 73 — оба четвёртые, следующий шестой. Регион без данных в рейтинг не входит и стоит внизу с прочерком.

Контент

Так
  • Заголовок сводки с периодом: «Сводка по стране · 14 дней».
  • Главное число с «из скольких»: 23/89.
  • Название региона официальное, как в справочнике.
Не так
  • Рейтинг из двадцати строк — это таблица.
  • Число без периода и без «из».
  • Цвет значения без порога — «просто красиво».

Доступность

  • Строки — кнопки: Tab и Enter открывают объект; кольцо фокуса при навигации с клавиатуры.
  • Порядок читается числом номера, не только положением.
  • Значение цветом и числом; цвет — дополнение.
  • Контраст. Значения на поверхности панели — проверка КОНТРАСТ.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

  • Читаем css/components.css…

Код

Только разметка. Ряды строит страница из данных; клик по строке — её событие.

<div class="dk-summary" style="--accent:var(--crit-ink)">
  <div><div class="dk-trend"><svg class="dk-i"><use href="#ti-arrow-up-right"/></svg> негатив растёт в 28</div></div>
  <div class="dk-score"><span class="dk-score__v">23</span><span class="dk-score__of">/89</span></div>
</div>

<div class="dk-rank">
  <div class="dk-rank__head"><span class="dk-overline">Регионы</span></div>
  <button class="dk-rank__row" data-id="RU-CR">
    <span class="dk-rank__i">01</span>
    <span class="dk-rank__name">Крым</span>
    <span class="dk-rank__v" style="--accent:var(--crit-ink)">82</span>
  </button>
</div>

Связанное

  • Таблица — несколько показателей на объект
  • KPI-плитка — одно число без списка
  • Регионы — те же данные на карте и плитках
