🏆Рейтинг и сводка

Располагает объекты по одному показателю, чтобы быстро увидеть лидеров и отстающих.

В работе

Порядок строк помогает найти крайние значения, полосы — оценить разницу. Подпись уточняет показатель и направление сортировки.

Когда использовать

Когда использовать
  • Вопрос «у кого хуже» по одному показателю: регионы по баллу, команды по просрочке.
  • Нужен верх списка, а не весь список — топ-5 или топ-10.
  • Строка ведёт к объекту: клик открывает регион.
Когда выбрать другое
  • Несколько показателей на объект — Таблица.
  • Доля от самого крупного полосой — Полосы (dk-bars).
  • Все 89 регионов — Плитки регионов.
Правила сочетания
  • Масштаб и пропорции
  • Дашборд по вопросу пользователя
  • Иерархия без декоративного шума

Из чего состоит

1 негатив растёт в 28
223/89
3Регионы
  1. Тренд сводки — dk-trend внутри dk-summary: куда идёт и в скольких объектах.
  2. Главное число — dk-score: значение и «из скольких» мельче.
  3. Шапка рейтинга — надпись и стрелка направления сортировки.
  4. Номер — dk-rank__i: место в списке, две цифры.
  5. Название — переносится и остаётся видимым целиком.
  6. Значение — dk-rank__v табличными цифрами; цвет смысла через --accent.

Ширина определяется сеткой виджетов. Показывайте короткий список лидеров; полный набор вынесите в таблицу с сортировкой и пагинацией.

Состояния

Ничья и нет данных
Равные значения делят место. Два региона с баллом 73 — оба четвёртые, следующий шестой. Регион без данных в рейтинг не входит и стоит внизу с прочерком.

Текст и подписи

Понятно
  • Заголовок называет показатель и порядок: «Регионы с наибольшим отставанием».
  • У числа есть единица и период; база сравнения указана, если нужна.
  • Полные названия объектов совпадают с источником.
Вызывает вопросы
  • Длина полосы и число показывают разные показатели.
  • Порядок строк не объяснён.
  • Одинаковый цвет обозначает разные уровни риска.

Доступность

  • Строки — кнопки: Tab и Enter открывают объект; кольцо фокуса при навигации с клавиатуры.
  • Порядок читается числом номера, не только положением.
  • Значение цветом и числом; цвет — дополнение.
  • Контраст. Значения на поверхности панели — проверка КОНТРАСТ.

С чем сочетать

  • Таблица — несколько показателей на объект
  • KPI-плитка — одно число без списка
  • Регионы — те же данные на карте и плитках
