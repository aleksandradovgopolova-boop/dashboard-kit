# Значение и цель

Сравнивает фактическое значение с целью и заданными диапазонами.

## Когда использовать

- В KPI нужно сравнить одно число с целевым уровнем.

## Когда выбрать другое

- Временной тренд: используйте line; доли целого: stacked-bar.

## Контент: так

- «Факт 72%, цель 90%»: обе величины имеют одну единицу.

## Контент: не так

- Полоса без подписанной цели и границ шкалы.

## Доступность

- Факт, цель и шкала написаны словами. Декоративная полоса aria-hidden. Горизонтальная полоса работает без hover и не является контролом.
- Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

## Пример

Найдите факт и целевой уровень. Подписи позволяют прочитать результат без оценки цвета.

## Структура

- **Контекст** — Компактно показывает факт, целевой уровень и контекст диапазонов.
- **Данные и действие** — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

## Состояния

Отсутствующий факт обозначается текстом и нейтральной заливкой; отсутствующая цель не рисуется. Факт вне шкалы визуально ограничивается, полное число остаётся в тексте. max должен быть больше min.

## Варианты

- `dkBullet(el, opts)` — Основной контракт API/markup. При задаче, описанной выше.

## Размеры

Полоса занимает ширину контейнера; значения и цель доступны текстом.

## Код

```html
<div id="advanced-bullet"></div>
<script>
document.addEventListener("DOMContentLoaded", function(){
dkBullet(document.getElementById('advanced-bullet'), {label:'Устранение за смену', actual:72, target:80, min:0, max:100, unit:'%', ranges:[{to:60,label:'Ниже нормы'},{to:100,label:'Рабочий диапазон'}]});
});
</script>
```

## Параметры

- `dkBullet(el, opts)` (API): actual, target, min, max, unit, ranges:{to,label}[], meaning?; update(opts), destroy().
