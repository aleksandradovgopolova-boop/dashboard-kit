# Каркас виджета

Объединяет хедер, содержимое и необязательный подвал в одну повторяемую структуру с едиными отступами и состояниями.

## Когда использовать

- Нужно поместить график, карту, таблицу или список в общую поверхность.
- Несколько блоков должны собираться по одинаковым правилам.

## Когда выбрать другое

- Для KPI брать tile, для сообщения состояния banner.
- Не оборачивать виджет ещё одним виджетом ради дополнительного фона.

## Контент: так

- Во всех состояниях сохранять название и контекст; тело заменяется загрузкой, пустым состоянием или ошибкой.
- Ноль отображать как значение. Нет данных — отдельное состояние.
- У таблицы прокручивается dk-tablewrap; вся страница не расширяется.
- Легенда принадлежит графику и остаётся с ним при экспорте или полном экране.

## Контент: не так

- График без названия, единиц и периода.
- Фиксированная высота, которая режет данные или длинный текст.
- Декоративные обводки и тени.
- Добавлять скролл внутри каждого виджета по умолчанию.

## Доступность

- Заголовки передают иерархию: один h1 страницы, h2 виджетов; в живых примерах справочника уровень сдвинут на один.
- Название не обрезается многоточием. При увеличении текста хедер растёт, действия переносятся.
- Переход — ссылка, изменение состояния — кнопка с доступным именем; декоративные SVG скрыты от скринридера.
- Цвет не заменяет текст состояния. Клавиатурный фокус остаётся видимым, сенсорная цель не меньше 44 px.
- Для именованной секции свяжите section и заголовок через уникальные aria-labelledby/id. Повторные экземпляры не разделяют id.
- Статус обновления — role=status; ошибка объявляется в месте действия. Не переводить фокус при фоновом обновлении.

## Пример

Атомы (текст, значок, кнопка, статус) → хедер → тело с компонентом данных → виджет → сетка страницы. В примере все переходы работают.

## Структура

- **Оболочка** — dk-widget: поверхность, внутренние поля, скругление. Без обводки и тени.
- **Хедер** — Название и локальные действия, отдельный компонент.
- **Тело** — dk-widget__body: один ответ на вопрос — график, карта, таблица или список. Содержимое может иметь свои составные части.
- **Подвал** — Необязательный dk-widget__footer: источник, пояснение или переход. Не дублирует легенду графика.
- **Сетка** — Внешняя dk-grid задаёт ширину и интервалы; виджет не определяет своё место на странице.

## Состояния

Последние события За выбранный период событий нет. Вернуться к сводке

## Варианты

- `dk-region-tools--stacked / __primary / __filters` — Поиск, период, настройки в первой строке; чипы риска (dk-legend / dk-lg) и сброс постоянно видны во второй. Выбор пользователя: не прятать рабочий фильтр в настройки. Живой пример — regions.html.
- `dk-focus-layout + __primary + __aside` — Главный объект и связанная боковая сводка, 2.2:1; ниже 1200px одна колонка. Для карты с рейтингом: управление, сводка и детали относятся к одному срезу.
- `dk-widget` — Базовая оболочка. Обычный содержательный блок.
- `dk-widget--overview` — Плотность выбранного референса. Карточки текущей сводки.
- `dk-widget__body / __footer` — Тело и необязательный подвал. Подвал отсутствует, если нечего сообщить.
- `dk-widget-icon / --crit` — Контурный значок на мягком круге. Смысловой значок в виджете, не обязательное украшение каждого хедера.

## Размеры

Поля --pad-widget, скругление --radius-xl, поверхность --surface. Базовый промежуток --gap-section; обзорный dk-widget--overview использует --space-5, как текущая сводка. Тело --gap-group. Ширина от сетки; фиксировать высоту всей карточки запрещено, если содержимое может вырасти.

## Код

```html
<section class="dk-widget dk-widget--overview">
<header class="dk-widget__head">
  <div class="dk-widget__heading">
    <h2 class="dk-widget__title">Последние события</h2>
    <p class="dk-widget__meta">Демонстрационные данные · за сутки</p>
  </div>
  <div class="dk-widget__actions"><a class="dk-btn dk-btn--ghost dk-btn--sm" href="accidents.html">Все аварии <svg class="dk-i" aria-hidden="true"><use href="#ti-chevron-right"/></svg></a></div>
</header>
  <div class="dk-widget__body">
    <div class="dk-row"><span class="dk-row__label">Прорыв теплотрассы</span><span class="dk-status dk-status--crit">В работе</span></div>
    <div class="dk-row"><span class="dk-row__label">Подача восстановлена</span><span class="dk-status dk-status--calm">Устранена</span></div>
  </div>
  <footer class="dk-widget__footer"><span>Два демонстрационных события</span><a class="dk-btn dk-btn--ghost dk-btn--sm" href="component-table.html">Табличный вариант</a></footer>
</section>
```

## Параметры

- `Сборка` (Порядок): dk-widget > header.dk-widget__head + div.dk-widget__body + footer.dk-widget__footer (опционально).
- `Данные` (Ответственность): Хост передаёт один согласованный срез в компоненты данных. Оболочка не вычисляет показатели.
- `Проверка` (Критерий): 320/390/1536 px, обе темы, длинный заголовок, 200% текст, клавиатура, загрузка/пусто/ошибка без потери контекста.
