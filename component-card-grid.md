# Сетка карточек

Адаптивная сетка карточек с равной высотой соседей.

## Когда использовать

- Сравнить несколько равноправных объектов.
- Все карточки должны быть видны в потоке страницы.

## Когда выбрать другое

- Сложный дашборд с разными долями виджетов — dk-grid.
- Последовательные истории — CardScroll.

## Контент: так

- Полные названия объектов и конкретные действия.

## Контент: не так

- Непонятные подписи «Далее» для перехода к объектам без контекста.

## Доступность

- Порядок чтения и Tab соответствует DOM; не используйте reverse для смысловой перестановки.
- На телефоне кнопки имеют область нажатия минимум 44 px.

## Размеры

Используются общие токены интервалов и размеров контролов. Соседние карточки растягиваются до одинаковой высоты; текст не обрезается.

## Код

```html
<ul class="dk-card-grid" aria-label="Отчёты"><li><div class="dk-widget dk-widget--s"><h3 class="dk-widget__title">Отчёт 1</h3><p>Продажи по каналам.</p><a class="dk-btn dk-btn--sm" href="component-table.html">Открыть пример таблицы</a></div></li><li><div class="dk-widget dk-widget--s"><h3 class="dk-widget__title">Отчёт 2</h3><p>Продажи по каналам и категориям товаров.</p><a class="dk-btn dk-btn--sm" href="component-table.html">Открыть пример таблицы</a></div></li><li><div class="dk-widget dk-widget--s"><h3 class="dk-widget__title">Отчёт 3</h3><p>Продажи по каналам.</p><a class="dk-btn dk-btn--sm" href="component-table.html">Открыть пример таблицы</a></div></li></ul>
```

## Параметры

- `--card-min-width` (переменная в style): Минимальная ширина, не больше ширины контейнера.
