Каркас виджета

Объединяет хедер, содержимое и необязательный подвал в одну повторяемую структуру с едиными отступами и состояниями.

стабильный код: css/components.css

Живой пример

Атомы (текст, значок, кнопка, статус) → хедер → тело с компонентом данных → виджет → сетка страницы. В примере все переходы работают.

Когда использовать

Когда использовать
  • Нужно поместить график, карту, таблицу или список в общую поверхность.
  • Несколько блоков должны собираться по одинаковым правилам.
Когда выбрать другое
  • Для KPI брать tile, для сообщения состояния banner.
  • Не оборачивать виджет ещё одним виджетом ради дополнительного фона.

4Два демонстрационных событияТабличный вариант
  1. Оболочка — dk-widget: поверхность, внутренние поля, скругление. Без обводки и тени.
  2. Хедер — Название и локальные действия, отдельный компонент.
  3. Тело — dk-widget__body: один ответ на вопрос — график, карта, таблица или список. Содержимое может иметь свои составные части.
  4. Подвал — Необязательный dk-widget__footer: источник, пояснение или переход. Не дублирует легенду графика.
  5. Сетка — Внешняя dk-grid задаёт ширину и интервалы; виджет не определяет своё место на странице.

Варианты и размеры

Поля --pad-widget, скругление --radius-xl, поверхность --surface. Базовый промежуток --gap-section; обзорный dk-widget--overview использует --space-5, как текущая сводка. Тело --gap-group. Ширина от сетки; фиксировать высоту всей карточки запрещено, если содержимое может вырасти.

Вернуться к сводке

Контент

Так
  • Во всех состояниях сохранять название и контекст; тело заменяется загрузкой, пустым состоянием или ошибкой.
  • Ноль отображать как значение. Нет данных — отдельное состояние.
  • У таблицы прокручивается dk-tablewrap; вся страница не расширяется.
  • Легенда принадлежит графику и остаётся с ним при экспорте или полном экране.
Не так
  • График без названия, единиц и периода.
  • Фиксированная высота, которая режет данные или длинный текст.
  • Декоративные обводки и тени.
  • Добавлять скролл внутри каждого виджета по умолчанию.

Доступность

  • Заголовки передают иерархию: один h1 страницы, h2 виджетов; в живых примерах справочника уровень сдвинут на один.
  • Название не обрезается многоточием. При увеличении текста хедер растёт, действия переносятся.
  • Переход — ссылка, изменение состояния — кнопка с доступным именем; декоративные SVG скрыты от скринридера.
  • Цвет не заменяет текст состояния. Клавиатурный фокус остаётся видимым, сенсорная цель не меньше 44 px.
  • Для именованной секции свяжите section и заголовок через уникальные aria-labelledby/id. Повторные экземпляры не разделяют id.
  • Статус обновления — role=status; ошибка объявляется в месте действия. Не переводить фокус при фоновом обновлении.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.
