Экспорт среза

Локально сохраняет текущие строки таблицы или изображение графика.

экспериментальный код: css/components.css · js/dk-workspace.js

Живой пример

Когда использовать

Когда использовать
  • Нужно передать текущий filtered dataset или сохранить график.
Когда выбрать другое
  • Экспорт всего серверного набора: нужен отдельный серверный контракт.

Анатомия

Номера на схеме — те же, что в списке.

  1. Контекст — Локально сохраняет текущие строки таблицы или изображение графика.
  2. Данные и действие — Живой пример показывает контракт подключения; демонстрационные данные не являются производственным срезом.

Варианты и размеры

Компонент следует ширине контейнера и системным токенам. Нативная кнопка с ясным названием формата. Экспорт не требует сервера; файл создаётся браузером. Об успешном скачивании ОС API не сообщает.

Класс или параметрЧто делаетКогда
dkExport.csv(rows, columns, name?)Основной контракт API/markup.При задаче, описанной выше.

Состояния

Canvas-графики экспортируются PNG, не SVG. SVG с внешними ресурсами/скриптами отклоняется. Имя очищается. Blob возвращается без скачивания, если name не передан.

Контент

Так
  • Нужно передать текущий filtered dataset или сохранить график.
  • Показывайте полные названия, единицы и источник данных.
Не так
  • Экспорт всего серверного набора: нужен отдельный серверный контракт.
  • Не выдавайте отсутствие наблюдений за ноль и не используйте цвет как единственное объяснение.

Доступность

  • Нативная кнопка с ясным названием формата. Экспорт не требует сервера; файл создаётся браузером. Об успешном скачивании ОС API не сообщает.
  • Dark/light берутся из ближайшего dk-root; reduced motion не требует анимации. Проверки DOM/клавиатуры не заменяют живой скринридер или физический телефон.

Токены

Какие токены читает компонент. Список собирается при открытии страницы из css/components.css по префиксам селекторов, а не пишется руками — иначе разошёлся бы с кодом при первой правке. Значения — с экрана, в текущей теме.

ПараметрТипЧто делает
