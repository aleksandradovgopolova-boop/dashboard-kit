# Flex

Располагает элементы в строку или колонку с общими интервалами.

## Когда использовать

- Кнопки и подписи внутри одной группы.
- Колонка элементов с одинаковым интервалом.

## Когда выбрать другое

- Сетка карточек — CardGrid или dk-grid.
- Не меняйте визуальный порядок относительно DOM.

## Контент: так

- Полные названия объектов и конкретные действия.

## Контент: не так

- Непонятные подписи «Далее» для перехода к объектам без контекста.

## Доступность

- Порядок чтения и Tab соответствует DOM; не используйте reverse для смысловой перестановки.
- На телефоне кнопки имеют область нажатия минимум 44 px.

## Пример

Измените ширину окна: обратите внимание на перенос и выравнивание группы действий.

## Структура

- **Контейнер** — Задаёт раскладку или поведение.
- **Содержимое** — Названия, данные и доступные действия задаёт приложение.

## Состояния

Строка переносится при нехватке ширины. Для вертикальной группы используйте column; nowrap допустим только при гарантированно коротком содержимом.

## Варианты

- `dk-flex` — Строка с переносом. По умолчанию.
- `dk-flex--column` — Колонка. Вертикальная группа.
- `dk-flex--between / --center` — Распределение по главной оси. Шапка / центрирование.
- `dk-flex--start / --stretch` — Выравнивание по поперечной оси. Разная высота / одинаковая высота.
- `dk-flex--nowrap` — Без переноса. Только если содержимое помещается.

## Размеры

Ширина определяется контейнером. Интервалы задаёт --flex-gap; перенос включён по умолчанию. Выравнивание выбирается по задаче группы.

## Код

```html
<div class="dk-flex dk-flex--between"><span>Отчёты</span><div class="dk-flex"><button class="dk-btn dk-btn--sm">Обновить</button><button class="dk-btn dk-btn--sm">Экспорт</button></div></div>
```

## Параметры

- `--flex-gap` (переменная в style): По умолчанию --gap-inline; используйте токен интервала.
