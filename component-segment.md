# Сегмент

Переключает представление одних данных: карту и список, месяц и неделю.

## Когда использовать

- Два–пять вариантов одного и того же: вид, период, единица измерения.
- Переключение мгновенное и без загрузки страницы.
- Все варианты должны быть видны сразу — выбор из скрытого списка здесь хуже.

## Когда выбрать другое

- Переход в другой раздел со своим адресом — Вкладки.
- Больше пяти вариантов — Фильтр с выпадающим списком.
- Независимое «да / нет» — Флажок или тумблер.

## Контент: так

- Короткие подписи одной формы: «Карта / Плитки», «7 дней / 30 дней».
- Первым стоит вид по умолчанию, и он же выбран при открытии.
- Значок и слово вместе; только значки — когда у группы есть aria-label.

## Контент: не так

- «Показать карту / Показать плитки» — глаголы у сегмента лишние.
- Пустая группа без выбранного: человек не знает, что он смотрит сейчас.
- Сегмент, который ведёт на другую страницу, — это вкладки под чужим видом.

## Доступность

- Роль. role="group" + aria-label, кнопки с aria-pressed. Не tablist: вкладки обещают отдельные панели с адресом.
- Клавиатура. Tab ходит по кнопкам, Enter и пробел переключают. Стрелки внутри группы кит не перехватывает — это обычные кнопки.
- Контраст. Выбранная кнопка к контейнеру не ниже 3:1 в обеих темах и не ярче самой контрастной серии — проверка ТИШИНА.
- Не только цветом. Выбранное отличается ещё и жирностью подписи.

## Пример

Выберите другой вариант. Активным остаётся только один пункт; переключение видно сразу.

## Структура

- **Контейнер** — role="group" с aria-label: скринридер слышит «группа Вид», а не «вкладки», и не ждёт новой загрузки.
- **Выбранная кнопка** — aria-pressed="true": серая заливка --control-on, подпись жирнее. Контраст к контейнеру 3,44:1 (проверка ТИШИНА).
- **Обычная кнопка** — прозрачная, при наведении темнеет подпись.

## Состояния

Выбрано Обычное Фокус Недоступно Состояния «загрузка» у сегмента нет. Переключение обязано быть мгновенным; если данные для другого вида грузятся, грузится виджет (скелетон), а не кнопка.

## Варианты

- `dk-seg` — Сегмент размера M. По умолчанию.
- `dk-seg--sm / dk-seg--lg` — Высота 28 или 40. Шапка виджета (sm), панель страницы (lg).
- `dk-seg--icons` — Кнопки только со значками, квадратные. Когда слов не хватает по ширине; подпись — в aria-label и title.
- `aria-pressed="true"` — Атрибут выбранной кнопки. Ровно у одной кнопки группы.

## Размеры

Размер согласуется с соседними контролами. В стеклянной теме обычный сегмент использует --control-lg, компактный — --control-sm. Внутренняя кнопка учитывает поля общей подложки.

## Код

```html
<div class="dk-seg" role="group" aria-label="Вид данных">
  <button type="button" data-view="map" aria-pressed="true">Карта</button>
  <button type="button" data-view="tiles" aria-pressed="false">Плитки</button>
</div>

<script>
seg.addEventListener('click', function (e) {
  var b = e.target.closest('button[data-view]');
  if (!b) return;
  seg.querySelectorAll('button').forEach(function (x) { x.setAttribute('aria-pressed', String(x === b)); });
  map.view = b.dataset.view;   // например, dkMap
});
</script>
```

## Параметры

- `aria-pressed` (атрибут): «true» у выбранной кнопки; страница переключает сама.
- `dk-seg--sm, dk-seg--lg` (класс): Размер группы.
- `dk-seg--icons` (класс): Квадратные кнопки под значки.
- `disabled` (атрибут кнопки): Вариант недоступен — например, нет данных для плиток.
