# Сегмент

Переключает представление одних данных: карту и список, месяц и неделю.

## Когда использовать

- Два–пять вариантов одного и того же: вид, период, единица измерения.
- Переключение мгновенное и без загрузки страницы.
- Все варианты должны быть видны сразу — выбор из скрытого списка здесь хуже.

## Когда выбрать другое

- Переход в другой раздел со своим адресом — Вкладки.
- Больше пяти вариантов — Фильтр с выпадающим списком.
- Независимое «да / нет» — Флажок или тумблер.

## Контент: так

- По умолчанию — узнаваемые значки; у каждой кнопки одинаковые aria-label и подсказка.
- Первым стоит вид по умолчанию, и он же выбран при открытии.
- Текст — осознанное исключение: «7 дней / 30 дней / Год» точнее значков.

## Контент: не так

- «Показать карту / Показать плитки» — глаголы у сегмента лишние.
- Пустая группа без выбранного: человек не знает, что он смотрит сейчас.
- Сегмент, который ведёт на другую страницу, — это вкладки под чужим видом.

## Доступность

- Роль. role="group" + aria-label, кнопки с aria-pressed. Не tablist: вкладки обещают отдельные панели с адресом.
- Клавиатура. Tab ходит по кнопкам, Enter и пробел переключают. Стрелки внутри группы кит не перехватывает — это обычные кнопки.
- Контраст. Выбранная кнопка к контейнеру не ниже 3:1 в обеих темах и не ярче самой контрастной серии — проверка ТИШИНА.
- Имена и состояния. Каждый значок имеет aria-label и подсказку; выбор передаётся через aria-pressed. Фокус меняет заливку и цвет значка, без обводки.

## Пример

По умолчанию — S со значками, названия доступны в подсказках. Один вариант выбран всегда. Периоды сохраняют текст: значок не передаёт точный интервал.

## Структура

- **Контейнер** — role="group" с aria-label: скринридер слышит «группа Вид», а не «вкладки», и не ждёт новой загрузки.
- **Выбранная кнопка** — aria-pressed="true": заливка --control-on отделяет выбранный значок от общей подложки; текстовый вариант дополнительно выделяется жирностью.
- **Обычная кнопка** — прозрачная, при наведении темнеет подпись.

## Состояния

Выбрано Обычное Фокус Недоступно Состояния «загрузка» у сегмента нет. Переключение обязано быть мгновенным; если данные для другого вида грузятся, грузится виджет (скелетон), а не кнопка.

## Варианты

- `dk-seg` — Сегмент размера S · 32 px. По умолчанию на дашборде.
- `dk-seg--sm / dk-seg--md / dk-seg--lg` — Внешняя высота 32, 36 или 44 px. S — по умолчанию; M и L выбираются явно.
- `dk-seg--icons` — Кнопки только со значками, квадратные. Основной вариант: у каждой кнопки есть aria-label и title. Текст оставляем для периодов и других значений, которым нужен точный смысл.
- `aria-pressed="true"` — Атрибут выбранной кнопки. Ровно у одной кнопки группы.

## Размеры

Размер согласуется с соседними контролами. По умолчанию S использует --control-sm (32 px); явные --md и --lg дают M 36 px и L 44 px. Это полная внешняя высота сегмента: она совпадает с кнопкой того же размера. На таче цели от 44 px. Внутренняя кнопка учитывает поля общей подложки.

## Код

```html
<div class="dk-seg dk-seg--icons" id="data-view" role="group" aria-label="Вид данных">
  <button type="button" data-view="map" aria-pressed="true" aria-label="Карта" title="Карта">
    <svg class="dk-i" aria-hidden="true"><use href="#ti-map"/></svg>
  </button>
  <button type="button" data-view="tiles" aria-pressed="false" aria-label="Плитки" title="Плитки">
    <svg class="dk-i" aria-hidden="true"><use href="#ti-layout-grid"/></svg>
  </button>
  <button type="button" data-view="table" aria-pressed="false" aria-label="Таблица" title="Таблица">
    <svg class="dk-i" aria-hidden="true"><use href="#ti-table"/></svg>
  </button>
</div>

<script>
var seg = document.getElementById('data-view');
seg.addEventListener('click', function (e) {
  var b = e.target.closest('button[data-view]');
  if (!b) return;
  seg.querySelectorAll('button').forEach(function (x) { x.setAttribute('aria-pressed', String(x === b)); });
  // Здесь обновите представление страницы по b.dataset.view.
});
</script>
```

## Параметры

- `aria-pressed` (атрибут): «true» у выбранной кнопки; страница переключает сама.
- `dk-seg--sm, dk-seg--md, dk-seg--lg` (класс): Внешняя высота S 32, M 36 или L 44 px; по умолчанию S.
- `dk-seg--icons` (класс): Квадратные кнопки под значки.
- `disabled` (атрибут кнопки): Вариант недоступен — например, нет данных для плиток.
