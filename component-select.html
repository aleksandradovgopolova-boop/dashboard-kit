🔎Фильтр

Ограничивает данные выбранными значениями из списка. Текущий выбор виден в закрытом фильтре.

Статус: стабильный ПримерКак выбратьС чем сочетатьКод и API

В работе

Выберите значение из списка или найдите его поиском. Выбранный фильтр остаётся виден после закрытия; его можно сбросить.

Когда использовать

Когда использовать
  • Нужно ограничить срез известными значениями: категориями, статусами, исполнителями.
  • Выбор применяется сразу и отражается в связанных показателях. Область действия фильтра понятна.
  • Для длинного списка нужен поиск; количество записей рядом со значением помогает оценить выбор.
Когда выбрать другое
  • Два–пять значений, видимых сразу, — Сегмент или Фильтры-легенда.
  • Даты — Период.
  • Ввод значения в форме, которое применяется по кнопке, — Поле с <select>.
Правила сочетания
  • Микровзаимодействия
  • Размеры элементов
  • Выбор значений
  • Фильтрация
  • Консистентность
  • Таблицы для чтения и сравнения

  6. Пункт — role="option"; выбранный отмечен галочкой, а не только цветом.
  7. Число записей — за каждым значением; ноль показывается приглушённым, а не прячется.

Варианты и размеры

Высота и радиус из общей шкалы контролов; в стеклянной теме обычный контрол — 44 px, size: 'sm' для шапки виджета. Ширина по подписи; длинная подпись переносится и остаётся видимой целиком.

Состояния

Пустой список — не пустое меню. Если под текущий срез не осталось значений, меню говорит «Ничего не найдено» и предлагает снять поиск; молча пустой список читается как поломка.

Текст и подписи

Понятно
  • Подпись — название измерения: «Округ», «Уровень риска»; после выбора — «Округ: Сибирский».
  • Число записей рядом с каждым значением.
  • Выбранное значение внутри самого фильтра; общий сброс-иконка появляется только при изменённом срезе.
Вызывает вопросы
  • «Все округа» после выбора — самая дорогая ошибка дашборда.
  • «Выбрано несколько» вместо числа.
  • Фильтр без счётчика результата: человек выбирает вслепую и попадает в пустой экран.

Доступность

  • Роли. Кнопка с aria-haspopup="listbox" и aria-expanded; меню — listbox с option и aria-selected.
  • Клавиатура. Стрелки, Home, End, Enter, Escape с возвратом фокуса на фильтр. Поиск получает фокус при открытии.
  • Не только цветом. Выбранное отмечено галочкой; активный фильтр — ещё и текстом подписи.
  • Контраст. Активный фильтр различим по подписи и мягкому тону поверхности; клавиатурный фокус виден отдельно.

С чем сочетать

  • Период — тот же фильтр, только значение — время
  • Фильтры-легенда — фильтр в один ряд, когда значений мало
  • Таблица — что стоит под фильтрами
  • Витрина: фильтры — полный пример со строкой применённого

Код и API

Контейнер пустой, разметку строит скрипт. Значения приходят списком объектов.

Исходники: css/components.css · js/dk-select.js

<!-- Строка фильтров — прямо на странице, над содержимым. На телефоне она
     переносится по доступной ширине. -->
<div class="dk-toolbar">
  <div class="dk-toolbar__group">
    <div id="period"></div>
    <div id="okrug"></div>
  </div>
</div>

<script>
var f = dkSelect(document.getElementById('okrug'), {
  label: 'Округ',
  options: [{ value: 'sfo', name: 'Сибирский', count: 10 }, /* … */],
  mode: 'single',        // или 'multi'
  url: 'okrug',          // ?okrug=sfo — ссылка на срез
  onChange: function (value) { /* строка или массив (multi) */ }
});
f.value;                 // текущее
f.set('sfo'); f.clear(); f.setOptions(list);
</script>

Параметры и методы

ПараметрТипЧто делает

options[]массив {value, name, count}Значения; count — записей за значением, ноль не прячется.
mode'single' | 'multi'Одиночный закрывает меню, множественный — нет.

urlстрокаКлюч в строке запроса; пусто — не пишется.
onChange(v)функцияПри каждой смене выбора.
value / set(v) / clear() / setOptions(list)APIЧитать и менять снаружи.
update({value,options}) / destroy()APIТихое обновление; cleanup меню, focusout, anchor и подписок. Старые set/clear/setOptions сохранены.
